# memfn/src/ — the kit's sources

Built into `libpcrec.a` by pcrec's Makefile (`KITSRCS`, compiled with `KITFLAGS`: no `-Ilib`/`-Isrc`, so nothing here can include pcrec). Every file includes its headers by relative path. pcrec's emitters render sites through the kit (`src/gen/memfn_sites.c`, DELEG_SITES): offset-skip block, pre-check composite, the VM's literal-run compare (VMRUN, runcmp.c), the prefilter find (PF, pffind.c).

## Standing rules

- External symbols go through `MF_NS` (`pcrec_mf_*`; C15), everything else `static`; an SPDX line and a provenance header on every file, with its row in `../PROVENANCE.md` (C16); nothing included from pcrec's `src/`/`cli/`/`lib/`. Scalar-arm provenance lines read `pcrec <commit> (relicensed 0BSD by its author, D145 addendum 1)` (R-4 Q1).
- The scalar arms are the LIVE scalar layer (D147): improvable kit code. Each byte-moving change adds its own `--memfn=no-NAME` deny row in `options.def` in the SAME commit, raises the floor in `docs/spec/registry.md` §6, and — where it moves a pcrec byte — is a pcrec abi event with `tests/memfn/pins/arms.tsv` re-pinned in the same commit. See `../CLAUDE.md` "The kit's option namespace".
- Selection is ONE walk, `kit_walk` (integration.md §R4.9.2.3): per row of the asked slot, in table order: deny, gate, predicate; first match; an empty slot is no selection and records nothing. Arms (`select_arm`), the run compare (`rc_row_of`) and `fn_rows[]` (`fn_select`) all call it. Do not add a parallel walk (E-find's `fd_find` asks the finder's walk itself; `fd_nested_walk` retired with RPT, D172 S3).
- ROW CONTRACTS ([MEMFN-ROWCON], `docs/design/memfn/row_contracts.md`): every arm declares `ct` (`uses`/`serves` with a citation per declaration at the end of the row's own file); the gate ENFORCES (a failing row is declined, a site no row serves is refused naming the fields, `mf_use` re-checks). Each row checks its own contract (K96); unstated fields are refused. Every arm declares `arm.tests` (`ARM_TESTS_EVERY`/`_REQUIRED`/`_UNSTATED`; an UNSTATED FIND row is refused by `mf_define`/`mf_ask`).
- Field/class space: `fields.def` classes and fields are bit sets; classes are FULL at 64 and fields at 64 (a 128-bit `kit_set` since R-26 Zk); a new class/field needs a wider mask. Any site-vocabulary move bumps `MF_SITE_ABI` / `MF_CLASS_V`.
- Vocabulary rules every site must pass live in `site_check` (`pred_kinds`, `rank_ok`, `window_check`, `kit_presence_check`, `kit_proof_check`, `pres_layout_check`; a window site's own statement rules, the renderer-interface refusal included, are window.c's `wf_check`); out-of-vocabulary shapes are REFUSED loudly. An UNSTATED `body` is refused (R-23); a PARAM body until B8.
- No tuning constant without a D149 label (derive, measure, or label unmeasured); overlap lengths and width rules are DERIVED.
- Generic row (`generic.c`) is the last row of every table, tests every term, honours `floor`/`n`/`end_back`/empty on every op, reads nothing for an empty range (§R4.7 F1). Its `stmt_advance` is pcrec's in-loop skip text for ADVANCE delegated sites (frozen target tests/memfn/pins/r4h_target/; sabotage S214, S616 anchored on its cap line).
- Finder (`finder.c`): `fd_rows[]` 10 rows (withdrawn, retired and deleted ids reserved, `memfn/docs/finder_history.md`; PAIR decides a window site's two-byte stop); LOCKDOWN: every row decides, no `routed` bit, no held row, R7w (the walk) the MEASURED default for every set FIND; a key ABSENT from the measurement set does not hold (never 0; S917, UNREACHED since no deciding row reads a key); one decision is the first row that holds (the residual N step and the pay rule retired with R8/R1/R2, span_pick 1f); a refusal is ONE path (`define_sel`); the trace-only shadow is retired. The window family's E-find asks the FIND slot about its stop (`fd_find`: the window site, the stop's set and offset) and renders the deciding row's pick. `memfn/docs/finder_history.md` logs routing.
- MF_TRACE (compile-time, off by default; format `../docs/trace_format.md`): `MFTRACE` records and reach counters; `REACH_DROPPED n=N` when the 32-row registry fills; `chosen=N asked=A`; keep `would_decline` meaning "the gate moved this selection".
- Zero-mover seam rules (R17-a): storage point protocol (`mf_locals` refused where `decl_point` is 0, twice, or with other `s`/`n` text; `mf_art_end` refuses "never placed"/"placed, never read" before "never used").
- SIMD rows (`vrun.c`) exist only as guarded, deny-able, ISA-gated forms; `policy` is a stated bit-set (PORTABLE/INLOOP/SIZE/NONE) a row must serve fully; scalar contracts serve MF_ANY; each SIMD form must beat scalar or show a named benefit (memory pcrec-post-spine-direction).
- STACK (R-28): no function over a 4 KB frame (`tests/memfn/run_link_checks.sh` holds it; the peak is stated in `../CLAUDE.md` "Compile-time stack"). A table that would pass it goes on the heap with a refusal path (`formhash.c` arena), or into a narrower type.
- Keep `mf_options()` (`--list-axes`) and `mf_opts_check()` (`--memfn=` acceptance) one table (`options.def`).
- THE WINDOW FAMILY (`window.c`, D172 S2 commit 1, `docs/design/memfn/window_site.md` rev 3.3) is the route of EVERY site stating window facts (`WF_STATES`: `mf_site.nalt`/`alts`/`wfloor`) on every art. Its fields.def fields classify only through `gate_in.wf` (unstated in every other walk, so no older row can be declined by them). Every cost row reads `plan_cost.def`; every tie reads `wf_ties[]` (the TIE table). Table E, first match: E-func/E-stmt render the plan TRANSLATED into today's row's site (so their text is today's; never a REPORT site); E-find (D172 S3, deny `window-search`) is the family's own find-then-verify text on a STMT/ASSIGN site with a stop (B: the FIND slot's pick, `fd_find`, by its renderer row: B-fn the offset-skip function for PAIR on a plan that is its predicate (fn-pair, SIMD rows over it), B-pair, B-memchr, B-walk; C: C-run's compares through runcmp; D: Table D, a kit_table: D-hors, deny `window-skip`, where the stop set's mass >= `HORS_MIN`, else D-one; the floor and E-find share the frame, prologue and test, C9); E-generic is the floor (`wf_floor_arm`), serving no REPORT site (so `no-window-search` refuses one and pcrec keeps its default). Its G2 family is `memfn/tests/run_g2_win.sh` (plants `--plants`).

## Files

- `kit.h` — INTERNAL header: `kb` text over the caller's `mf_arena`, `mf_art` and site records, arm interface (an arm writes straight to the sink), sink writers, `ofs_fn_*` renderer, `kit_table`/`kit_walk`, `gate_contract`, MF_TRACE calls, `MF_SERVES_*_TODAY`, `kit_set`. Never included outside this directory except by tests/memfn/proven_check.c.
- `compose.c` — K2, the composer: `mf_art`, define/use split (`mf_define`/`mf_use`/`mf_emit`/`mf_call`/`mf_art_end`), `site_check` rules, `kit_walk`, first-match arm table (an old-field REPORT site refused), `mf_ask`/`kit_class`/`proven[]`, `mf_locals`, `mf_defined`, stamps (`mf_stamps`: `RUN_WORDS`, `MEMFN_FORMS`, `MEMFN_LIBC` via `mf_art_note_libc`), `mf_reach`, `mf_lever` (the test-only levers' table, `kit_levers[]`; R-30).
- `generic.c` — the generic scalar row (plain byte loop for every vocabulary site; STMT/FUNC/EXPR; its context-span test left with `ctx`/`absent` at D172 S2 commit 6).
- `ofsskip.c` — offset-skip arm: `fn_rows[]` BODY (`fn-pair`, `fn-memchr`) and PREFIX slots, `ofs_fn_define` (`ofs_fn_define_at` for a site that is not the record's: E-find's B-fn; `ofs_fn_define_lead`, R-30: the verify chain's run compare led by a slice) routed as `<fn>__body` + `<fn>` selector, `ofs_fn_serves`; trace table `fn`; `ofs_pair_text` (+ `ofs_pair_decl`), the ONE two-stream (PAIR) renderer, bounded look-aheads so a find-all stays linear: fn-pair's body and window.c's B-pair.
- `vrun.c` — fused run-scan SIMD rows `vrun-w16`/`vrun-w32` (KB second filter, trim, padded verify; denies `no-vrun-kb`/`-trim`/`-pad`).
- `vany.c` — STANDALONE kernel, NOT ROUTED (no row, no deny, no pcrec caller): `mf_kernel_find_any`, find any of 2-3 bytes, `<fn>__body` + per-level helpers + selector (lane simdset). Its tests: `../tests/run_g2_any.py`; its card: `../data/cards/kit-kernels.tsv`.
- `levels.def`, `levels.c` — the kit's ISA levels table (`MF_LEVEL`), `mf_levels()`, `kit_level()`.
- `precheck.c` — pre-check composite: `precheck_arm` (ON_MISS), `precheck_assign_arm`, `precheck_assign_byte_arm` (deny `precheck-assign-byte`; pcrec states the shape from [REQ-HANDOFF-L1] only). R-30: a run part a later run part implies (its run a slice at the same scan byte, not `ret_pred`: the run WINDOW beside the WHOLE run) is neither defined nor asked, and the implying part's compare is LED by its bytes; the test-only lever `pres-window` keeps it.
- `runcmp.c` — run compare row table (`words`, `overlap`, `bytes`, `memcmp`), `run_cmp_render[_trim|_pad|_lead]` (`_lead`, R-30: a slice compared first, then the words outside it), `mf_flush_helpers`, `mf_run_rows`; THE NORMAL FORM's one spelling `run_cmp_sat` / `run_pos_sat` (span_pick 1d: gate.c's CL_UNSAT class, `kit_presence_check` and generic.c's RUN chain ask it).
- `pffind.c` — prefilter find rows (`pf_memchr`, `pf_memchr_bounded`, `pf_walk`, `pf_walk_bounded`, `pf_memchr_back`).
- `mismatch.c` — F8 mismatch loop (`mm_render`; generic + `mismatch_inplace_arm`).
- `k1_ref.c` — K1 reference functions (`mf_ref_*`), G2's oracle side; never artifact text.
- `fields.def` — the field/class X-macros (`MF_CLASS`, `MF_FIELD`) of the row contracts.
- `gate.c` — row-contract gate: classifiers, `gate_check`, `gate_describe`, `MF_MISS_N`/`mf_miss_n`, `kit_is_ident`, shape helpers, MF_TRACE records, `policy` `class_set_of`.
- `options.def`, `options.c` — option registry `MF_OPT(...)`; `mf_options`, `mf_opts_check`, `kit_opt_denied` (`no-<name>`).
- `finder.c` — the finder table (`fd_rows[]`, `fd_decide`, `fd_route`, `fd_pres`, `fd_find`, `mf_finder_rows`).
- `window.c` — the window family (D172 S2 commit 1): `wf_check`, THE CANDIDATE LIST `cands` (span_pick 1d: the one builder every Table A row reads: C-meet's positions with their mass/stop/stretch, the walked offsets on their own sets, F0; MFTRACE WCAND), Tables A (stop) / M (the MARGIN) / C (plan, T-VERIFY's step list: C-member first, C-bound applied: a full-set position is the bound alone) / D (resume: D-hors, D-one; a kit_table whose rows carry their actions, `wf_d_text`) / E (frame), Table B's renderer rows (`wf_brows`), the TIE table and THE PICK's one before-relation `kit_pick_takes` (span_pick 1d: every argmin over (value, tie row) asks it: A-mass, A-model, the run member, presence's set pick and run window), `kit_run_member` (the ONE run member, span_pick 1c: run_member, P3's scan, translate's ranking), `mf_wdecide` (phase 1), `wf_prepare` (phase 2), the pre-check's FUNC PARTS (`wf_part_site`, `wf_parts_check`, `wf_parts_prepare`: window facts per part, wsc3), the rows `wf_find_arm` (E-find, S3) and `wf_floor_arm` and their class (`wf_plan_class`).
- `plan_cost.def` — the window family's cost table `MF_COST(name, value, unit, provenance, box, basis)`: prefix_k's integers verbatim (window_site.md §3.3) and D-hors's PROVISIONAL `HORS_MIN` (S3).
- `presence.c` — KW-8 ports `mf_pres_ports` / `kit_pres_picks` (read by the routed PRES slot; S458, S1096, S1097 here, S1094 and S1095 on its window.c readers); the byte-rate and its ONE mass primitive `kit_byte_rate`/`kit_mass` over a multiset of byte SETS (set-only since span_pick 1c, D187), with the declared NONE row (span_pick 1b; the window family reads it too), and `kit_run_set`, the ONE run-position-to-set conversion. Its picks ask `kit_pick_takes` (T_PRES_MEMBER, T_WINDOW); its run scan asks `kit_run_member`.
- `formhash.c` — `mf_form_hash[_text]` (R-MS3 form identity; allocates with `malloc`, listing only).
