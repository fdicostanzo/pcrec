# memfn/tests/ — G2, the kit's own tests

G2 (integration.md §10.2, §14.6) checks the kit's rendered code against G2's OWN scalar byte loop over a GENERATED predicate space, never against another output of the kit's generator. Originally written D27-blinded (lane memfng2) from the contract (integration.md §8.3, §14) and `memfn/include/memfn.h` only, without the kit's source. The pcrec-side kit checks (C4, C5, C9-C17, pins under `tests/memfn/`) live in pcrec's `tests/`, not here.

## Standing rules

- Independence: G2's reference (`g2/g2_ref.c`) calls NO kit function (not even `mf_ref_*`); the floors in `run_g2.sh` are literals sharing no source with the generator or driver (K35: count populations). `g2_k1.c` is the only G2 file that links the kit's `mf_ref_*` answers; G2 never uses them as its oracle.
- Extending G2 to a new site-ABI/shape: write from `memfn.h` and integration.md §14/§15 contract sentences, not the kit's source (blinded families: stride, mismatch, ABI 6); the families written by the row's author (landmark gate sites, SIMD family) rest on the oracle and the compiler, and say so. Each lane's contract coverage and open questions go in its `G2*_REPORT.md`.
- Every new family draws its OWN RNG stream and id range (base none; `pf` via `pf_enter`/`pf_leave`; `stride` 1000000; `mismatch` 800000; `mline` 700000; landmark `gate` 2000000; `window` its own process, `run_g2_win.sh`) so no older site moves; give it a `--<fam>-only` generator switch if its row-count check needs one.
- From MF_SITE_ABI 11 the generator STATES the window (`g2_win`/`G2W(site)`) at every `mf_emit`/`mf_define` call and, from ABI 18, span 0's class (`g2_span0`), AFTER every perturbation so each refusal case keeps its refusal; the window rules are C5's gate cases (tests/memfn/arm_fixtures.c `seq_cases`), the R-26 proof checks are `tests/memfn/run_proof.sh`.
- ENFORCED CLASSES (hook-nonident, miss-unstated, refusal-unnamed, fn_ref-unstated, pf-edge, loop-exit; renamed from PENDING-ENFORCE): each a named population with a floor (`FLOOR_CLS_*`) and printed count; they render in their own batches. `G2_STRICT_HOOKS=0` is diagnostic only. Refusals must NAME the field the header names.
- Poison differential: every field the contract says a site does not use is set to junk; rendering must be byte-identical or refused (bisected to the field, `FAIL poison`). An UNSTATED `note` hook is never poisoned; a FUNC site's `pred.fn_ref` is never poisoned on ALL_PRESENT.
- Two entry paths differ by contract: `mf_emit` holds use hooks at selection; `mf_define`+`mf_use` refuse a use the form does not serve (lawful, counted `USEREFUSE`, unnamed must be 0). A refusal at `mf_define` of a site `mf_emit` rendered fails.
- Witnesses: W1 (reference defects `--ref-defect K`, 1-10), W2 (kit-text mutations `--mutate K`, 1-16; every mutated, non-equivalent site must be killed), W3 (planted functions: over/under-read, `st-*`, `mm-*`). A change to a reference range/shape adds its W1/W2/W3 witness. Guard-page witnesses run without aliases where an alias would fault anyway (`mm_noalias`).
- Read-limit layouts: U (guard at `s + n`), L (guard below `s + floor`, floor <= lo), A (exact heap, alignment 0..15), plus TIGHT for strided sites; a fault is a failure; a non-returning loop is stopped by a 10 s alarm and fails.
- Rows: `--rows` (implied by `--quick`) links against `build/libpcrec_mftrace.a` and sums `MFTRACE REACH chosen=N`; checks (a) REACH_DROPPED 0, (b) every row n >= 1, (c) distinct rows >= literal `FLOOR_ROWS` (20 now), (d) every process printed REACH lines, (f)/(g) MISMATCH-only and stride-only floors (`ST_ROW_FLOORS`). A new row raises `FLOOR_ROWS`.
- Every step runs under GNU timeout; `run_g2.sh` exits 0 only when failures 0, every floor holds and every witness fired. `make test-memfn-g2` = `--quick` (a `make test` section); `make test-memfn-g2-full` is opt-in, never part of `make test`. Mech arm `g2gate` for `run_g2_gate.sh`.
- SIMD family targets (unit U2): the space renders once per target (x86-64-v3, x86-64, generic), each file in the target's family guard, `mf_includes` lines, and region, the kit's text between markers; zero CPU conditionals or `#include`s and exactly the admitted levels' helpers per file; a consumer TU (r5 X-1); the x86-64 and generic tokens follow x86-64-v3's by rule. Host gate: arms for higher ISA levels are always BUILT but RUN only when the host supports the level (a file whose target needs it, or a -march above it); a skipped arm prints `SKIPPED ARM <level>: <why>; N checks NOT run` plus `skipped arms: K` (never a silent pass); `G2V_SKIP_ARMS` forces a skip; `G2V_CPUS` pin is honoured as given (hard error outside the affinity set); `G2V_JOBS` concurrent builds. Its checks: ranking check, verify check, padded verify, guarded bytes vs `tests/memfn/simd_bounds.tsv`, answers across levels and ASan+UBSan, per-path execution floors, six plants per level, no PDEP/PEXT/gather.
- Triage: `G2_TRACE=<site id>` prints every call of that site (layout U).
- Maintenance: update this file when a family, witness or runner changes; add the lane report here.

## Files

- `run_g2.sh` — the one command: builds generator against `build/libpcrec.a` (`-I memfn/include` only), renders, compiles (gcc+clang, ASan+UBSan on quick tier), runs driver and W1-W3, holds floors (`FAM_FLOORS`, `FORM_FLOORS`, `FLOOR_MT_*`, poison/semantic floors, libc leg `MEMFN_LIBC` vs `nm -u`). Options `--quick`, `--keep`, `--seed N`, `--rows`/`--no-rows`, and (quick only, R-39) `--part K/N`, `--units LIST`, `--list-units`; prints `checks passed/failed`.
- `g2_units.tsv`, `g2_parts.py`, `g2_parts_selftest.sh` — the SHARD SELECTOR (R-39): the quick tier's units and declared weights; `assign` (the deal for `--part K/N`), `reweight`/`predict` (weights from a log; predicted part walls) and `gather` (exact-population check + section 4b's (a)-(e) over the parts' `G2PART` lines + totals); the plants that make `gather` red. NOTES.md "The part selector".
- `run_g2_gate.sh` — the landmark `gate` family standalone (~30 s): ASan+UBSan runs, LMSITES floors, `precheck_assign_byte` chosen by trace, control (W2 mutation 2 kills >= 80%).
- `run_g2_simd.py` — SIMD-family runner (run_g2.sh section 4a; alone `python3 memfn/tests/run_g2_simd.py [--quick]`).
- `run_g2_any.py`, `g2/g2_any_gen.c`, `g2/g2_any_driver.c` — the FIND-ANY family (lane simdset; run_g2.sh section 4y, ~25 s alone): the standalone kernel `mf_kernel_find_any` over a generated byte-set space, one file per target (x86-64-v3, x86-64, generic; U2: zero CPU conditionals, the admitted helpers only), builds v3 at x86-64 and x86-64-v3 / x86-64 / generic at gpr-only / ASan+UBSan v3 against the driver's own byte loop (every length 0..73, every hit position, every alignment, guard pages at s + n and below s + pos), refusals (a non-row target, NULL, no brackets at a level, NULL `includes`), no kit `#include`, a consumer TU (r5 X-1), population floors, plants per admitted level (each red; the three bound plants must FAULT and run to the end), no PDEP/PEXT/gather. Host gate `G2A_SKIP_ARMS`, `G2A_JOBS`. Written by the kernel's author (not D27-blinded).
- `g2/g2.h` — G2's site description (`g2_site`, `g2_pred`, `g2_term`; `G2_MAXT` 32), outcomes, miss values, helpers; `G2_FAM_STRIDE`, `st_*` fields. Does not include `memfn.h`.
- `g2/g2_gen.c` — generator and G2's only kit caller: families `base`, `ofs`, `ofsrun`, `stmt`, `onebyte`, `gate` (+`landmark_one`), `setrest`, `vmrun`, `pf` (four cells + edges), `mline`, `mismatch`, `stride`, `sem` (semantic differential, incl. `site-fn_ref`), PENDING queue, REFUSAL table, poison differential, `--mutate K`, `--gate-only`, `--mm-only`, `--stride-only`.
- `g2/g2_ref.c`, `g2/g2_ref.h` — the independent REFERENCE (one plain loop per operation; `g2_ref_range`/`g2_ref_readsbelow` the one statement of the read-bounded range; `g2_ref_mismatch`, `g2_ref_stride`; `--ref-defect K`).
- `g2/g2_driver.c` — driver: subjects (lengths 0..129, planted hits, near-misses, random; two (lo, floor) pairs), three layouts, census, `run_stride`, `run_mismatch`/`mm_instance`, `--witness-overread` (W3), `--mutants` (W2).
- `g2/g2_k1.c` — K1: kit `mf_ref_*` functions vs G2's loops (every length 0..129, alignment 0..15, `mf_ref_skip_blocks`).
- `g2/g2_simd_gen.c`, `g2/g2_simd.h`, `g2/g2_simd_driver.c` — SIMD family generator, site table, driver (vrun rows; denies kb/trim/pad classes).
- `run_g2_win.sh` — the WINDOW family (D172 S2 commit 1; run_g2.sh section 4w, ~25 s alone): builds `g2/g2_win_gen.c` against the kit, renders GENERATED window sites (the family is every art's since S2 commit 6), compiles the text `-Werror`, runs `g2/g2_win_run.c` plain and ASan+UBSan, W1 (`--ref-defect 2..5`), literal floors; `--plant ID` / `--plants` (the plant list: NOTES.md "run_g2_win.sh")) must each go red (a planted kit whose text no longer compiles is red too); floor `two_runs` counts the generated alternatives the F-8 refusal must refuse. Its later populations, controls and plants (S3, the S3 code review's C1, s3fix, 3.0a): NOTES.md "run_g2_win.sh". Since plan_frame.md 3.0b: a FRAMED (EMIT) ask before each render, its (frame_row, stream) cells, text classes, reply-id resolution and `table_name` population floored (plants S3084, S3089-S3093, S3096); `G2W_TRACE=1` is run_g2.sh's TRACED pass against libpcrec_mftrace.a (the kit's agreement at every window define, ~26 s, generator and plain driver).
- `g2/g2_win.h`, `g2/g2_win_gen.c`, `g2/g2_win_ref.c`, `g2/g2_win_run.c` — the window family's site description (no memfn.h), generator (its only kit caller; the lever's controls), reference (the decision from window_site.md: Table A, MARGIN, TIE, C steps; the core rule and the floor's three-way guard) and driver (DECIDE, PLAN, BIND, PROOF, COMPL; layouts U, L at s + F, and sentinel pads). Written by the family's author (not D27-blinded): its independent controls are the facts and the layouts.
- `run_g2_pres.sh`, `g2/g2_pres.h`, `g2/g2_pres_gen.c`, `g2/g2_pres_run.c` — the PRESENCE family (K38-2a, K38-2; run_g2.sh 4p): generated pre-check sites in MF_SITE_ABI 27's form (set-form run, signed omin/K, one derived run part), routes P0/P2/P3/P9, per U2 target x {default, `run-tie-left`}; reads the reply `mf_class.run` (FAM-2); C2's classifier, the §3.5 witnesses and the ORACLE RECORDS (ORC-3) piped to `tests/memfn/occurrence_oracle.py`. `--plants` S3007-S3012, S3043-S3047, S3060-S3064, `--reach`; a generic pass (`on_miss_leaves` 0). Detail: NOTES.md "The presence family".
- `check_targets.sh` — NOT G2: the kit's CPU TARGET TABLE CHECK (unit K0, R-36; its header): targets.def (facts) and targets_c.def (C spellings) through the preprocessor, held to gcc's own `-march` (floor plus needs vs `-march=<name>`, the whole `-dM` set), the structural rules, every facts field a token list (no emitter text), one C spelling per family, and the host `#if` chain to the guard column under four preprocessor targets, and (unit U2) LEVEL ADMISSION: for each host-family target and level, the table admits it iff gcc -march=<target> supplies every need (`-m<need>` adds no macro); FEATURES COMPLETE: over the check's own token->macro vocabulary, a target lists exactly what `-march=<name>` enables; `LEVELS_DEF` points it at another levels table. Run at `make` (warns), `make strict` and `make test-memfn-targets` (fail); `TARGETS_DEF` points it at another table (hand plants). Exit 0 ok, 1 mismatch, 2 could not run.
- `G2U_REPORT.md`, `G2X_REPORT.md` (interim, superseded), `G2M4_REPORT.md` (ABI 6, R-7), `G2M6_REPORT.md` (ABI 8 strided ADVANCE), `G2M7_REPORT.md` (ABI 7 MISMATCH), `G2ROWS_REPORT.md` — lane reports.
