# lib — public library API

The only header installed for embedding pcrec as a library (`pcrec.h`). Declares the FOUR public functions (`pcrec_compile`, `pcrec_output_free`, `pcrec_default_options`, `pcrec_limits_tsv`) and the options/output/error structs. Sole public interface; everything under `src/` is internal. Generated code has no runtime dependency on pcrec. Types of the generated artifacts (`rx_ctx`, `rx_matchfn`, `rx_info`, ...) live in the GENERATED .c/.h, per artifact, never here (`docs/spec/match_api.md`, `docs/design/match_api_m4.md`).

## Standing rules

- Maintenance: update this file when files are added/removed or their roles change.
- Anything a caller can observe (option, flag bit, stamp, limit, error code) changes `docs/spec/` in the SAME change (D80): `docs/spec/match_api.md` (§6 stamps, §8.2 options, §10 generated API), `docs/spec/tuning.md` (axis entries), `docs/spec/limits.md`.
- Options are GENERATION AXES (D18, compiled away), not runtime parameters. `rx_matchfn`'s signature is frozen (no budget slot); budgets are axes (engine_m4.md §4.6).
- New `pcrec_options` fields are APPENDED so no existing offset moves (memset-zero = old behaviour byte for byte). Library-struct changes are not artifact `abi` events; emitted-text changes ARE (D76/D94 ritual in the root CLAUDE.md).
- Flag bits are spelled `PCREC_BIT(n)` (`1ull << n`, `pcrec_options.flags` is `uint64_t`). Bit 31 and every bit 32..63 must be a `#define`, not an enum member (enumerator range under pedantic ISO C). `tests/registry/axes_registry_check.sh` and `tests/axes/run_axes.sh` derive bit tables by grepping this header (`NAME = PCREC_BIT(N)` or `#define NAME PCREC_BIT(N)`), hard-fail on zero bits. Successor beyond 64 bits is a word-array bitset, built when the count nears the width (D77: trigger, not timeline). Flag bits' truth is `src/core/axes.def`.
- STRATEGY-DENIAL bits (the DENY family, D47.3: `PCREC_NO_POSSESSIFY`, `_NO_REVDET`, `_NO_COUNTER`, `_NO_LENGTH_PRUNE`, `_NO_ALTCLS_MERGE`/`_FACTOR`, `_NO_VIEW_EDGE` bit 42, `_NO_START_SET` bit 47 (D148), `_NO_POSS_CTX_FOLLOW`/`_NO_POSS_BREF_FIRST` bits 50/51, `_NO_REV_END` bit 52 (D156), ...) change no answer and are MASKED out of the emitted `rx_info.flags` (mask derived from `axes.def`; `emit_info_def`'s `kept` set in `src/gen/emit_dfa.c`), so two artifacts differing only in one are byte-identical and the pass's byte-identity gate is expressible. Do-or-die is asserted by the artifact stamp (`<PREFIX>_VM_STRATS`, `_VM_RUNGS`, `_VM_PRUNE_CEILING`, `_ALTCLS_MERGES`/`_FACTORED`, `_VM_POSS_ARMS`), never by a flag-passed stamp. A denied build is the differential's ground truth; the denial must leave no trace.
- KEPT (unmasked) bits are contract/engine-selecting: `PCREC_NO_SPLICE_CALLS` (bit 13, selects an engine; the identity gate's linkage claim is subject-against-itself, so do NOT add it to the mask), `PCREC_NO_ATOMIC_DISCHARGE`, `PCREC_NO_POSS_CTX_FOLLOW`, `PCREC_FORCE_UTF_CHECK` (39) and `PCREC_FORCE_STARTPOS_ALIGN` (40) (D133, kept except under `byte`).
- [M4.6f] PREFILTER is a FORCE PAIR (`PCREC_NO_PREFILTER` bit 8, `PCREC_FORCE_PREFILTER` bit 9; `fit.prefilter` is one artifact-wide verdict, decided with `--engine`), unlike the per-quantifier deny-only bits: FORCE-on is do-or-die (refuses on a DFA-engine pattern), NO_PREFILTER never refuses; both masked from `rx_info.flags`; recorded in the SCALAR stamp `RX_VM_PREFILTER` (src/gen/emit_vm.c, `"hybrid"`/`"none"`); the DFA has its own `RX_DFA_PREFILTER` (emit_dfa.c); `RX_ENGINE` is unconditional on both engines. Tests: tests/prefilter/, tests/codegen/run_dfa_stamps.sh; mask sabotage S65.
- `PCREC_ENGINE_DFA`/`PCREC_ENGINE_VM` are `#define`s, not enum members ([ABI-NS], D60 addendum): generated artifacts emit the identical `#define`s in their `PCREC_RX_ABI_H` block, and an enum enumerator would be textually rewritten. `PCREC_ENGINE_AUTO` (0) stays an enum member. Keep the two `#define` lines byte-identical to `emit_rx_abi_types`' emission.
- `PCREC_ENC_ASCII` is renamed `PCREC_ENC_BYTE`, NO alias (D58, [SR-10]: two names for one member is the defect); encoding names come from one table, `src/enc/enc.c`; the encoding is per-`pcrec_compile()`-call state, no globals. The generated-searcher comment documents `<prefix>_next_pos` (do NOT inline `+ 1`; `match_api.md` §3.1.1).
- The `<prefix>_search` doc comment: `int` return is NOT two-valued; negative give-ups (`PCREC_ERR_STEPS`/`_FRAMES`/`_WORK` in [`PCREC_ERR_FLOOR`, -2], D49, unprefixed per D60) leave `caps` untouched; `docs/spec/match_api.md` is authoritative. The emitted `rx_matchfn` ABI comment (src/gen/emit_dfa.c) must agree. The header's "Generated searcher contract" block names the `_in` entries, `<prefix>_buffers` and sizing macros (`match_api.md` §10).
- `PCREC_ERR_UTF` (-9) is an EMITTED constant like other `PCREC_ERR_*`, not declared here. `pcrec_err_input`/`pcrec_error.input` (D42.4); `pcrec_compile()` sets `PCREC_ERR_INPUT_PATTERN`.
- Flags: `PCREC_CASELESS`, `PCREC_EMIT_MAIN`, `PCREC_NO_CAPTURES` (D42.1: captures ON by default), `PCREC_TRACE` (instrumented stderr matcher, never default, artifact stamps it).
- Limits: raise-only fields (`max_emit_code_bytes`, `max_emit_bytes`, `max_nfa_states`, `max_dfa_states_goto`, `max_subset_elems`, `max_auto_dfa_elems`; 0 = built-in default, below default refused). `PCREC_MAX_DFA_STATES_TABLE` gets NO field (`src/core/limits.def`). `pcrec_limits_tsv` is declared HERE only (moved out of internal.h; REVW.5; `docs/spec/limits.md` §3.4a); limit values are NOT also `#define`d here (D90 single home `limits.def`). `unroll_k` (`PCREC_UNROLL_K_DEFAULT` -> `PCREC_DEFAULT_UNROLL_K` in `src/core/limits.h`, decides what pcrec ACCEPTS; one value per artifact, D47 addendum); `work_budget` default lives in `src/gen/emit_vm.c` (a give-up budget accepts/rejects nothing); inclusion rule of limits.h applies both ways. `--fno-step-budget` suppresses both budget counters (D49).
- `pcrec_options.name` (appended): the artifact's NAME for `rx_info.name`; NULL means "use `prefix`" (format_design §6.3), no artifact carries a NULL name; emitted as a string literal, not a symbol.
- `pcrec_options.features` (REL-1.11): per-call feature spec; NULL = "make no request" (empty gate, D37 addendum; tests/registry relies on it), NOT the CLI's `std1` default; pass `pcrec_default_features` explicitly. Resolution is PURE (`pcrec_enabled_resolve_spec`, stored on `Ctx.enabled_features`; D19 thread-safety); `pcrec_feature_enabled`/`pcrec_ext_gate` take the mask as a parameter. The process-global `pcrec_enabled_set_spec`/`pcrec_enabled_mask` stay for the CLI query surfaces only. Contract `match_api.md` §8.2.
- `PCREC_VERSION` (D115) is a PRODUCT semver `#define`, INDEPENDENT of `abi` (`PCREC_ARTIFACT_ABI`); stamped beside the abi digit in the essential provenance line (survives `-fno-comments`, D112).
- `pcrec_options.analysis`/`analysis_dirs`/`analysis_source` ([FINDINGS] B2; `docs/spec/findings.md` §9): the library PARSES (R17), all-NULL = old behaviour; `analysis_source` is no-filesystem mode; chosen bundle NAME is stamped in the artifact.
- Part-layout controls ([ENTRY-TABLE] E1): `part_layout` (2-bit slot per class, `PCREC_PART_LAYOUT_GET`/`_SET`), `part_inline_rank` (`PCREC_PART_RANK_*`), `part_residual` (`PCREC_PART_UNSET`/`_AUTO`/`_SHARED`/`_INLINE`); class enum `PCREC_PART_PREFILTER`/`_COMPOUND`/`_FIND`/`_WRAP`; zero = unset; `tuning.md` §2.51-§2.53.
