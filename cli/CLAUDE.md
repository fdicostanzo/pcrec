# cli — command-line compiler tool

Entry point: the `pcrec` command-line tool. Parses flags, calls `pcrec_compile()` (via `lib/pcrec.h`), writes output to disk or stdout. `docs/spec/cli.md` is the contract.

## Standing rules

- Maintenance: update this file when files are added/removed or their roles change.
- Compilation goes through `lib/pcrec.h`. The SR-3 syntax queries are the one exception (they include `src/core/internal.h`; the construct registry is not public surface); `main.c` touches no registry type, it calls two functions returning finished text.
- Anything a caller can observe (flag, mode, diagnostic tier, exit code) changes `docs/spec/cli.md` in the SAME change (D80). `--help` text, `docs/spec/cli.md`, and tests/cli move together.
- ONE OPTION PARSER: `cli_parse` over `CliState`; a `.rxt` `config` block's `pcrec <raw>` line is re-parsed by this same parser (a second caller, never a second parser). `pcrec_options opt` is `CliState`'s FIRST member and `cli_extras_clean` checks the bytes PAST it are zero: that one span test refuses output paths, `--pattern`, query modes, file operands, `-h`/`--version`, `--pattern-esc` inside a config. New state that is not a compile option goes in the TAIL (e.g. `saw_prefix`, `want_help`, `want_version`); never add a per-flag-name list. `-h`/`--version` set a flag, they do not print in `cli_parse`.
- `-f`/`-fno-` grammar is ONE LOOP: `cli_axis_apply` walks `src/core/axes.def` (deny bit, spellings, default polarity). Add an axis by adding the row, not a `cli_parse` branch. The retired `-fno-req-set-lead` stays an alias in `cli_axis_apply` (maps to the kit option `no-pres-set-lead`). `-futf-check=extent` is refused BY NAME as reserved (D133).
- Mode mutual exclusion is written once: `CLI_MODE_TABLE` + `cli_modes_active` + four named masks (`CLI_MODES_VS_FILES`, `..._VS_PATTERN_QUERY`, `..._VS_EMIT_FACTS`, `CLI_MODES_REGISTRY_QUERY`). A new mode adds a table row and joins the masks; the summed-count registry-query exclusivity is a second relation (`cli_modes_count`) by ruling. `main` refuses shared conflicts, decodes `--pattern-esc` once into an arena freed after `cli_dispatch`.
- `cli_err` is the one diagnostic channel (`"pcrec: "` + message + newline, stderr, returns 1). CLI-LOCAL: the library never prints. No `where` parameter (D77). D26: do not chase wording.
- Free `st.files`/`st.libdirs` on every `main` exit that can hold them; `libdir_push` keeps `st.libdirs` NULL-TERMINATED (it IS `pcrec_options.analysis_dirs`).
- Encoding goes through `set_encoding` and the encoding REGISTRY (`src/enc/enc.h`), never string mapping here; it does NOT ask whether the encoding is implemented (`pcrec_compile()` owns that). `-e byte|utf8` and `--encoding=` reach one helper; `-e ascii` is not accepted (D58). tests/cli case13 pins it.
- `--engine` is DO-OR-DIE (refusal, never silent downgrade); `--engine=vm` also turns the DFA prefilter off (D44/R21 E-6). Explicit CLI `--engine=` beats a target's `engine` row (non-fatal stderr note; [RULEFIX]) and is the ONLY file-wins exception; "explicit" = `ts.opt.engine != PCREC_ENGINE_AUTO`, no tracking field. `--analysis` is FILL-ONLY (D123-8), not a second exception.
- DENY/FORCE test axes (`-fno-possessify`, `-fno-revdet`, `-fno-counter`, `-fno-length-prune`, `-fno-altcls-merge`, `-fno-altcls-factor`, `-fno-splice-calls`, `-fno-prefilter`/`-fprefilter`, `-fno-atomic-discharge`, ...) are testing/tuning axes (D47.3): deny-only per-selection-point, NOT in `--help`; do-or-die asserted by observability (`<PREFIX>_VM_STRATS`, `_VM_RUNGS` bits, `_VM_PRUNE_CEILING` "none"), not by a flag-passed stamp. `-fprefilter` is do-or-die (refuses on a DFA-engine pattern). `-fno-splice-calls` can change the engine a pattern gets, so it is its own flag. `--unroll=K` (1..4096) is one value per artifact. `--work-budget=N` and `--pattern-esc` DO appear in `--help` (real axis / input spelling). `--trace` is a generation axis (`PCREC_TRACE`), never default, artifact stamps it. Bit values: lib/CLAUDE.md.
- Option effects: `-i` -> `PCREC_CASELESS`, `--emit-main` -> `PCREC_EMIT_MAIN` (flags, no separate int fields); `--size-cap=refuse|degrade` sets `PCREC_SIZE_CAP_REFUSE`; `--memfn=OPTS` stores ONE opaque pointer in `opt.memfn` (kit validates; config copies via `cli_keep_string`); `--no-captures`, `--engine=dfa|vm|auto`, `--step-budget=N`, `--fno-step-budget`, `--backtrack-frames=N` are generation axes (D18 compiles options away).
- Raise-only limits are ONE table: `raise_only_limits[]` + `raise_only_match` + `parse_raise_only` (below-default is malformed). `PCREC_MAX_DFA_STATES_TABLE` has NO row on purpose (`src/core/limits.def`, `docs/spec/limits.md` §3.3). `--help` lists them beside `--max-emit-*`.
- Query/listing modes: `--emit-ir` (VM only, refuses a DFA pattern, no `-o`; TSV per `docs/spec/table_contract.md` + `docs/spec/ir_listing.md`; read it via `tests/lib/table.sh`, column width not a contract); `--emit-facts[=ENC,...]` (`src/dump/facts_dump.c`, `docs/spec/facts_listing.md`, checks `tests/codegen/run_facts_checks.sh` `[facts-cli]`); `--list-schema` (seventh registry dump, no flavour, `docs/spec/cli.md` §2); `--list-families`/`--list-axes`/`--list-limits` take no `--flavour`; `--list-definitions` takes it (`docs/spec/registry.md` §9); `--list-analyses`/`--list-analysis X` (`--view=V` modifies `--list-analysis NAME`, refused otherwise; `src/dump/findings_dump.c`).
- `--explain` exit codes: 0 answered-and-agreed, 1 could not answer, 3 a row DISSENTS. A doorway that raises `setjmp`s and prints the compile-path shape `pcrec: --explain: <diag> (pattern offset N)`; an EMPTY `err->msg` is misuse, a FILLED one a failed parse (tests/cli case12). `--probe-ask WANT CONSTRUCT` consumes two argv tokens; a doorway refusing is exit 0.
- gcc-shaped CLI (REL-1.10/D118): a positional operand is an INPUT FILE, never a pattern (`cli_operand` collects; mode decides at dispatch); `--pattern 'X'` is the literal pattern, set once, refused with a file operand; `--source` is RETIRED, no alias; `-I DIR` = `--lib-path DIR` (repeatable, order is search order; also the analysis path, legal for file/`--pattern` compile and `--list-analysis`); `--target NAME`/`--lib-path` apply to a file operand only. `compile_sources` flattens all targets into one `OwnedTarget` list before `-o`'s rule, `--target`, and the prefix-collision check (two files same prefix refused by name). `apply_target` takes `src_path` and calls `pcrec_rxt_flags_from_letters` (single-homed with definitions); `compile_*` calls `pcrec_compile_defs` (D24: no second spelling).
- `--pattern-esc`: ONE DECODER (`pcrec_rxt_decode_escaped`, `src/parse/rxt_source.c`) for it, file operands and `--list-source`; no bash decoding. `\x00` refused by name citing K9. Lives in the `CliState` tail.
- `--version` prints `pcrec <PCREC_VERSION>` (REL-1.4/D115). Part-layout controls `--part-layout=CLASS:V,..`, `--part-inline-rank=R`, `--part-residual=V` read words from `src/core/part_layout.def` (file-wins per class in config).
- `--features LIST` (MOD-0.1 slice 9) installs the set via `pcrec_enabled_set_spec`; a bare invocation also resolves via `pcrec_default_features` (`src/parse/enabled.c`, `"std1"`, D37). `-i` is ASCII case-insensitive folded at parse time (OS-1/D23).

## The harness build

`build/pcrec-harness` (`main.c` with `-DPCREC_HARNESS`; the Makefile rule's comment) adds test-only options the shipped `build/pcrec` lacks. Their spellings live ONLY in `main.c`, `tests/compound/`, `tests/memfn/run_arm_reach.sh`, `tests/memfn/site_census.py`, `tests/kitproof/` and the harness-pairing allowlist of `tests/compound/run_lever_fence.sh` (the G7 fence, which names this file as an allowed record). The options: (1) one that force-declines the compound family; (2) since R17-b' B1 (lane fdb1) one taking a measurement-set file (`harness_measures_load`: `kit.` rows with a value, `null` rows skipped; handed to the kit's `mf_art_begin` via `PcrecHarnessOptions.measures`); (3) since R17-b' B2 (lane fdb2) one setting `PcrecHarnessOptions.arm_reach`, so the kit counts each routed finder site's branch entries under a reserved counter name (R-MS6; `tests/memfn/run_arm_reach.sh` drives and reads it); (4) since [KIT-VERIFY] Z2 (lane z2build) one setting `PcrecHarnessOptions.kit_proof`, the only route to the `cover` LOCATE row before B1 (`pcrec_kit_proof_routed`; `tests/kitproof/`, C17's corpus pass and `tests/memfn/site_census.py` compile through it). New harness option: keep the lever rules (one global under `pcrec_harness_`, no lib/ header declaration, no mention outside the fence allowlist).
