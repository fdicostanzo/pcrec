# tests/codegen/manifests/k50_gate_refinement.txt — DD12a(i)'s NAMED
# GATE-REFINEMENT class ([K50], docs/dev/known_issues.md).
#
# DATED: 2026-09-06, RE-DERIVED at the [K50-NULLGATE] narrowing (the expiry
# event the first revision of this header predicted; see "HOW THIS SHRANK").
#
# Each non-comment line is a corpus pattern, VERBATIM, whose byte and utf8
# artifacts are EXCUSED from DD12a(i)'s strict byte-identity bar and held to a
# DIFFERENT bar instead: their whole remaining difference must be TABLE data —
# dimensions and cells (`diff_is_data_only` in run_encoding_checks.sh). A pair
# whose difference reaches a line of control flow still FAILS, on every row
# here.
#
# MECHANISM ([K50]). An unanchored machine under an encoding with a
# character-start restriction carries K50's boundary gate, so `eqclasses`
# refines the byte-equivalence partition by that set: a utf8 machine has one
# more class (the continuation bytes 0x80..0xBF) than its byte twin, and every
# table's width, length, stride and legend moves with it. Measured on
# `(?:a||b)`: `forward_next_state[6]` byte / `[8]` utf8. The gate NODE itself
# adds no state on these patterns — the closure absorbs it — so what the rows
# below carry is an ALPHABET change, which is DATA.
#
# EVERY ROW IS NULLABLE, AND THAT IS NOW THE MEMBERSHIP RULE RATHER THAN AN
# OBSERVATION. [K50-NULLGATE] builds the gate iff `pcrec_minw(root) == 0`,
# because a match that CONSUMES a byte already begins on a byte the backend's
# `start_cls` admits (`pcrec_startgate_needed`, src/core/internal.h, carries
# the proof). So a row appearing here that cannot match empty is a defect in
# the predicate, not a new excusal — read it before adding it.
#
# WHY THIS IS NOT A LEAK. DD12a(i)'s claim is that no encoding CONDITIONAL
# reaches the hot path (DD-12 (7)). The refinement is not a conditional: the
# emitter has no `if (enc == UTF8)`, the partition is derived from the
# backend's own `start_cls` exactly as the residual bodies are derived from
# the backend, and the resulting loop is the SAME loop over a wider alphabet.
# The caller-startpos guard and its stamp are not here at all: both are
# marker-delimited and are EXCISED and COUNTED like the residual entries.
#
# ---------------------------------------------------------------------
# HOW THIS SHRANK, AND THE DEFECT THE SHRINKING EXPOSED — 207 rows -> 13.
#
# [K50-NULLGATE] was expected to retire most rows and did: of the 207 rows the
# first revision carried, 97 named artifacts with NO DFA TABLE AT ALL and 100
# more now compile to BYTE-IDENTICAL tables. So 197 of 207 rows were in a
# class named for the boundary gate while carrying no gate.
#
# THEY WERE NEVER GATE MEMBERS. Membership was the raw `nb != nu` over the
# EXCISED text, and comments were dropped only later, in the CLASSIFICATION
# step — so a pair whose entire difference was the `next_pos` residual's own
# per-encoding explanatory PROSE ("byte encoding: one byte is one
# character..." vs "utf8 encoding: skip forward over continuation bytes...")
# was admitted and counted toward the floor of 200. That floor was asserting
# over a population that was ~95% prose: K35's shape — a population nobody
# counted — inside an instrument written to escape it.
#
# CORRECTED rather than re-pinned: `comments_only` is now the membership test,
# so this class contains only pairs that differ in something a comment strip
# does not remove. The strict bar is UNCHANGED and nothing is weakened — a
# pair that reaches equality by dropping comments has no token difference left
# for an encoding conditional to hide in.
# ---------------------------------------------------------------------
#
# DISCIPLINE: a row here is a K50 CLAIM, not a licence. The check fails if a
# row stops appearing in the corpus (stale), if a swept row stops diverging,
# or if a pair enters the class WITHOUT a row — the class cannot grow silently
# any more than it can rot. Those two guards together are an EXACT set match,
# which is what carries the load at this size; the floor below them is now a
# collapse tripwire rather than a population claim, and is set at 10 against a
# measured 14.
#
# ---------------------------------------------------------------------
# A FINDING THIS CLASS SURFACED, owed to whoever owns the stamp family.
#
# Three patterns below are marked `#UNDECLARED`. Their utf8 artifact selects
# a DIFFERENT emitted FORM on AXIS E (the accept placement: whether a state's
# accept is class-indexed), because the extra byte-equivalence class changes
# whether any state's accept varies by class — so `<m>_accepts_class` exists
# on one side only. Every other moved form in this class is admitted because
# THE ARTIFACT DECLARES IT in its own stamps; axis E cannot, because the
# `RX_DFA_*` family has no member for it. The exception list is therefore
# EXACT rather than a floor, and the honest fix is a stamp for axis E rather
# than a wider rule here.
# ---------------------------------------------------------------------
#
# THE FORM SUB-CLASS (4 pairs) is not listed separately: those rows are in the
# population below and the check counts them from the artifacts' own stamps,
# with a CEILING of 8 so a growing form population is loud.
#
# EXPIRY. This class empties only if the boundary gate stops being built for
# nullable patterns too, which would be K50 re-opening. Do not delete rows to
# go green; re-derive them from a measured run (`K50_HARVEST=file`).
#
