# tests/codegen/manifests/k50_gate_refinement.txt — DD12a(i)'s NAMED
# GATE-REFINEMENT class ([K50], docs/dev/known_issues.md).
#
# DATED: 2026-09-06, the [K50-BNDSTART] landing.
#
# Each non-comment line is a corpus pattern, VERBATIM, whose byte and utf8
# artifacts are EXCUSED from DD12a(i)'s strict byte-identity bar and held to a
# DIFFERENT bar instead: their whole remaining difference must be COMMENT or
# TABLE text (`diff_is_data_only` in run_encoding_checks.sh). A pair whose
# difference reaches a line of control flow still FAILS, on every row here.
#
# MECHANISM ([K50]). An unanchored machine under an encoding with a
# character-start restriction carries K50's boundary gate, so `eqclasses`
# refines the byte-equivalence partition by that set: a utf8 machine has one
# more class (the continuation bytes 0x80..0xBF) than its byte twin, and every
# table's width, length, stride and legend moves with it. Measured on `b|c`:
# 2 classes byte / 3 utf8, `forward_next_state[4]` / `[6]`, cells restrided.
# The gate NODE itself adds no state on these patterns — the closure absorbs
# it — so what the rows below carry is an ALPHABET change, which is DATA.
#
# WHY THIS IS NOT A LEAK. DD12a(i)'s claim is that no encoding CONDITIONAL
# reaches the hot path (DD-12 (7)). The refinement is not a conditional: the
# emitter has no `if (enc == UTF8)`, the partition is derived from the
# backend's own `start_cls` exactly as the residual bodies are derived from
# the backend, and the resulting loop is the SAME loop over a wider alphabet.
# The caller-startpos guard and its stamp are not here at all: both are
# marker-delimited and are EXCISED and COUNTED like the residual entries.
#
# DISCIPLINE: a row here is a K50 CLAIM, not a licence. The check fails if a
# row stops appearing in the corpus (stale), if a swept row stops diverging,
# or if a pair enters the class WITHOUT a row — the class cannot grow silently
# any more than it can rot. The population is floored at 200.
#
# EXPIRY — [K50-NULLGATE]. That row narrows the gate to patterns that can
# match EMPTY at a mid-character position, which are the only ones that can
# ANSWER there. Every NON-NULLABLE machine then loses the gate, its alphabet
# stops being refined, and it RETURNS to the strict bucket. **The manifest
# shrinking to the genuinely-nullable set IS the expiry event**: these rows go
# stale, this check fails loudly, and the correct response is to re-derive the
# rows from a measured run — never to widen the class or delete rows to go
# green. Nearly every row below is expected to leave.
#
# ---------------------------------------------------------------------
# A FINDING THIS CLASS SURFACED, owed to whoever owns the stamp family.
#
# Three patterns below are marked `#UNDECLARED`. Their utf8 artifact selects
# a DIFFERENT emitted FORM on AXIS E (the accept placement: whether a state's
# accept is class-indexed), because the extra byte-equivalence class changes
# whether any state's accept varies by class — so `<m>_accepts_class` exists
# on one side only. Every other moved form in this class is admitted because
# THE ARTIFACT DECLARES IT in its own stamps; axis E cannot, because the
# `RX_DFA_*` family has no member for it. The exception list is therefore
# EXACT rather than a floor, and the honest fix is a stamp for axis E rather
# than a wider rule here.
# ---------------------------------------------------------------------
