# tests/possessify/patterns.txt — the differential's pattern population.
#
# Built as §2.4's family: PREFIX x BODY x COUNT x FOLLOW, with every count
# spelled BOTH ways. The both-ways part is not decoration and it is not
# optional — [R24 S-F1] found the lazy defect precisely because the design
# lane's own probe could not express a lazy row, so its differential silently
# covered half the question. §5.3 makes greedy-AND-lazy MANDATORY for exactly
# this reason: a sweep that spells every shape greedy is structurally
# incapable of exercising the lazy conjunct.
#
# The follows include `b`, `ab` and `bc` — follows beginning with a BODY'S
# SECOND BYTE. The design's v1 family had no such follow, which is why the
# `(?:ab|a)` family passed a differential that could not ask the question it
# existed to ask (§2.4's "one thing v1 got right by accident"). They are here
# so this sweep does not repeat that.
#
# Prefixes carry `z`, a character no body contains, because D47.6's whole
# lesson is that a sweep whose subjects omit a pattern character measures
# nothing about the patterns using it. run_possdiff.sh derives its subject
# alphabet from each pattern's own text so this stays true by construction.

# ---- ENCLOSING LOOPS: the transitive-FOLLOW line ([R24 H1], 42,336 pairs) -
# The inner quantifier's follow must include FIRST of every enclosing loop's
# body, because the enclosing loop can start another iteration once the inner
# one's parent finishes. Dropping that term yielded 172 counterexamples on the
# panel's instrument, so these cells are where a regression of it would show.

# ---- the ENCLOSING-LOOP term's own discriminating shape -------------------
# The block above is NOT enough, and finding that out is the reason these
# exist. Dropping the enclosing-FIRST term (sabotage S45..S49's S48) left the
# first version of this file entirely GREEN — because in `(?:a{0,2}b)+c` the
# inner quantifier is followed by a NON-NULLABLE `b`, so the enclosing loop's
# first set is not actually reachable at the inner loop's exit and the term is
# merely conservative there.
#
# The shape where the term is LOAD-BEARING puts the inner quantifier at the
# END of the enclosing body (or behind a nullable tail), so control really can
# arrive at the enclosing loop's next iteration with the inner loop's own
# first byte available. Found by generated search: 7,553 patterns in an
# 18,480-pattern nested family change verdict without the term, and 44 of
# 1,259 sampled produce a WRONG SPAN. `(?:a{1,2}){2,2}b` is the smallest.

(?:a{1,2}){2,2}
