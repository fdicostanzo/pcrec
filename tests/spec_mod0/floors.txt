# tests/spec_mod0/floors.txt — ratcheting population floors.
#
# One line per population bucket: "<bucket> <minimum>". A check fails if a
# bucket's count drops below its floor, AND fails if it reports a bucket with
# no line here. Unpinned is unchecked: an empty population prints the same
# "0 disagreements" as a full one, so the count is what makes a PASS mean
# anything.
#

# floor when a sweep legitimately grows; lowering one is a claim that the
# suite should compare less, and belongs in review with a reason.
#
