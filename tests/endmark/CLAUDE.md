# tests/endmark — D164 B3's answer net and differential

D164 B3 (the match-end mark on `rev-end`, `docs/design/endmark.md` §R; lane
b3build). The `.rxt` file states SEMANTICS, so it was green on the tree before
the build (§R.6.2 item 1, the `rev2corp` precedent); the forms are the build's.

## Files

- **b3_rows.rxt** — one block per row and class of the `rev-end-form` table:
  F1 `one-seed`, F2 `tagged` (`mark_prio` const0 / const1 / state-dependent),
  the S2 class-dependent tie `(?:\Bx\n|x)$`, the S3 distance-set merges
  (`\n{1,4}$`, `\n\n?$`), the S5 unmarked arms (`ab\z|b\Z`, `\d+$|\w+\z`,
  `\s*$|x\z`), F3 `two-seed` (`(?:a|b\n)+$`, `a\n$`, `(?:\n\n|a){0,4}$`),
  near-cap families, hybrids (captures) and S8's held cases (find-all `mc`
  lines, startpos, `\Z` = `$`, `\z`, `(?m)$`, utf8). GENERATED by
  `gen_b3_rows.py`; do not hand-edit. Every block is `# pcre2-only`. Rides
  `make test-corpus`.
- **gen_b3_rows.py** — the case table and writer, oracle first:
  `python3 -I gen_b3_rows.py ORACLE_BIN SCRATCH > b3_rows.rxt`, ORACLE_BIN
  being `tests/fuzz/pcre2_oracle.c` built against libpcre2-8 (`gcc -O2 -o
  ORACLE tests/fuzz/pcre2_oracle.c -lpcre2-8`). Re-check the written file with
  `tests/revend/verify_stage2.py ORACLE_BIN SCRATCH tests/endmark/b3_rows.rxt`
  (shares no code with the table; the `mc` counts are the generator's own
  find-all loop over the oracle, match_api.md §3.1.3).
- **b3diff.py** — the BUILT compiler against libpcre2 10.46 (§R.6.2: the
  twins' differentials re-run against the built compiler): every pattern of a
  pattern file, every arm (a pcrec flag set), every subject up to `--len` over
  a small alphabet, every start position, group spans included.
  `python3 -I b3diff.py build/pcrec PATFILE SCRATCH [--len N] [--arms "A|B"]`.
  Not a `make test` section: a lane and review instrument.
- **b3_population.tsv** — the population b3diff and the mover census read:
  the 266 rev-end `$`/`\Z` artifacts of the b3rev census at `e8ca1252`
  (`docs/design/endmark/b3rev/results/census.json`), one row per distinct
  (pattern, encoding) with the census's form row and first id.
- **run_b3_checks.sh** — `make test-endmark` (mech arm `endmark`): §1 the
  answer net under three arms (default, `-fno-anchored-dfa`,
  `-fno-rev-end-onewalk`); §2 the per-form witnesses (`--emit-facts`
  `end_mark`'s `form=`/`prio=`); §3 the probe census against
  `b3_census.tsv` with literal population floors per form and `mark_prio`
  value; §4 gates G1-G4 per artifact (§R.6.2, D164 add. 4) with the NAMED
  exemption list and its own floor; §5 the declines under reference builds
  (`-DPCREC_MARK_PRIO_MAX_STATES=2`: state-dependent; `-DPCREC_ANCHORED_MAX_STATES=3`:
  form overflow), each answering.
- **gen_b3_census.py** / **b3_census.tsv** — the 266-row probe census
  (`docs/design/endmark/b3rev/results/census.json`) as the form and
  `mark_prio` each artifact must take; §3 reads it.
- **mover_census.py** — which corpus artifacts move between a reference pcrec
  and this build (byte + utf8, auto + vm), and whether that is EXACTLY the
  rev-end population by form (§R.7.3). Build the reference with the SAME abi
  digit. A lane and review instrument, not a section.
