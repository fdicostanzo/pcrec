## Notes

- Compile time is excluded from every measurement (pcrec pays it at build
  time by design; PCRE2 JIT pays it once before the timed loop; see README.md).
- Iteration counts are auto-scaled per engine so each timed measurement
  accumulates at least 0.3s of wall time.
- Every timed invocation is pinned (taskset -c 2) and repeated `BENCH_TRIALS`
  (5) times with the engine order rotated per trial (trial i starts
  at engine index i mod N, wraps around) so no one engine is always first;
  reported values are the median, spread is that trial set's max/min ratio.
- INVALID cases were NOT timed (agreement check ran, timing did not).
- UNVERIFIED case detail (no oracle -- pcre2-interp or python-re -- returned
  a verdict within RUN_TIMEOUT, so pcrec's own result could not be
  cross-checked; it is still reported, standalone, below):
  - case e: pcre2-interp baseline did not return a verdict within 90s (rc=dnf) -- reported as DNF/error below, not timed, not treated as a disagreement; python-re baseline did not return a verdict within 90s (rc=dnf) -- reported as DNF/error below, not timed, not treated as a disagreement; no oracle (pcre2-interp or python-re) returned a verdict within 90s -- agreement UNVERIFIED, pcrec's own result reported standalone
- See tests/bench/compare/README.md for full methodology and fairness notes.
