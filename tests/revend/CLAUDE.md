# tests/revend — [OPT-REVEND] stage 2's correctness corpus

Capture-bearing END-PINNED patterns (`$`, `\Z`, `\z`, no `(?m)`), with matching
and non-matching subjects, written BEFORE the L1/L2 build whose stage 2 (a
reverse-seeded locator plus a VM finisher that places the groups,
`docs/design/locate_finish.md` §4.3) it will be verified against. It describes
semantics main already implements, so it passes today; the report is
`docs/dev/lanes/rev2corp_report.md`.

## Files

- **stage2_captures.rxt** — 119 blocks, 647 m/n/ms/ns cells, 645 `g` slots.
  GENERATED by `gen_stage2.py`; do not hand-edit (regenerate and re-run the
  verifier). Every block is `# pcre2-only`: python `re` is not an oracle here
  (its `\Z` is PCRE2's `\z`).
- **gen_stage2.py** — the case table (one `add(C(...))` per block, the family
  letter and the risk it stresses in each comment) and the writer. Usage:
  `python3 -I gen_stage2.py ORACLE_BIN SCRATCH > stage2_captures.rxt`, where
  ORACLE_BIN is `tests/fuzz/pcre2_oracle.c` built against libpcre2-8. It asks the
  oracle for every span and group; `flags i` / `flags u` / `encoding utf8`
  become `(?i)` / `(*UCP)` / `(*UTF)` pattern prefixes (the oracle compiles at
  options=0).
- **verify_stage2.py** — re-reads the WRITTEN .rxt with its own parser and
  re-asks the oracle for every cell and every group slot; shares no code with
  the generator. Exit 1 on any disagreement.

## Running

    bash tests/harness/run.sh tests/revend/stage2_captures.rxt              # default engine
    RXTFLAGS=--engine=vm bash tests/harness/run.sh tests/revend/stage2_captures.rxt
    python3 -I tests/revend/verify_stage2.py ORACLE_BIN SCRATCH

`--engine=dfa` refuses every block (captures are on); with `RXTFLAGS="--engine=dfa
--no-captures"` the whole-match cells of every pattern the DFA accepts agree
(only the `g` slots, and the lookbehind and `\K` blocks, which require the VM,
cannot run). The file rides `make test-corpus`; its counts are pinned in
`tests/rxtsource/run_rxtsource_tests.sh` (CENSUS_*, RUNSH_*, C3_SKIP*).
