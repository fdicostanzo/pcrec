# tests/startset/ — [START-SET]'s checks (D148; `make test-startset`)

The start-set mechanism (`docs/design/startset.md`) is built in stages (§8).
This directory holds its checks; the fixtures (`vmhat.rxt`, `dfahat.rxt`, …)
join at the stage that builds each hat (§6.4.4). Stage 2 (the VM hat, lane
ssbuild2, 2026-10-05) and stage 3 (the DFA hat, lane ssbuild3, 2026-10-06)
added their fixtures and checks (below); `make test-startset` runs the three
scripts, any failing fails the section.

- `run_startset_checks.sh` + `startset_checks.py` — stage 1, the `start_set`
  FACT's checks, in `make test` as `make test-startset` (~20 s) and on the
  mech arm `startset`. All three read the SHIPPED fact (the `--emit-facts`
  row), never a probe (review r4 checks-F2):
  - **[ss-ctrl] C-SS\***: on every corpus block whose artifact carries a
    forward DFA (DFA or VM hybrid), seeded included, the emitted start bytes
    (`Tdfa` on a seeded machine, the emitted `can_begin_match` on an
    unseeded one) are a subset of the fact wherever it is necessary.
    Independent of the walk (the subset construction's tables); the failing
    direction is a WALK plant (S501, S502). It cannot see a too-small `T`
    that still contains `Tdfa` (§6.4.3 item 2); the start-byte oracle and the
    answer cells are that detector (stages 2/3).
  - **[ss-null]** `nullable` ⇒ `start_set.nullable` on every compiled block
    (`L ⊆ L⁺`, sound-F9).
  - **[ss-flag]** hand-written witnesses: `-i`, `--ucp`, utf8 caseless, the
    conservative arms.
  Floors are half the landing population (D110), printed beside REACH lines.
- `startset_lib.py` — the shared population (corpus blocks with their own
  options, deduplicated on (text, options)), the listing parser, and the
  emitted-table reader (`E`, `E*`, `Tdfa`; ported from
  `docs/design/startset/rev2/estar.py`). The stage-1 census imports it so the
  census and the checks read one population.
- `manifests/` — the stage-2/3 MOVER MANIFESTS (checks-F5), GENERATED by
  `docs/design/startset/s1/census_s1.py` at stage 1: `manifest_s2_vm_auto.tsv`
  (V at each block's own options), `manifest_s2_vm_forced.tsv` (V under
  `--engine=vm`), `manifest_s3_dfa.tsv` (F, `T = S ⊊ E`). The stage that
  builds a hat checks its movers against its manifest (0 off-diagonal);
  regenerating the census MOVES that check, so a regeneration is a reviewed
  diff, never a refresh.
  **Regenerated at stage 2** (lane ssbuild2) when the stage-2 fixtures joined
  the corpus: +12 auto / +13 forced rows, every one a fixture block, no
  existing row moved (`docs/design/startset/s2/`). **Regenerated at stage 3**
  (lane ssbuild3) with the PRE-STAGE-3 compiler when the stage-3 fixtures
  joined: `s3_dfa` +39, `s2_vm_forced` +54/-1, `s2_vm_auto` +0, every added
  row a fixture block; the one removed row is `tests/ucp/ctxnode.rxt:400`,
  whose (text, options) twin in `dfahat.rxt` now takes its id in the dedup
  (`docs/design/startset/s3/`). **Regenerated at the ssfix3 panel fixes**
  (2026-10-06) on the CURRENT build: the census now compiles every arm with
  `-fno-start-set` (checks-m5: the deny arm is today's emitter, so no frozen
  binary is needed) and reads F as `T = S`. `s3_dfa` and `s2_vm_auto`
  byte-identical; `s2_vm_forced` +12, the `dfahat_f1.rxt` blocks.
  **Re-pinned at m7fix** (2026-10-08): s670cell (ae7cf901) added eight
  caseless-backreference blocks (`tests/backrefs/caseless.rxt:71,86`,
  `caseless_ucp.rxt:262,274,288,298,310,322`) that are correct VM-hat movers
  and were never pinned, so `[vm-movers]` read 8 unlisted on both arms.
  `census_s1.py` on the lane's build: `s2_vm_auto` +8 and `s2_vm_forced` +8,
  exactly those blocks, no existing row moved, `s3_dfa` unchanged. Only the
  corpus rows were taken: the same run against pcrec-bench bb87dfa5 also adds
  bench rows (+6 forced, +1 `s3_dfa`), which are counted, never checked, and

## Stage 2 — the VM hat (lane ssbuild2, abi 62)

- `vmhat.rxt`, `giveup.rxt` — ssedge's VM-hat edge cells moved home
  (startset.md §6.4.4): GENERATED, every answer libpcre2's (10.48 and the
  10.46 reference agree), at every character-boundary startpos. Written by
  `edge_import.py` from `docs/design/startset/edge/`'s drafts (it adds
  `features all` per block and drops the draft's head `oracle` line, which
  `verify_rxt.py` cannot read; every block is `# pcre2-only`). `giveup.rxt`
  is the Q-R3 capacity witness: the hat answers where the deny arm gives up
  (run_axes.sh GROUP F5 allows exactly those 22 keys).
- `vmhat_walk.rxt` — S499's answer witness, `(?=(a))\1b`, python-verified (a
  walk that dropped the backreference's bytes would make it a mover and lose
  its match). S500's twin, a variable, is `tests/vars/startset.rxt`.
- `edge_import.py` — the importer above; re-run after `gen_rxt.py write`.
  Takes several comma-separated drafts for one home (stage 3's
  `dfahat.rxt` gathers six).
- `run_vmhat_checks.sh` — stage 2's runner (`make test-startset`, mech arm
  `vmhat`; ~3 min on the Mac): the fixtures through the harness, then:
- `vmhat_checks.py` — over every corpus block on two arms (own options,
  `--engine=vm`), default and `-fno-start-set`: [vm-iff] the stamp names the
  emitted seek; [vm-route]/[vm-anchor]/[vm-handoff] every mover is a
  prefilter-less, unanchored, handoff-free VM artifact; [vm-deny] a
  non-mover's deny artifact is byte-identical and a mover's is identical once
  the table, two seeks and stamp value are removed; [vm-table] the table
  equals the `start_set` fact; [vm-movers] movers == the manifests BY ID
  (corpus rows; the pcrec-bench rows are counted, not checked); [vm-wit]
  hand-written witnesses. Landing: 6,946 artifact pairs, 176 auto / 2,560
  forced movers, 0 off-diagonal.
- `vmhat_diff.py` + `vmhat_driver.c` — the EVERY-STARTPOS DIFFERENTIAL and
  START-BYTE ORACLE (§6.2): each auto mover x {own options, `--engine=vm`,
  `--no-captures`}, the deny and hat artifacts linked into one TU, every
  startpos of own/sweep/random/ill-formed subjects (each in an exact-size
  heap block); answers and captures equal except a deny give-up becoming the
  hat's answer, and every non-empty deny match starting on a byte of the fact.
  `SAN=1` builds under ASan/UBSan. Landing: 528 pairs, 3,165,576 cells, 0
  defects.

## Stage 3 — the DFA hat (lane ssbuild3, abi 64)

- `dfahat.rxt`, `reseed.rxt`, `hybrid.rxt` — ssedge's DFA-hat edge cells
  moved home (startset.md §6.4.4: `dfahat.rxt` gathers the witnesses,
  lookbehind, wordb, bounds, multiline and utf8 drafts), GENERATED by
  `edge_import.py` exactly as stage 2's; every answer libpcre2's at every
  character-boundary startpos. The draft's `config`/`target`
  head lines (`hybrid.rxt`'s `-fprefilter-collapse` targets) are dropped and
  their `name` lines commented, since a head makes a file unreadable to
  `verify_rxt.py`; the count-collapsed blocks (HYC, `\B(a|b){1,3}` on "xa")
  are compiled collapsed by the differential's `collapse` config.
- `dfahat_f1.rxt` + `gen_dfahat_f1.py` — the ss3 D6 panel's BLOCKER
  sound-F1 witnesses (`(?<=\w) *a` and eleven more): a byte of `S` leaves
  every seed state where it is, so the old `T = S & E*` dropped a start byte
  and its `T == S` assertion REFUSED them at default flags. With `T = S` the
  admission declines and the artifact is the deny arm's. GENERATED (libpcre2,
  every startpos; byte-tier blocks python-verified too). Every block must
  compile (the harness), equal the deny arm byte for byte ([dfa-deny]) and
  answer as libpcre2 does; the pre-fix compiler fails all 322 cases.
- `compile_fuzz.py` — the COMPILE-ONLY arm (the panel's lesson: an answer
  differential cannot see a pattern that no longer compiles): 9,000
  generated seeded patterns (a fixed seed; 30% from an F1-shaped template),
  each `-fno-start-set` compile must be matched by a default compile, and an
  internal error on either arm fails; floors on the deny-compiling
  population and on the DFA-hat reach. On the pre-fix compiler it reads 70
  hits (4 in 9,000 with `TEMPLATE=0`, the critic's grammar); ~25 s.
- `dfahat_paths.rxt` — hand-written, python-verified: the SET form's
  clamp-path witness `\B(?<!a)[de]` on "xd" (S483) and S488's nullable-S
  seeded skip `\b\B|\b(?:ab|cd)`.
- `run_dfahat_checks.sh` — stage 3's runner (`make test-startset`; ~6 min on
  the Mac), in two parts (the ss3 D6 panel's checks-M1), `DFAHAT_PART=answers`
  (mech arm `dfahat`: the five fixture files through the harness, as written
  and again under `RXTFLAGS=-fprefilter-collapse` for the count-collapsed
  hybrids' oracle answers, checks-M4, then the differential) and
  `DFAHAT_PART=struct` (mech arm `dfahatstruct`: `dfahat_checks.py` and
  `compile_fuzz.py`), `all` by default:
- `dfahat_checks.py` — over every corpus block at its own options, default
  and `-fno-start-set`: [dfa-iff] the stamp names the emitted skip, table and
  conditional re-seed; [dfa-route] every mover is the unanchored scan of a
  seeded machine; [dfa-reseed] the re-seed is conditional; [dfa-table] the
  scanned set EQUALS the `start_set` fact and is a PROPER subset of the deny
  arm's `can_begin_match`; [dfa-deny] non-movers byte-identical, movers
  identical outside the hat, a mover in one of three named cross-row classes
  (G1's `REQ_WHY`, the hybrid `VM_RESEED`, `DFA_SCAN_EDGE`) re-compiled with
  those rows denied on both arms, the classes counted; a VM-hat
  mover is left to `vmhat_checks.py`; [dfa-movers] movers == the manifest by
  ID; [dfa-wit] witnesses, including the hybrid re-seed row read over `T`
  (S495's answer-side detector); [dfa-refuse] (ssfix3, checks-m1) no block
  refuses or times out at default while the deny arm compiles it; [dfa-bot]
  (sound-F2's sentinel) a start-of-subject or `\G` read takes the attempt
  scan. The class re-compare asserts the hat is still selected (checks-m2).
  Landing: 3,528 artifact pairs, 71 movers, 0 off-diagonal (3,540 with
  `dfahat_f1.rxt`).
- `vmhat_diff.py` under `HAT=dfa` — the same EVERY-STARTPOS DIFFERENTIAL and
  START-BYTE ORACLE over `manifest_s3_dfa.tsv`'s corpus movers x {own options,
  `--no-captures`, `-fprefilter-collapse`, and `-futf-check` on a utf8 mover},
  the sweep alphabet carrying two bytes of the deny arm's `E` outside `S` (the
  bytes that move the context the re-seed restores). Landing: 219 pairs, 1,155,139 cells, 0 defects.
  **ssfix3 (checks-M4/M5/m1)**: a pair byte-identical to its mover's `auto`
  pair is run once and counted once; the context bytes are ADDED to the
  alphabet (the outside byte and the pattern's literals are kept); the pairs
  that saw a match and (DFA) the count-collapsed pairs are floored; a hat
  refusal where the deny arm compiles is a FAIL. At the fixes: DFA 153
  distinct pairs (5 collapsed, 151 matching), 1,920,044 cells; VM 423
  distinct pairs (382 matching), 2,486,254 cells; 0 defects.
