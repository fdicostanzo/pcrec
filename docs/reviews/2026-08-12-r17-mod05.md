## ENGINE critic — one tier-2 divergence, fixed; five clean sweeps recorded

**Bare `(?` at end of pattern answered "unrecognized character" (the 111
family) where PCRE2 gives error 114** — and the panel's measurement
SHARPENED the finding: `(`, `(?`, `(?i`, `(?^`, `(?-` are ALL 114, so
PCRE2's answer for `(?` is the generic UNCLOSED GROUP, the same error bare
`(` gets — which pcrec already answered correctly ("missing closing ) for
group"). Root cause: c2 == -1 aliases REG_SEL_ANY, landing on the
catch-all's fixed message; the Q2-era comment called the aliasing harmless
("same diagnostic either way") and the Q2-era reject pin's prose claimed
PCRE2 agreement — measured false. FIXED in ext.c (c2 < 0 answers in the
bare-`(` family, both gate states); the pin moved with its third
measured answer in three eras, history in its comment. The probes missed it
for the R16 reason: registry_check's `(?%c` template structurally cannot
generate the zero-byte case.

Clean sweeps recorded as evidence (all cells agreed both sides): xx
deletion vs first-position-`]` (incl. negated + raw-tab control); nested
`:`-scopes with opposite settings and cross-letter nesting; `(?^)` inside
scopes it did not create; `n` vs CAPTURECOUNT (4 cells incl. scoped
re-enable); `[(?i)]` as a literal class.

NOTED, pre-existing, outside this milestone: the base K12
