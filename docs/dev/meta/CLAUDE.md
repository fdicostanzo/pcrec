# docs/dev/meta — the sidecar: what we learn about developing WITH models

A side project riding pcrec (Frank, 2026-09-20): pcrec is also an experiment
in whether a Fable manager directing sonnet/opus lanes scales past the point
where a single Opus session lost track. This directory keeps the LEARNINGS
that transfer to other projects — what helps, what measures it, what to try
next — separate from pcrec's own process docs (which say what to do here).

- `ai_dev_learnings.md` — the living record: findings with their evidence,
  instruments that worked, ideas for future tests. Append; date entries;
  cite the pcrec artifact that measured each claim.

Rules: a claim here names its measurement or is marked OPINION; pcrec-only
process (wake.md ritual, lane briefs) stays in `docs/dev/lanes/BOILERPLATE.md`
and the memory files — this directory is for what would be true on the next
project too.
