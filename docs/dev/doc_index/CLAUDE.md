# docs/dev/doc_index — owner tables for the index + details split ([DOC-INDEX])

Design: docs/design/doc_index_format.md §2.2, §5.2; appendix A (census) and B (owner table, plants, witnesses).

## Files

- `decisions_owners.tsv` — the decisions ADDENDUM OWNER TABLE: one row per addendum marker of docs/dev/decisions.md (appendix B's columns: extent `old_line..old_end` + `extent_hash`, full `old_label`, `class`, `owner` + `owner_src` label/enclosure/ruled, `old_number`, `new_id` `Dn.aN`, `date`, `who`, `title`, `cites`, `note`). GENERATED by `python3 -I scripts/doc_census.py --emit`; never hand-edited. `--check` (tests/doc_lint/run_doc_index.sh) fails when it disagrees with a fresh census. The unit 1 converter copies rows; `scripts/doc_control.py` checks a conversion against it.
- `decisions_owner_rulings.tsv` — the HAND RULINGS the census reads: every id-less marker's owner (with a one-line reason citing its evidence), plus ruled overrides (`number`, `old_end` as `lines:N`, `title`, `date`). Keyed by host entry + exact old label. An unused ruling fails `--check`.

## Rules

- Line numbers here (`old_line`) are a migration record, exempt from C8 (appendix E).
- A landing re-run re-emits on HEAD: unchanged markers keep their rows; a new id-less marker stops for a ruling.
