# guide addenda

One file per module or area (`kit.md` for `memfn/`). Each adds to the base
guide (`../README.md`, `../coding.md`, `../architecture.md`, `../style.md`) and
never contradicts it; a conflict goes to the manager. Same amendment rule as
the base: every rule carries its WHY and a source. Point at the area's own
`CLAUDE.md` rather than restating it.
