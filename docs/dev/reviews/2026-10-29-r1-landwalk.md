## Findings (verifier status in brackets)

### Answer tier

- **A1 The UNIQUE rule and its sufficient forms** (PREMISE-1, SIM-1, SIM-2) [verify §1, §2 HOLD].
  Three facts, all true at once:
  - the rule as worded ("no accepting state of rev(P) is reachable from another accepting state")
    REJECTS dup-param's `\b\w+`: its by-class accepting state self-loops on `\w` (`build/pcrec -p rw
    --pattern '\b\w+='` tables). So the stage-2 headline mover would decline;
  - the syntactic form "`\b` with P's alphabet ⊆ `\w`" ADMITS nullable P and is wrong:
    `\b(\w*)=x\1` on `ab=x`, libpcre2 (2,4), per-hit attempt at s*=0 NOMATCH (fuzz: 178 wrong /
    9,520 for nullable P; 0 / 42,040 non-nullable);
  - positional accepts (`^`, `\A`, `\G`) are not covered by "by-class accepts": `(?:^|-)([\w-]+)=\1\b`
    on `ab-cd=cd`, libpcre2 (2,8), per-hit NOMATCH.
  The census used the forms, so it counts neither the rule nor the truth.
  **PROPOSED: FIX-NOW.** Restate UNIQUE over (state, class) pairs, with the floor/positional accept
  counted as a `c = none` pair (the verifier checked it accepts dup-param and rejects both witnesses);
  drop the syntactic forms or label them as approximations the rule must reproduce; say whether a
  BOT-family P declines (a named row) or builds a floor accept; add the three witnesses to stage 2's
  answer net. Answer-relevant only on the VM hat (S reads P's groups), so stage 1 is not at risk.

- **A2 Two DFA-hat hand-offs have no row in the table as it stands** (SLOT-1, SLOT-4) [verify §3, §4
  HOLD].
  - The reach guard hands LOWER to FIN4 `search-from`, but on `CAND_ROUTE_DFA` its take cells are
    `{AT, ENDSET}` only (emit_dfa.c:10611-10624); no FINISH row takes LOWER on the DFA route.
  - With the anchored machine A not built (cap, or `-fno-anchored-dfa`), `verify-at` is unavailable
    (`finish_available`, emit_dfa.c:9420) and an AT hand follows `search-from`'s LOCATE ask back to
    the SELECTED LOCATE row, i.e. `landmark-walk` itself: a run-time cycle the static closure does

  **PROPOSED: FIX-NOW.** Add an `anchored-A built` admission row (the `cover_conj[]` C4 precedent);

## Lessons for the guide (proposed)
1. **A rule stated over states must be checked on a machine with by-class accepts.** A by-class
   accept and the step that continues read the same byte; a state-level reachability rule cannot see
   that they exclude each other. Read the emitted tables of the design's own witness (PREMISE-1).
2. **A design's sufficient syntactic forms are a second statement of its rule, and they drift.** The
   census counted the forms, so the population measured neither the rule nor the truth (A1). A
   simulate lens tests the forms and the rule separately.
3. **A new row that hands a NEW hand is a table walk, not a sentence.** For every hand the row
   produces, walk the take cells on each route and the path-closure branch it follows; the first
   LOCATE row to hand AT found a self-cycle (A2).
4. **A speed price needs the baseline of the selected path, not of the motivating case.** The
   motivating pattern was the only admitted row whose shipped path walked every byte (S2).
5. **Compile-time admission cannot pass a subject-dependent acceptance cell.** If the same pattern
   appears in a positive and a negative cell, the design must state the loss as a bounded non-goal
   (S3).
