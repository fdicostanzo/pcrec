# r3 (2026-10-11): D6 panel on R-17's general set-FIND row

**Under review:** `docs/dev/lanes/r17s_report.md` §3.4 (one term-list row
family in `memfn/src/pffind.c`: memchr | SWAR term-OR | today's walk), with
the step-2 timing reading `docs/design/memfn/probes/r17/reading_slot.md`.
**Panel:** three read-only sonnet critics. None ran a build; the box was held
by main's slot.
- C1: correctness and over-read.
- C2: measurement regime and density admission.
- C3: the contract against pcrec's emitters, and docs staleness.

Each critic carried the "propose unlocks" lens.
**Consolidated by:** the kit manager (pcrecdev3).

## Verdict

The DIRECTION survives: one general row, a term list derived from the set,
and memchr / SWAR / walk chosen first-match. No critic proposes per-shape
rows, and C3 confirms the row fits the kit's row, gate and deny machinery
with no parallel mechanism. **The design is NOT ready to build.** Two gaps
block it.

1. **Correctness gaps.**
   - At n = 0, `hi = n - end_back` wraps, and the check skips exactly that
     case (C1-1).
   - The term derivation, the riskiest function, has no specification and no
     test (C1-3, C1-4).
   - Kit locals can capture hook identifiers (C1-6).
2. **The rollout is mis-sequenced.**
   - Inline-SWAR-first, SIMD-after moves the SIMD-off bytes twice (C3-1).
   - The SIMD-off half is not "no pcrec change": the `<string.h>`
     prediction, stamp and spec meaning, and dead tables all move (C3-2,
     C3-3, C3-12).

The measured regime is also not yet decision-grade (C2-1..C2-4). The 300k
"loss" partly reflects `table` getting unusually cheap there; placement is
i.i.d. and was never real text; there are grid holes; and K cannot be read
off the run, because no cell has more than 3 terms.

## Proposed path

1. **Revision 2 of the design**, written as a design note,
   `docs/design/memfn/setfind.md`, by an opus lane. It answers every
   MUST-FIX and SHOULD below by id, and specifies:
   - the term derivation: candidates, objective, search, purity, and the
     uncoverable-set decline;
   - the row contracts per form;
   - the n = 0 and NOP span arithmetic;
   - the endianness spelling;
   - the hook-safe local naming;
   - the one-event rollout (routing + row) and the pcrec-side facts it needs;
   - the density gate field;
   - the G2 family and the kernel test;
   - the sabotage rows (more ids than S820-S824).
2. **A follow-up measurement** in a slot, before any build:
   - the intermediate ppm grid (100k-600k), with 1M at the dense points;
   - dense per-call (the Q-R5 regime);
   - clustered-run placement;
   - the real bench subjects for `lc`/`dig`/`bkn`/`bpr` with their measured
     ppm and run profile;
   - synthetic 4/5/6/8-term cells;
   - branch-miss counters for `table` and `swar` at 70k/300k/800k;
   - a stated noise band.
3. **A light re-check panel** on revision 2. The build comes only after a
   measured win in every regime the row admits (K-1, D147).
4. **Questions to Frank via main**: Q-R17-1 and Q-R17-2 below.

## Questions for Frank (via main)

**Q-R17-1: how the row decides density.**
- Every form wins by a wide margin from 0 to 70k ppm, and loses up to 24%
  at 300k i.i.d. on the bench's dense controls. The kit has no density fact
  today.
- C2 and C3 converge: no shape-based proxy (width is not density), and no
  run-time adaptive form (no measured need).
- The row admits only on POSITIVE density evidence. A density gate field
  carries the `ppm` facts, unknown declines to today's walk, and the
  threshold is labelled UNMEASURED until the grid fixes both edges.
- **Consequence:** the row is inert until pcrec fills N1, R-17's promised
  `cand_ppm`/`ppm` facts.
- **Recommendation:** accept that. N1 becomes the build trigger, and main
  schedules its no-mover fill ahead of the build.
- **Alternative:** admit sparse-only sites now on some static proof. No
  critic found a sound one.

**Q-R17-2: one routing event for every PF site.**
- To avoid a second SIMD-off move, the first event routes PF/MLINE
  statements through a one-call selector (R4e′.0b's shape) and adds the term
  row. N2, pcrec accepting file-scope text for a STMT site, is therefore
  needed in that first event.
- Cost: every PF site moves at once (772+ corpus sites), as one abi event.
- **Recommendation:** do it, as one event, only after the follow-up
  measurement confirms the win.
- **Alternative:** inline scalar first, accepting a second SIMD-off move
  when the SIMD half lands.

## Requests to main (pcrec side; filed as `responses.md` notices when the design is revised)

- **N1:** density facts at every R-17 site (already promised).
- **N2 as a capability:** pcrec accepts file-scope text for a STMT site,
  positioned ahead of its function. It generalizes the existing
  pending-helper flush (`pcrec_memfn_flush_helpers`), so the DFA and VM
  engines agree on placement. The VM hat's `start_set` table moves to file
  scope or is passed in (C3-6).
- **N3:**
  - pcrec asks the kit for the includes a site needs (a plan-time fact
    query), instead of `need_string_h` predicting the kit's calls (C3-2);
  - pcrec emits a table only when the chosen row reads it (a result fact or
    a define-then-emit order) (C3-3);
  - pcrec describes every FIND uniformly: set, optional table fact, empty
    and guard facts (C3-12).
- **N4:** in trace/test builds, a door assertion that `mf_term.set` equals
  the table bytes (C1-13).
- **Spec (D80):** `RX_DFA_PREFILTER "byte-class"` / `"first-class-bounded"`
  and `RX_VM_START_SCAN "first-class"` are redefined method-blind, or a form
  stamp is added (C3-3).
- **Request text:** R-17's Facts name shape classes ("ONE CUBE", "ONE
  RANGE") and an OFS/PRE population that is 0. Main may restate them as sets
  (members, count) (C3-13, D157). The VM hat caller is `emit_dfa.c` ~7200,
  not 7111.

## Unlocks (filed, not built; each with a trigger)

- **One kit primitive `mf_set_terms(set, K)`** owns derivation for every
  row and SIMD level. Trigger: build time, since it avoids a fourth copy.
- **An exact-lane term renderer** gives first-non-member SKIP for
  STAY/EDGE/VMSPAN complements (`[^"]*`). Trigger: a measured stay-loop
  loss with ≤ K exit terms. Caveat: in-loop spans are short.
- **Exact masks give COUNT** via popcount for counted edges. Trigger: a
  measured counted-edge loss.
- **A term-based vrun filter position** (KA/KB as a class). Trigger: a
  ranked class position with a measured loss.
- **An ofsskip BODY set row** (`offset-set`). Trigger: pcrec re-prices
  prefix_k (F-1), with ci-moskva as the witness.
- **N4 SETREST over SET terms.** Trigger: a set-rest cell in a loss table.
- **`$_valid_upto`'s ASCII skip** shares the one-range term. Trigger:
  R-12's pending listing (Q-R12-5).
- **A reverse scan (clz) for REVEND/rev-inner set landmarks.** Trigger: the
  first rev-inner row with a set landmark.
- **The density gate as a shared fact** for `[START-DENSE]` and the
  stay-loop admission. Trigger: N1 filled.
