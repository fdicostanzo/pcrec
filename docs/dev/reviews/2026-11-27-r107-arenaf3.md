## Lessons for the guide (proposed)

1. A sabotage plant that MOVES an object back to an old shape must also restore the old shape's own release (or
   its absence), or it adds a second effect (here a success-path leak) that a broader net catches; the "single
   control" claim is then false for the plant. Proposed sentence for docs/dev/guide/critics.md "Lessons" and the
   check-adequacy row: "for a re-aimed plant, build the FAITHFUL old shape (every edit of the pre-change code at the
   site) and run it through every net, not only the row's own; an exact allocation-count pin is a net too."
2. A comment copied from a sibling client carries that sibling's routes; the lifetime lens should grep every caller
   of each new scope's function and check every route the comment names.
