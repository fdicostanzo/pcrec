## Lessons for the guide (proposed)

1. **A rewrite upstream of a choice reader needs a per-reader speed probe, not a census.** The design listed "the VM
   island census" as a 2b mover and cited the earlier altcls/island collision, but predicted no direction; program
   bytes FELL (w-256 143 KB -> 110 KB) while matching work rose ~130x. Size views read the loss as a win. Proposed
   critics.md line: for every predicted "census mover" of a choice the subject does not own, the build states one
   instruction-count pair on the bench family that reader serves.
2. **A new rung in an ordered retry ladder states its cost and is placed by it.** The ladder's own order rule was
   by measured cost; the new row carried none and went first (EMIT-2).
3. **The D94 bump grep matches the bare number in every `*_ABI_*` line**, not "abi N" prose (CON-1, a second miss in
   the same file as the 2026-09-01 one).
