## Findings with PROPOSED dispositions

### Answer level (the design would miscompile if built as written)

**F1 — `\G` in a lookbehind branch is admitted to `exist`/`gate` and answers wrongly for both polarities.**
SOUND-1 = SLOT-5. Verify item 1: HOLDS.
- **Why `\G` gets through.** `A_GSTART` sets no `Nfa.erased` bit (kindrow.def:64, nfa.c:704). In a REVERSE machine,
  `\G` is met only after a byte has been consumed. There `gst_ok` is false (dfa.c:1027-1030, :1750-1756), so the
  path dies. The machine is a SUBSET of the branch's language, not a superset.
- **Wrong answers.** Oracle: `(?<=\Ga{1,2})b` on `aab` gives (2,3), and `(?<!\Ga{1,2})b` gives nomatch. Row `exist`
  ("no") would give nomatch and (2,3). Row `gate` ("no accept is decided") gives the same wrong pair. §3.1's "a
  superset machine's NO accept is always sound" does not apply, because the machine is not a superset.
- **Why no current walk hits this.** Today `pcrec_nfa_has_bot` (nfa.c:1342-1351) routes `\G` away from every
  reverse machine. The landmark walk screens it explicitly (lmwalk.c:181, `lc_g1`). A per-branch lookbehind
  machine bypasses both screens.
- **PROPOSED FIX-NOW** (design text, rev 1). The whole `reverse-dfa` admission (rows 1 and 2) gains the existing
  predicate as a conjunct: `!pcrec_nfa_has_bot(branch NFA)`, or `lc_g1`'s shape. Witnesses: both polarities of
  `(?<=\Ga{1,2})b` on `aab` from offsets 0, 1 and 2, with the `caab` cells as controls.

**F2 — a `^`, `\A` or `(?m)^` in a branch turns the reverse build into an "internal error" compile REFUSAL, not
a decline.** SOUND-2. Verify item 2: HOLDS, as a design hazard that is unreachable on main today.
- **The path.** The build hits `DFA_INVARIANT` (dfa.c:1583-1586), which calls `pcrec_ctx_fail`, which longjmps.
  `revend_build_one` (compile.c:454-466) catches overflow only.
- **What it breaks.** §2.4 says "an overflow is the row's decline, never a refusal". This failure is not an
  overflow, so that sentence does not cover it. Rev 1's own §2 cell `(?<=^a{0,2})x` is one such pattern.
- **PROPOSED FIX-NOW.** F1's conjunct covers this, but only if it is tested BEFORE the build. State that order.

**F3 — §3.1 row 1's hand "yes / no, the answer for either polarity" gives one BRANCH's answer, not the
lookbehind's.** SOUND-3. Verify item 3: HOLDS.
- Oracle: `(?<!a{1,2}|b)x` on `bx` gives nomatch, and `(?<=a{1,2}|b)x` on `bx` gives (1,2). Row 1 read literally
  flips both.
- **PROPOSED FIX-NOW** (wording): "yes: decided (positive holds, negative fails); no: this branch fails, the next
  branch starts from the cursor".

**F4 — "built `exact`" is not a recorded fact, and the exactness `exist` needs is three conjuncts, not one.**
SOUND-4 + SEAM-9 (build-request part). Verify item 4: HOLDS. No live answer bug.
- **What is recorded today.** The only recorded fact is `Nfa.erased`. A collapse already sets `NFA_ERASED_COUNT`.
  The value of `prune` changes a DFA's language (dfa.c:979-987), and no build request names it. Every reverse
  build passes `false` today.
- **A word clash.** `RX_VM_PREFILTER_LANG` (emit_vm.c:11307-11311) already stamps "exact" for atomic-erased and
  lookaround-erased machines. A lane reading arev's "exact" in that sense would admit WD1's machine.
- **PROPOSED FIX-NOW.** §2.1/§2.4 name ONE entry fact that is read after the build: `exact` = `erased == 0` and
  `!has_bot` (no `\G`/`\K`/absent-prev rows) and prune off. Drop "built exact" as a request. Use a word that does
  not clash with the stamp, or cite F-13.

### Record design (seam, slots, F2)

**F14 — the record carries C text.** OWNER-1 + SEAM-3 + SEAM-4 + SEAM-11 + SEAM-12.
- **What is C text.** `seed`, `floor`, `dead` and `names` are C fragments (`continue;`, `search_from`,
  `slot_values[...]`, variable names). S1 moves those strings into the record. The manifesto's F2 falsifier names
  exactly this: "a record still carries target text". §2.1's "the record is the seam document of principle 9" is
  false as written.
- **`dead`.** It merges two hands, the dead entry and no accept. Its W1 cell is wrong: no accept is `return 0;`.
- **`names`.** It is two stems. Table stems belong to a machine × direction and are shared, and the relocate reuses
  them. Label stems belong to a walk.
- **Hands flowing back.** These are consumer conventions: the distance bit set and its tie via popcount, the
  empty-at-n probe, and `lmwalk_reach`, which the finisher writes and the next walk reads.
- **PROPOSED FIX-NOW** (design text):
  - `seed` and `floor` become typed position REFERENCES.
  - `dead` is split into a hand set {DEAD_ENTRY, NO_ACCEPT, ACCEPT(pos[, tag])}, each mapped to a FINISH or host
    hand.
  - `names` becomes an instance id. Tables belong to the machine-table entry and are emitted once per
    (machine, direction).
  - A hand-type table with encodings is added.

**F15 — the renderer does not read the record; it reads a `DfaForm`.** SEAM-1.
- `dfa_form_derive` (emit_dfa.c:12962) makes four `DFA_SELECT` choices (repr/view/seed/acc) from deny flags, the
  route and the start-set fact. Callers then override fields afterwards. A process holding only a `RevWalk` cannot
  reproduce the bytes.
- **PROPOSED FIX-NOW** (a design decision in the text). Either the record carries the SELECTED form rows as plan
  outputs (roadmap §0a: "emit is a pure function of the plan"), or it names the frame inputs as declared fields.
  Leaning: the first.

**F16 — `RevWalk` is reverse-only, and it is the third walk descriptor beside `DfaForm` and `Rev`.** PREMISE-7 +
SLOT-1 + standing question 1.

  it never defines.
- `dfa_dir_lmverify` and `pcrec_emit_dfa_retry`'s run-time copy repeat the "instance name" need on the forward
  side.
- **PROPOSED FIX-NOW** (design). The operand record is direction-general, either `DfaForm` made direction-neutral
