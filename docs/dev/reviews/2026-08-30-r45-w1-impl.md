## r45sem — composer semantics (delivered ~02:3x)

(Header path: `src/core/internal.h`, not `src/parse/`; the note's bare `internal.h:NNNN` cites resolve against core/.)

**B1 (BLOCKER) §2.8 — "W1 delivers SLOTS" is refuted by two measured mechanisms.** (a) `src/opt/atomic.c` `pcrec_has_live_capture` (~:709-716, the `A_CALL` arm ~:752): "A subroutine call is CAPTURE-TRANSPARENT" — the arm returns false, and the `A_REP` arm prunes `rmin==0 && rmax==0` (exactly §2.4's injection wrapper). So a composed pattern whose only captures live in definitions looks capture-dead → `forces_captures` (`select_engine.c:99-135`) allows the DFA → no captures recorded, every delivered slot `-1,-1`. (b) Even on the VM, `Ast.u.call.nsave/save` (`internal.h` ~:826-849): the callee region's slot write set is RESTORED on return (only slots 0/1 excluded) — a delivering call's captures are wiped. Settles it: a distinct delivering-call semantics — the callee's capture indices EXCLUDED from the `W` fixpoint in `callgraph.c`, plus a live-capture arm reporting a delivering call live — stated in §2.4's reuse table; or descope delivery from W1.

**B2 (BLOCKER) §2.5 — the re-basing walk corrupts B2 caller-scope references.** `(?&^.w)` resolves to a CALLER group number on the same `u.call.target`; the walk adds `base`. Example: `d` = `(?&^.w)x`, caller `^(?<w>a)(?&d)$` (ngroups 1, base 2): target 1 → 3 = `d`'s own first group. §2.3 never classifies B2. Settles it: a discriminator on the `PendingRef`/node, or resolve caller-scope refs strictly AFTER the walk.

**B3 (BLOCKER) §2.10 — the text splice does not round-trip NAME binding.** Explicit numbers do not fix by-name binding: an injected definition's internal `(?&w)` is re-bound by `pcrec_bref_resolve`'s name arm (`mod_backrefs.c:683-687`, lowest number with that name over the WHOLE composed text) — M2's naive-append row reintroduced by the serializer; without `(?J)` a loud refusal (python `re`: "redefinition of group name 'w'"). Two libraries' `email` → two `(?<email=N>` wrappers in one text. Settles it: `--emit-composed` renders every internal by-name reference NUMERICALLY (`(?3)`/`\g{3}`), or A==B inherits §2.3.4's population restriction as a counted, NAMED skip.

**B4 (BLOCKER) §2.7 — `nnames` counting only `scope == NULL` while `groups[]` holds every entry breaks the shipped ABI contract.** `match_api.md:1349` (`nnames /* entries in groups[] */`), `:1684-1695` (bsearch by name bounded by `nnames`, walk back/forward); `emit_dfa.c:1156-1166` builds from ALL of `cx->named_groups` sorted (name, number), `:1493` emits `.nnames = cx->n_named_groups`. Under §2.7 the array is longer than `nnames` and injected rows sort AMONG the primary's, so a caller can miss its own name or reach a library's private group — D87 rule 2 violated at the artifact tier. S9b covers counts, not the array's length or sort key. Settles it: a second count field, or a sort key making the primary's rows a genuine prefix, plus a §6 caller-algorithm hunk ([M6.5-DUPNAMES] moves too).

**M1 §2.2 — restoring `first_cap_pos`/`first_vmonly_pos` is wrong when only a DEFINITION carries the construct**: `forces_captures` walks the COMPOSED tree then reads `cx->first_cap_pos` = `(size_t)-1` → `engine_why` stamps offset 18446744073709551615, `ctx_fail` reports it under `--engine=dfa`; `forces_registry` same hole (offset 0). §2.9's scope stack is the supply for a third state.
**M2 §2.2 — the `mods` seed drops a definition block's own `flags` and imposes the caller's**: `pcrec_parse_mods_init` seeds only `.caseless` from `cx->opt->flags` = the TARGET's options; format_design §2.6 makes `flags` block-scoped. Blast radius: `flags i`.
**M3 §2.7 — one of two walkers named, and the wrong pass**: `cx->named_groups` is walked by the `PEND_CALL` name arm (`mod_backrefs.c:683-687`), `br_name_run` (the `PEND_BREF` arm — a caller's `\k<w>` sees injected rows) and `emit_dfa.c:1160`; the pass named has already run at injection (`parse.c:1321`) — the rule belongs to the composer's re-resolution (DECIDED(5)).
**M4 §2.5 — `target == 0` cannot tell "root" from "not yet resolved"**: the arena zeroes it, `mod_recursion.c:41/:128` sets 0 for `(?R)` with NO pending record, and DECIDED(5)'s deferred cross-definition `(?&other)` also reads 0 when the walk runs. Key the walk on the `PendingRef`, or run it after re-resolution.
**M5 §2.8 — the "under a repeat" walk refuses every delivering call** (every injected definition sits under `A_REP{0,0}`); exempting the wrapper is the DEFINE-shaped special case `atomic.c` ~:720 argues against.
