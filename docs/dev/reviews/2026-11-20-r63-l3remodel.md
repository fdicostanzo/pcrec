## Lessons for the guide / skill (proposed; see .coord/process.md)
1. Per-commit and BASE kit trees must build CLEAN, not seeded from the review tree's `build/`. A `git archive`
   carries commit-time mtimes, so a seeded BASE or per-commit tree reuses SUBJECT's newer objects and silently
   builds the SUBJECT binary. The r32 advice is safe only for plants, whose edited file is touched. A clean build
   took about 14 s here.
2. A zero-mover remodel lens compares the TRACE stream as an ORDERED sequence (`scripts/trace_diff.py`'s default),
   not only the record set. EMITTED-1 is invisible to every named gate.
3. The anchor map pinned at the arch tree `T` cannot be re-run at a later BASE. A function-scoped map over the
   BASE..SUBJECT hunks (kit/anchor_map.py, reusable) gave the binding population in one call.
