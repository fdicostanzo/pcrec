### SOUNDNESS-5 — HOLDS (by reasoning)
- Sheet §3.5 W-K4 (l.221) quoted: plant "a vector form reads its block aligned down from `floor`"; witness "a G2 site with the subject at a page start, a guard page below offset 0"; fails "a fault (G2) or an ASan report".
- Reasoning check: page size (4096 here, `getconf PAGESIZE`) is a multiple of every vector width W in {16,32,64}, so for any address p, `p & ~(W-1)` >= `p & ~(4096-1)`: an aligned-down block never leaves p's own page. With the subject at a page start, aligning down from offset 0 gives offset 0 (no read below 0); from floor > 0 it stays >= the page start = offset 0. So the guard page below offset 0 cannot fault for this plant; only an unaligned read below 0 (e.g. an unclamped `lo + omin` pointer) reaches it. ASan reaches the aligned-down read only when the subject start is not W-aligned (then the block reaches into the heap chunk's left redzone). Kit has no `no_sanitize` suppression today (`grep -rn no_sanitize memfn/src memfn/include`: none), so the ASan half is not blocked by an attribute.
