## Lessons for the guide (proposed; also in .coord/process.md)
1. **A held commit that builds only on a future combined branch gets a COMBINED APPROXIMATION tree.**
   - How: `git archive SUBJECT`, then `git apply --reject` of each dependency's diff against ITS OWN merge-base,
     then the held diff. Code hunks must apply clean; doc .rej files are noise.
   - The first attempt diffed the dependency against BASE, which reversed about 21k lines of newer main. Always
     use the dependency's own merge-base.
   - Payoff: the round's only answer-level finding (READ-1) and two blockers came from probing this tree.
2. **The check-adequacy lens asks for one witness per new header CONTRACT CLAUSE** ("writes only X", "writes
   nothing on -1", "*out zeroed on -1"), planted as the clause's violation. Pointer-equality shortcuts in a deep
   compare are flagged as checks that can only turn green (CHECK-3/4).
