## Findings

### CONTRACT-1 — `round med` is stated as a format-2 permission, but `round` (and every cell column but `events`) is unparsed text in BOTH formats
CONFIRMED. Severity: doc. Effort: one sentence. Blast radius: spec readers and S2c/S2e authors; no answer or byte effect.
measures.md §2.2¶1a (SUBJECT) says "In a format-2 set ... `round` may be the literal `med`", and span_cards §9 S2a lists "`round med`" as built format-2 content; §2.1¶1a says format 2 differs "in three places and only there" (noise, class, events). The code (ks_measures.c check_rows) parses only `events`; `round`, `length`, `launch`, `ns_e6` are carried as text in both formats.
Repro: fx-f2 cell c1 `round` set to `MED`, `median`, `-1`, `01`, `-`, empty: all load (9 files); fx-rich (format 1) with `round med`, and `length`/`launch`/`ns_e6` = `x`, `01`, `-1`, empty: all load (13 files); format-2 `ns_e6` = `x`: loads. So the "may be `med`" sentence grants nothing and its "In a format-2 set" placement suggests format 1 refuses it, which is false. Fix: state that the cell columns other than `events` are carried as text in both formats (or move the `med` sentence out of the format-2 paragraph); S2c's estimator text is where `round`/`ns_e6` get a grammar. The mfixtures `round med` fixture therefore witnesses nothing the loader checks.

### CONTRACT-2 — §2.2¶1a admits any non-negative `events` integer; the loader refuses one past INT64_MAX as "misspelled"
CONFIRMED. Severity: doc (no reader, D77). Effort: one clause. Blast radius: none today.
Repro: fx-f2 cell c2 `events` = `9223372036854775807` loads; `9223372036854775808` refused "events '...' is neither '-' nor a non-negative integer in its one decimal spelling" (it is one). Noise has its stated bound (10^15) and value_e6 is int64 by §3.3; `events` has none in the spec. Fix: state the bound ("at most 2^63-1", or 10^15 like noise) in §2.2¶1a and the §7 row.

Confirm by the manager's reading of D174's "spec prose a caller reads" for a paragraph describing an internal hand-off with no caller-visible effect at stage 2 (all stamps `""`).

### CONTRACT-4 — §7 has no row for "a known column missing", which format 2 newly reaches (a format-2 `cells` header without `events`)
CONFIRMED (pre-existing gap, new instance). Severity: doc. Effort: one §7 row. Blast radius: none.
§2¶2 refuses "a known column missing from a section that has a header", and the loader does ("section 'cells' has no column 'events'": fx-rich restated format 2; a format-2 cells header-only section without `events`). §7 ("Each of these refuses") lists no such row; S2a makes the most likely real-world instance of it (a format-1 cells table under `format 2`). Fix: add "a known column missing from a section that has a header (in a format-2 set, `cells` without `events`) | §2¶2, §2.2¶1a".
