## Unlocks section

Filed with triggers; none built (D77).

- **Single attribute-writing table (checks).** CE-2 and CE-3 point at the general form: the emitters' existing attribute writers (VM chain, OPT-1 `_deep`, clskit, seam, K24) become declared constraint rows with owner and reason, so the table is the one place any linkage attribute is written. Trigger: E1 itself. The census check (CE-8) becomes a grep for any `__attribute__` emitted outside the table.
- **U-A (family).** A single `part_facts{callers, copyable, rank, forced_attr}` record per part as the general input to every row; `_deep`, K24 and seam then read as rows L1 and L3 rather than exceptions. Trigger: the first non-zero cell going live.
- **U-B (family).** The λ kit row and the L-rows share the ladder that picks a form by size and speed. Trigger: the same ruled diff that migrates the VM chain.
- **UNL-1 (linkage).** Once `entry_rows[]` carries a rank column, the same edge rank could drive `cold`/`hot` hints and `noclone` per part. Trigger: a measured K24-style splitting loss on a part. Not before.
- **UNL-2 (linkage).** LK-2's legality predicate (argument-compatible wrapper) gives a general "forwardable" fact per entry; the VM chain's `may_fwd` is the same fact. Trigger: when the first `-2` cell diff is written.
- **F5's trigger.** findall_iter.md §2.2's `I_shared` measurement is kept as the trigger for promoting "shared for every body" (unlock U1).
