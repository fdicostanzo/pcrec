## Lessons for the guide (proposed)

1. A DEFINITION note (a model replacing a foundation) gets a MODE-CLOSURE drill: every operator of the definition run
   in every mode the language has (whole value, searched, inside a nested filter role), whatever modes the subject's
   evidence ran. Here the evidence was whole-only by design, and the three answer-level splits of finding A were all
   in searched mode (found by three lenses).
2. When the record closes with a summary ("STATE OF THE MODEL"), the ruling lens builds the next revision's RULING
   TABLE (every ruling and reading: stands / retired / reversed / open, by entry) rather than checking the summary
   alone; that table (RULING.md) is the round's most directly usable output.
3. A "MINE, to be checked" restatement that changes answers on a locked rule's territory (A2 vs absent-rule (1)) is an
   owner question, not a manager restatement: the ruling lens should test each such item against every LOCKED rule.
