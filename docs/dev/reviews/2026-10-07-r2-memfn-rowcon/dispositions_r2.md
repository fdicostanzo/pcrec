# Kit manager's dispositions, ROWCON re-check panel r2 (rev 2.1), 2026-10-07

These are BINDING. Every finding id from r2_critic_customer.md, r2_critic_soundness.md
and r2_critic_rvc.md maps to one theme below, or is ACCEPT-AS-MINOR
(folded into rev 3's text).

U-A ENGINE ZERO-MEANS-X (cust B2, M1; sound B3): ACCEPT. The engine follows
  the no-silent-defaults ruling too:
  - `routes == 0` is a table-definition ERROR (checked at registration);
    an "all routes" table writes MF_ROUTES_ALL;
  - a route is an INDEX;
  - scope has an explicit token, MF_SCOPE_ONE, distinct from every real
    slot value;
  - `honours`/`requires` are explicit, MF_HONOURS_NONE/ALL; 0/0 in a
    profiled table is a definition error;
  - the appendix's dfa_pfs row is corrected ("0 = DFA-only" today).
U-B PREDICATE SIGNATURE (cust B1): ACCEPT. The row head carries no
  `applies`. Each table has one `test` thunk, generated by MF_TABLE_TYPED,
  which casts the row to RowT and calls the customer's OWN predicate in
  its own type and polarity. NULL-applies rows (fit_rungs) and tag
  predicates (reseed rows) go through the same thunk.
U-C TOTALITY (cust M3): ACCEPT. The engine never aborts. Each table has
  an `on_none` hook (pcrec: pcrec_ctx_fail; kit: kit_fail), plus a
  per-query MF_Q_NULL_OK option for the both-walks oracle.
U-D ROUTE CARRIER (cust M2): ACCEPT. mf_query has no route. The typed
  wrapper reads it from ctx through the table's `route_of` accessor, so
  there is ONE carrier.
U-E TRACE ABSORPTION (cust M4): ACCEPT and NARROW THE CLAIM. The engine
  absorbs ROW-CHOICE records only.
  - The record prints the row's trace token through the table's `tok`
    accessor.
  - A route may be "-" (no route).
  - RECF/ROUTE pseudo-records stay pcrec macros: they are not decisions.
  - The site literal: the call is the macro MF_SELECT(t, ctx, "site"),
    which pastes "" site, so the literal check is kept and nothing is
    built before the walk.
U-F LISTING (cust M5): ACCEPT. The engine only iterates rows. Listing
  projections (list[route], order, unlisted rows) stay the customer's.
  The sentence "force = deny of the alternatives" is retracted, and so is
  the strategy_denials remark.
U-G RECORD NESTING (cust M6): ACCEPT. There are no parent pointers. A
  caller-owned bounded stack plus a depth counter, reset on entry, makes
  it longjmp-safe.
U-H MISSING CUSTOMERS (cust: the pss_verdict ladder, pcrec_reseed_rows;
  M7 fit_rungs): ACCEPT. Add them to the customer table with their
  encodings: the degrading/FAST_OR_FAIL class deny, NULL-applies rows,
  and their fallback.
U-I GATE GRAIN (rvc M1; sound M4; r1 M1 partly): ACCEPT. `honours` is per
  (field, value class), with the classes in fields.def (e.g. miss ∈
  {MISS_N, OTHER}, floor ∈ {ZERO, OTHER}). The gate admits a row iff every
  stated (field, class) is honoured. pcrec stating `floor="0"` therefore
  stays on ofsskip, so no byte moves.
U-J STATED MECHANISM (sound B1, M6, M7; r1 M3 not): ACCEPT, with scope
  REFERRED to Frank as Q-ROW-5.
  - A STATED BITMASK is set by builder macros (MF_SET(site, field,
    value)), inside the kit's 4→5 bump. That covers enums and numerics
    whose 0 is a real value.
  - Each row has a READS list; the chosen row's reads must all be stated.
  - The independent check is a G2 POISON differential: undeclared hooks
    are set to poison, and the output must be identical.
  - There is a full field inventory: a token or a WRITTEN exemption per
    field. Callbacks are "an absent offer is not a value".
  - Rev 3 carries Appendix B: each kit row's reads/honours, from the
    audit matrix.
U-K SNAPSHOT PLACEMENT (sound B2, M1, M2, M3; rvc M2, M3): ACCEPT.
  - A per-shape placement table:
    - STMT: a block top;
    - EXPR: GNU `({ })`, as generic already does;
    - FUNC: arguments snapshot by C, but they are unsequenced, so the
      kit snapshots in a statement before the call where the form has
      one; otherwise its hooks must be side-effect-free, and G2 checks
      that;
    - ASSIGN with result_decl: names unique per use;
    - ADVANCE more/peek: EXCLUDED (per iteration by design).
  - Snapshot only the hooks the chosen row READS (keeps -Werror clean).
  - The reserved prefix is `_mf_` (block scope, not user-choosable via
    -p). Hook text containing `_mf_` is refused.
  - A bare `break`/`continue` in on_miss/on_cand inside a kit loop is
    REFUSED; only goto/return or a braced block without them.
  - The snapshot spelling is fixed in rev 3, not at T3.
  - `--memfn=no-snapshot` is DROPPED. G1's comparator is the pre-T3b
    commit; that is an exception to D144 item 4, referred as Q-ROW-6.
U-L SEQUENCING (sound M5): ACCEPT. Three steps that each stay green:
  1. R-6: pcrec states every value (zero-mover; nothing refuses yet);
  2. G2's blinded update;
  3. the kit turns the refusals on.
  R-6's inventory comes from the U-J field inventory.
U-M TRACE WIRING (rvc M4): ACCEPT.
  - The census uses emit_sweep --trace (KITFLAGS inherit CFLAGS); no

  - Counters are kit-private statics, outside public structs.
  - The stderr tag is distinct ("MFTRACE").
  - The trace line format is a documented contract in memfn/docs.
U-N CELL INDEPENDENCE (rvc M5): ACCEPT. A committed cells.tsv written by a
