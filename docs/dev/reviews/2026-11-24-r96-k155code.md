## Lessons for the guide (proposed)

1. A conversion from "free when done" to "the arena keeps it" moves retained memory from O(peak live) to O(sum of all calls): the complexity lens must count CALLS per compile, and a call inside a re-render loop (the intern loop here) multiplies. Add to coding.md 1.6: a scratch builder in a function called in a loop over a user-controlled size needs its call count stated.
2. A static census plus a "dynamic independent control" is only independent where a dynamic witness reaches the site; the check lens should ask for the per-row reach table of the dynamic half (CHECK-5), as it already does for invariance harnesses.
