### RDYW-4 — `hb` is redundant once rule 1 reads `hs`, and keeping it as rule 0's input newly refuses a pattern that compiles today: `(?<=(?:${v}){0}x)y`
CONFIRMED (build-tree run + the recurrence by hand). Severity: design/simplification (+ an unnamed newly-refused pcrec-only pattern). Effort: small (drop one column value; rule 0 reads `hi`). Blast radius: V1 (three values, not four), V3's rule 0, §6.2.6 gate 2's "newly refused set ... 0 expected".
