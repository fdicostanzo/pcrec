### RULINGS-2 — REACH `back` is the presence class's existing `omin`, bounded by the wrong slot (MF_MAX_BACK)
CONFIRMED (cites). Severity: design. Effort: S. Blast: §2 REACH pair, §5.3, L3, Q5.
memfn.h:679-684 already has the slot: presence `omin`, "the smallest offset, from the MATCH START, at which an occurrence of the span can begin ... the true omin is B5's"; ReqRun has its upper twin `maxoff` (K82, facts.h, signed long long). `back` = -omin, so the "REACH pair" is not a new notion: it is the run's signed offset interval [omin, maxoff] that two slots already half-hold; state it as that (the general form) rather than a new pair. And the bound is taken from the wrong slot: L3/Q5 cap `back` at MF_MAX_BACK, which is the WINDOW statement's span-offset shape bound (memfn.h:228-235, :586-591), while L3 routes BACK through the PRESENCE statement, which has no such bound. The natural bound is the pattern's own read-before-start fact, `Ctx.lb_max`/`<prefix>_VALID_LB` (internal.h:3985-3997), the one the note's own soundness sentence ("PCRE2 lets a lookbehind read before the start offset") rests on.
