### F1: the two proof-range witness rows (r20 F8) depend on a refusal §1 does not declare, and row (b) cannot fail on an after-stated cover (FIXIND-2, OWNER-14)
- **Status and severity:** CONFIRMED by reading. maintenance (a witness that cannot fail as written).
- **The undeclared refusal.** §1 lists exactly two kit refusals: a tested offset outside the range, and rows past the
  caller's cap. The plant cuts `end` to `last_s + 1`, which trips neither.

    declares.
  - Row (b)'s `SAB_FILE2` removes a check the reply never names.
- **Row (a) has no channel for its message.** The asks are PURE and set no error (memfn.h, `mf_ask`/`mf_wdecide`

- **Row (b) reads UNDETECTED on an after-stated cover.** B5 requires the range to reach `k + 1`. When the after side
  is stated, `last_s = k`, so the cut end is still `k + 1` and nothing fires. Row (b) needs an after-UNSTATED cover,
  and its REACH must assert that.
- **PROPOSED: FIX-NOW (text).**
  - Declare the third check, on both the ask path and the define path, and mark it as a self-check that shares its
    source with `end`.
  - Say that row (a) reads the message through `mf_define`.

### F2: at `mf_rows_need`'s size, F2's own example over-read is a refusal labelled like a legitimate decline, not a B5 catch (FIXIND-5)
- **Status and severity:** CONFIRMED by arithmetic and code (`known.c:413-424`, `:649-660`; the same on covs2afix).
  design (check observability).
- **How the over-read is lost.** On the usual cover (after side unstated), storage ends at offset `k`. A text that
  tests `k + 1` makes the ask return a bare -1, and `cc_served` records `refused`. That is the same detail
  `--memfn=no-window-search` produces.
- **What today does instead.** B5 reads every offset up to 32, by offset and byte.
- **The answer is unaffected** (the engine answers). But a kit over-read defect can no longer be told apart from a
  legitimate decline. §1's "lands inside the range, where B5 reads it" holds only on an after-stated cover.
- **PROPOSED: FIX-NOW (text plus a question to main).** Choose one:
  - (i) the cover ask passes storage up to `MF_MAX_FWD` (4,104 rows, 131 KB, one ask per attempt), so every
    over-read lands in B5's view; or
  - (ii) the over-range refusal gets a signal pcrec can tell apart.
  
  Then correct the F2 sentence. Coordinator's lean: (i). Its cost is already priced in §5 at `k` = 4095, and it keeps
  B5 the independent control.
