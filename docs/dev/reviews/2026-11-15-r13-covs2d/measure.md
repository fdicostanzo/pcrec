# MEASURE — covs2d

## Findings

### MEASURE-1 — rule yields NO value when the lowest movers fail; "24 or below" is outside the rule (CONFIRMED by construction)
Severity design; effort S; blast: the default and the EMITTED-2 fallback. §11.2 (lines ~790-797, ~810), §11.4.
Timed mover widths (R/kit/facts.sh, both encodings): lit-l31 = 31, hex32 = 32, dig-exact-32 = 32, hex32-id = 32 (\b), both uuid shapes = 36 (loglines/uuid, grok), lit-l40 = 40. The only timed width below 31 is the A/A control lit-l16 (16), which is not a mover.
The rule picks "the longest k AMONG THE TIMED MOVERS". If the 31/32 movers fail (the EMITTED-2 case), no mover width qualifies: the set is empty. The text says the fallback "would land at 24 or below"; 24 is not a timed width, and §11.2 says unmeasured widths are off by default. So the rule cannot land at 24; it lands at "nothing", i.e. cover off for every width (below 31 nothing was timed). Also the stage-1 movers (31-32) are the narrowest, so "stage-1 fail, stage-2 pass" gives the same empty result: 36 and 40 pass but the prefix rule bars them.
Fix: state the empty-set outcome (default = no cover? or the owner picks a value, with its own timing of widths 17-30), or add timed movers at 24 and 16 (e.g. a lit-l24 / hex24 cell, which §7 already names as "the 24-position twins").

### MEASURE-2 — outcome table is not first-match-safe: the noise row is last (CONFIRMED by reading)
Severity design; effort S. §11.4 outcome table.
The A/A row ("noise above the floor -> night void") comes LAST. On a night with A/A spread above the floor and one cell "slower", row 2 or 3 matches first and the night is NOT voided; the slower cell then drives a size report or an EMITTED-2 order from a void measurement. The validity row must be first. Also no row covers: a stage-2 mover slower in near-miss only (row 2 names only "a stage-1 class cell"); a cell slower in not-warm AND near-miss (row 2 says "near-miss only", row 3 then matches, fine, but then §11.2's rule excludes it while row 3 says "owner's call": which sets the default?); a stage-1 class cell slower in not-warm only (row 3, but nothing says whether stage 1 stays landed). Row 3 versus the §11.2 rule conflict: the rule excludes any cell slower in ANY regime, the table defers it to the owner; one default must be named for the interim.

### MEASURE-3 — the noise floor, launch count, outlier, bimodal and equal-effect handling are undefined (CONFIRMED: grep of the subject)
Severity design; effort M. §11.2 "beyond the A/A noise floor", §11.4.
`grep -n -i 'noise|floor|launch|bimodal|median'` finds only the phrase "A/A noise floor" and "bench's" in §0/§7/§11; no number, no statistic, no repeat count, no rule for one outlier launch, a bimodal cell (two clusters across launches), or an A/A spread that straddles the floor. "Not slower beyond the floor" on a bimodal cell is decidable either way, so the same data can give default 32 or 24. Equal-effect sweep (every cell slower by the same amount, including A/A) is an A/A failure and voids, only if row 4 is first (MEASURE-2). Name the bench report field the floor comes from, or a procedure (N launches, median, the A/A max as the floor).

### MEASURE-4 — hex32-id is declared a stage-1 mover but is not one in the default build (CONFIRMED)
Severity design/doc; effort S. §11.4 A, §0 G5.
R/kit/emit.sh: `\b[0-9a-f]{32}\b` byte and utf8: `def` and `eng` emit BYTE-IDENTICAL C (26,586 / 30,946 bytes, scan=unanchored both; diff 0 lines), although facts.sh lists a `cover` row (k 32). Only `kp` (harness-forced) gives scan=cover. pcrec-bench selfcheck also calls it "control, declined". The bench-side hex32-id is a declined control; A-timing it shows no change by construction. The uuid shapes (36) also emit unanchored both ways today (seam), and whether they pass C9-C14 at stage 2 is unknown ("an UPPER bound", §11.1). Consequence: "timed movers" must mean "movers whose artifact takes the cover at the lever's ceiling"; a declined cell counts as "not slower" and can carry the default up to k = 36/40 on no evidence. Check the emitted `RX_DFA_SCAN` of every cell before timing and drop declines from the rule (SUSPECTED for lit-l40/uuid/grok at stage 2: confirm with the stage-2 build's listing).

### MEASURE-5 — §11.4 B's arm changes more than the cover route (CONFIRMED, 6 patterns x 2 encodings, def vs `--memfn=no-window-search`)
Severity design; effort S. §11.4 B.
Diffing emitted C for lit-l31, hex32, dig-exact-32, lit-l16 (control): differing axes, all downstream of declining the cover LOCATE row: RX_DFA_SCAN cover->unanchored; RX_DFA_START attempt-start->end-minus-width; RX_DFA_PREFILTER none->byte-class (hex32) or offset-set "0,9*" / "0,1*" (lit-l31, dig-exact-32); RX_REQ_WHY dominated->untestable (hex32) or emitted (lit/dig), REQ_HANDOFF none->0 (the required-run scan site is emitted only in the engine arm); a whole forward DFA (tables, state-step functions, can-begin and scan1 tables, ~125-240 differing lines) added; the `rx_mf1_*` kit span site removed. Emitted C bytes 21,993 vs 32,965 (lit31), .text 5,282 vs 8,815. So the comparison is "cover route vs engine route including its prefilter and required-byte sites", which is the intended A/B, but it is not ONE variable: the prefilter/req-run choice and `.text` size move with it. Say so (name the axes) rather than claim one variable. Per tuning.md §2.43¶3d, `no-window-search` also affects other window sites (lookbehind two-stream bounded look-ahead); not exercised by the movers (no lookbehind), so not a confound here, but the stage-2 `--memfn` carrier must be confirmed per cell by diffing RX_DFA_SCAN only.

### MEASURE-7 — §11.4 B ceiling and "each long mover" vs the default's meaning (design)
The lever at "the ceiling" times the mover; the rule then picks a default from widths only 36/40, all no wider than 40. Width 40 is the longest timed; so default can never exceed 40 though the owner's population tail goes to 1000. That is consistent with "unmeasured, off" but means the stage-2 build (4095 span, arrays, kit forms) is built and measured at 3 widths only; no near-miss witness for 36/40 exists beyond "k-1 positions then a miss" (a shape that is stated, not generated; hex32 on digit runs and 31 digits+g are stage-1 ones).

- emit def vs eng: 6 patterns x 2 encodings = 24 compiles; hex32-id and uuid identical both ways; lit-l31/hex32/dig-exact-32/lit-l16 differ as listed. kp on hex32-id gives cover (1 compile).
- The rule is monotone-prefix as written: "all widths <= k" is consistent for all-clean (default 40), one-fail-at-40 (36), 36 fail (32), and the equal-effect case is only caught by the A/A row (MEASURE-2). Only-width-32-timed-in-a-regime: the rule then takes 32 as the longest tested in that regime but a longer mover timed in another regime is not capped by it; underspecified: "every timed mover ... in ANY regime" assumes every mover is timed in every regime (state it as a requirement; a missing cell must be a void, not "not slower").
