## Lessons for the guide

1. A fold's stale-text check must take its search strings from the RECORD's revise/reverse sentences and from every
   piece in each ruling's `tags:` line, not from the lane's own list (r114 F16/F17: core/labels/flow and the errors
   table were tagged and unvisited; STALE129's 6 texts all absent).
2. A probe kit that loads the evidence engine up to its checks, with a CONTROL switch, let every lens run its own
   cells in ~1 minute per batch; answer findings came from cells no printed line reaches (`|`, loops, group reads,
   read-before). Ship one in every design-mode round whose evidence has an engine.
3. An evidence engine's FALLBACK to an older engine answers with rules the fold reversed (F5): drill each fallback
   path with a program the new rule moves.
