## Lessons for the guide (proposed)

1. A generated corpus from the oracle REACHES the new sites but need not DISCRIMINATE them: random tokens never sat on an interval edge
   and the nullable patterns could never retry to a non-empty match. Proposed critics.md line: "for a generated oracle corpus, the check
   lens plants one fault per new site in a COPY of the emitted C (no rebuild) and reports SAME plants; edge cells of every interval table
   are demanded" (cost here: one sonnet critic, 281 cells, zero builds).
2. When a branch lifts a refusal, grep plan.md for rows naming that refusal as a TRIGGER (RULES-1) — already the root CLAUDE.md
   "close a row" rule; make it explicit for "a refusal goes away".
