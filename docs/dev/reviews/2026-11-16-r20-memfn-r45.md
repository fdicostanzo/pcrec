## Findings (PROPOSED dispositions)

Severity order. "Text" means the fix is a change to the reply. None needs a measurement before the reply is revised.

### F1: the per-reply proof range does not reach offset `k` when the after side is unstated (PREMISE-1)
- **Status and severity:** CONFIRMED. answer/design.
- **What's wrong:** the reply defines `stated_end` = 1 + the largest STATED offset. pcrec states the after span only when
  that side constrains (`cover_side_stated`, known.c:563-569; `cover_window` :614-625). For an unanchored
  `[0-9a-f]{24}` with nothing after it, the range is `[-8, k)`.
- **Consequence:** cover_cap §11.1 B5 requires `k+1` and raises a named internal error otherwise. So B5 fires on every
  unconstrained-after cover while the kit's own check passes. The reply's sentence "the range always reaches offset `k`"
  is false.
- **PROPOSED: FIX-NOW (text).** Define the end per REPORT site (span-0 end + 1, or always state the after span), or
  change B5. Say which.

### F2: a range sized from the statement re-introduces rev 5's struck range and blinds B5 to kit over-reads (PREMISE-4)
- **Status and severity:** CONFIRMED by reading. answer (latent: a control goes blind).
- **What's wrong:** the rows are computed from TESTED offsets (`wf_plan_class`, window.c:3840-3858), but the range is
  sized from STATED offsets. A defective text that tests `k+1` is clipped out of the rows and read as all-ones, which
  equals pcrec's want, so B5 passes.
- **Why it matters:** cover_cap §11.1 B5 struck exactly this narrower range. The kit's proposed check (range >=
  statement) does not test tested ⊆ range.
- **PROPOSED: FIX-NOW (text).** `proof_n` = 1 + max(stated, tested) − `MF_PROOF_LO`. The kit refuses a reply that tests an
  offset outside `[MF_PROOF_LO, MF_MAX_FWD)`. Restate "by construction" as a kit promise that B5 checks.

### F3: "the kit writes rows into the caller's arena during `mf_ask`/`mf_defined`/`mf_wdecide`" has no mechanism (PREMISE-3)
- **Status and severity:** CONFIRMED. design (API/abi).
- **What's wrong:** the asks take a `const mf_art *` and are contractually PURE (memfn.h:1527-1538, 1729-1737). The NONE
  ask deliberately avoids the art's arena (window.c:2768-2770). There is no arena parameter.
- **What the reply must choose:** one of three, named in §5's abi list:
  - a new `mf_arena *` parameter on every ask and its callers;
  - a caller-supplied row buffer, with the count asked or bounded first;
  - allocating through the art, which breaks PURE.
- **PROPOSED: FIX-NOW (text; a design choice).** Recommend the caller-supplied buffer, which keeps the asks pure and is
  serializable.

### F4: pointer members break every byte-for-byte struct compare (PREMISE-2, READY-1, READY-2 part, READY-9)

### F11: the cards and the decision rule invert the owner's burden of proof (OWNER-1, OWNER-2)
- **Status and severity:** CONFIRMED by quote and drill. design (owner criteria).
- **What the owner asked for:** loops by default with a MEASURED inline head; all-inline becomes a dial option only on
  proof.
- **What the reply does:** C1 asks whether H/L BEATS I, and if neither does, the default stays all-inline.
- **The drill:** the first-match rule leaves the UNMEASURED all-inline default in place in 3 of 4 constructed outcomes:
  - predicted tie: no knee, and no tie-break is declared;
  - "I faster in one regime": row 2 sets nothing, and first match stops there;
  - tie within noise: as the predicted tie.
  
  In the fourth outcome (L faster everywhere), `H(0)` = L is missing from the grid.
- **PROPOSED: FIX-NOW (text).** Use a combining rule:
  - the default is H(h*), with a declared tie-break over a grid that includes 0 and ≥ k;
  - independently, any cell where I wins is filed as dial evidence.
  
  Keep "zero movers at 32" as a stability trade offered to the owner in plain words, not as his direction. The owner
  rules Q2.

### F12: interim h = 32 is tied to a width default that stage 2 exists to move (OWNER-3)

- **Consequence:** if the night picks a width above 32, uuid and lit-l40 ship an unmeasured H(32)+L form, and the

- **PROPOSED: FIX-NOW (text).** Say whether h is independent of or derived from the width default. Q5 becomes: the cards
  run before or on the same binary as §11.4's B cells, and set h first. This needs a main ruling on the night's order.
