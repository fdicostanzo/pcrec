### FORMS8-1 CONFIRMED, speed: the interaction test (A) reads per-TEXT launch-noise heterogeneity as a variant x regime interaction, and one flag voids the WHOLE night's pick
cards.py:1593 `text_interaction`, :1895 (vc.append), :1358 (r1 step 5) at 3fd31c86d compares each text's lack-of-fit mean square against the
pure-error variance POOLED PER REGIME OVER EVERY TEXT OF THE NIGHT. A text whose own launch noise is above its
regime's pool has ratio > 1 with no interaction at all; with sL2 ~ 0 (small layout main effect) the share is ~1
whenever sI2 > 0, so INTER_SHARE does not hold it back (see FORMS8-3). A flagged text's cells go into `vc`
(void_cells) and r1's step (5) returns the grid top for the WHOLE night (the pick is only recorded): the ruling's
"the affected text's cells are VOIDED (no pick there)" is in effect "no pick anywhere that night".
Repro (scratch copy of cards.py with a TSCALE(key) multiplier on the launch sigma, no RNG change;
work/d1.py, `python3 -I d1.py 100`, 100 nights each, layout "phase" tau 1 %, one true 5 % H(8) win in hit-dense):
| launch-noise model | nights flagged | h* = 8, void ON | h* = 8, void OFF |
|---|---|---|---|
| homogeneous (baseline) | 1 | 71 | 72 |
| ONE pattern's (hex24) head arms 2x sigma | 100 | **0** | 62 |
| every head arm 1.5x | 1 | 36 | 37 |
| A/A 0.7x (selftest G2 model) | 1 | 86 | 86 |
| t(5) launches (selftest F2 model) | 55 | **32** | 78 |
| one regime 3x not-warm (selftest G2 model) | 56 | 13 | 21 |
Expected: no flag (no interaction exists in any row). Two of the selftest's OWN standing noise models (F2 t(5),
G2 one regime 3x) flag ~55 % of nights once a layout is present; the drill rows never combine them with a layout,
so no gated row sees it. h* never leaves 64 because of it (answer-safe; a void is speed only). t(5): the chi-square
line assumes normal launches; heavy tails inflate the lack-of-fit ratio's spread.
Proposed: FIX-NOW before the night if the void stays: (a) pure error per TEXT (or per row) instead of pooled per
regime, or a robust (median-based) lack-of-fit; (b) void only the flagged text's cells for the pick, not the
night (or state plainly in rev 13 that one flag = no pick that night); (c) gate a drill row combining the layout
with t(5) and with one pattern's arms at 2x, power AND flagged-night rate. At minimum DOC + record-only (print,
never void) for the first night, since INTER_SHARE/INTER_ALPHA are UNMEASURED.

### FORMS8-3 CONFIRMED, speed: the interaction line voids a quarter of nights on an interaction of half the launch sigma; INTER_SHARE never binds; no power row under any interaction
Interaction drill keyed UNLIKE the fit (scratch models added to a copy of `synth_layout_effect`, work/d2.py,
200 nights a row, seeds 1200): "onereg" = a per-(body, variant) head effect in ONE regime only (5 regimes
clean, so the per-text fit half-absorbs it); "mix" = the phase main effect x a per-(body, regime, variant)
interaction of a smaller tau_i (variance share of the interaction 0.2 at 2 % x 1 %).
| model (heads only) | void ON: flagged / P(h*!=64) / h*=8 | void OFF: P(h*!=64) / h*=8 |
|---|---|---|
| onereg hit-dense tau 2 % | 200 / 0.000 | 0.035 |
| onereg hit-dense tau 3 % | 200 / 0.025 | **0.175** |
| onereg hit-dense tau 5 % | 200 / 0.015 | **0.170** |
| mix 2 % x 1 % | 200 / 0.000 | 0.020 |
| mix 3 % x 1.5 % | 200 / 0.000 | **0.135** |
| mix 3 % x 2 % | 200 / 0.015 | **0.240** |
| POWER mix 1 % x 0.5 %, one 5 % H(8) win | 52 / h*=8 **144** | h*=8 193 |
| POWER mix 0 x 0.5 %, one 5 % H(8) win | 56 / h*=8 **132** | h*=8 189 |
So the ANSWER half of A HOLDS under both differently-keyed models (every P with the void <= 0.025; the void is
what holds it: off, 0.135-0.240). The cost: the line fires on everything it sees: a 2 % x 1 % mix (variance
share 0.2, below the stated 0.5) is flagged on 200/200 nights, and an interaction of 0.5 % (half the 1 % launch
sigma, harmless with the void off: 189-193 of 200) voids ~27 % of nights and takes power from 189 to 132.
INTER_SHARE (cards.py:1534) is on the mean-square scale (cards.py comment: "an index"), so 0.5 is not the variance share the
rev-13 text implies ("share exceeds 0.5"), and with sL2 ~ 0 the share is 1 for any sI2 > 0: the line that
decides is INTER_ALPHA's chi-square alone. The selftest's (r44 A) rows gate only P(h*!=64); no row measures
power or the flagged-night rate under an interaction or under a benign small one, so the void's cost is
unmeasured in the record (it compounds FORMS8-1).
Proposed: PLAN/DOC now: record the flagged-night rate and power for a small interaction (0.5 %) in drill
(xxiii); state in rev 13 that INTER_SHARE is an index, not the variance share, and that one flag means no pick
that night. If power at the first night matters: FIX (raise the line to an effect-size floor, e.g. sI2 above
a fixed fraction of the floor's own variance, rather than significance alone).
