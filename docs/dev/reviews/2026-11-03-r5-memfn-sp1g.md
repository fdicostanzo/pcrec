## Lessons for the guide (proposed)

1. **A "kit never reads X" invariance check must pick its witness sites from where the kit READS the containing object, with a reach control** (the varied render must differ from the absent-object render on at least one site). Prefer a static "kit source names no X" scan beside it. (F1: L(4b) varied the digest on two sites that never consult the object; three real readers stayed green.)
2. **A seam-shape check is an ALLOWLIST of members, on every struct of the seam, not a denylist of the retired names.** (F2: provenance re-entered under a new name, and on the parent struct, and nothing turned red.)
3. **When a deletion removes the last record column read from the built object, move one surviving column to read the object** (F3, F17). Otherwise the builder's remaining writes lose their only witness.
4. **A design reader list built from a grep pattern misses bare vocabulary words.** Add the enumerator's bare spelling to the pattern (F8: `PRIOR_NONE` without its `MF_PROV_` prefix) and sweep design docs beyond the named sections (F6).
