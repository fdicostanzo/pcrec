### SEAM-3 — `def` crosses as a C struct of pointers, callbacks and C TEXT, and the plan classifies that text by C grammar: the projection that would round-trip is not named, and §2.8's "facts reused unchanged by a Rust emitter" is false for the gates T-FRAME and the composer walk read. - What crosses `mf_wdecide(art, site, def, call, out)`: `mf_hooks*` (`memfn.h` ~:930-1055) holding `void *u`, six callbacks (`on_cand`, `member`, `table_name`, `fn_name`, `note`, `note_tag`) and C expression/statement TEXT (`s`, `n`, `lo`, `floor`, `more`, `peek`, `step`, `cursor`, `ref`, `reflen`, `fold`, `on_miss`, `start`, `moved`, `indent`). `art` is an opaque pointer whose facts (denies, options, measure set, layer) the design names but does not enumerate as the ask's text (§2.2 Purity).
- What the plan READS of `def` (the round-trip-relevant projection): stated-ness (`window.c:1314`), and a CLASS per text from `gate.c`: `ident_or_other` = `kit_is_ident` (a C identifier, :618-628), `cl_floor` = `strcmp(floor, "0")` (a C literal, :639-643), `cl_miss` = `in->h->miss == MF_MISS_N` compared BY ADDRESS, else `strcmp` with `n`'s text (:648-653), `conj_shape`/`postfix_shape`/`expr_stmt_shape`/`stmt_shape`/`fold_shape` (C `&&`, postfix, `;`-statement grammar, :86-297). The class vocabulary (IDENT, ZERO, MISS_N, statement shapes) is the real cross-language fact; the classifiers are the C front end of it.
- Fix (design text only; D77, no serializer built): §2.2 names the ask's round-trip form = site facts + art facts list + per hook {stated, class enum, miss token} + call; Goal 3's counting hook already proves callbacks are not called, so add "and the plan reads `def` only through that projection" as a checkable claim (a fixture that replaces every text with a different text of the SAME class and asserts the reply unchanged; sabotage: a gate that reads text beyond its class). §2.8 moves the text classifiers to the C-SPELLINGS layer (pcrec states classes in the Rust world).
