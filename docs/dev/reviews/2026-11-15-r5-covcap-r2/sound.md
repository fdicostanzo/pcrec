# SOUND — covcap-r2

## Findings

### SOUND-1 — TERMINATION: a DEAD line can cycle with a period exponential in the NFA; the "anchored machine's state count" bound is false off live lines
- SUSPECTED (hand-executed on `sw_close`/`sw_take`; the hang itself cannot be shown on today's budgeted walk). Severity: answer-adjacent robustness (compile hang / unbounded arena) + design (G4 "no budget" rests on this claim). Effort: small (state the bound correctly; a cap or a cheaper dead proof). Blast: every `--emit-facts` compile (`pcrec_facts_force_all`, compile.c:3678) and any future PF_SPAN asker; NOT the default cover path today (C8 is reached only after C6/C7 prove a live fixed-width entry, and a live root makes the line live, so it ends within the live path).
- Cite: cover_cap.md §3.1 TERMINATION AND COST ("its length is at most the number of distinct subsets on one path ... in general it can never pass the anchored machine's own state count for the same path").
- Witness: `(?:(?:a{2})*\z\W|(?:a{3})*\z\W|(?:a{5})*\z\W|...|(?:a{47})*\z\W)` (15 prime-length unary loops, each killed only by `\z\W`). Hand-execution: `\z` with a known previous byte gives `nr` = empty and no NOACC (kset.c:711-725), so the `\W` entry is pushed with R = empty and dropped by `sw_take`; every thread's loop entry stays. U_d = {thread p at offset d mod p, for every p}; the only consuming class is `a`, so every depth has ONE successor; POSSIBLY LIVE holds for every entry (items passed as held), SURELY LIVE for none; U_d never accepts. The line therefore runs until an exact subset repeat, at d = lcm(2..47) ~ 6.1e17. Today `pcrec -p rx --features all --emit-facts=byte --pattern '(?:(?:aa)*\z\W|(?:aaa)*\z\W)'` lists `span_facts 0`, `never_matches no`, `width [1,inf)`: the threads survive to E3 and no earlier fact proves the pattern dead, so nothing stops the walk before E3's PF_SPAN.
- Why the claim fails: the minimized DFA bound holds on a LIVE line (two equal residual languages on a line ending in accept at e would put an accept before e), but a dead line's residual languages are all empty; the bound is on NFA SUBSETS, which is the unminimized subset construction (up to 2^n). The `[ab]*\z\W` witness only exercises period 1.
- Fix shape (design's call): state the bound as "distinct NFA subsets on the path" and prove deadness without walking the cycle, e.g. a line whose subset's POSSIBLY-LIVE successor targets are only reachable through items that the context already decides false; or keep one LABELLED budget for dead lines only (owner criterion (c) asks for no arbitrary constant, so this needs an owner word).

### SOUND-2 — ROOT RULE does not say which liveness makes a root "live"; the surely-live reading states a wrong product
- SUSPECTED (design gap; hand-executed). Severity: doc/listing (a `span_facts` value larger than the truth; contract facts.h:296). No answer: C6 declines this shape (`seeds`) before C8, and C8's DFA comparison would decline a disagreement. Effort: one sentence. Blast: listing values of context-dependent roots.
- Cite: §3.1 THE WALK step 1 ("The live roots must be ONE subset"), against step 3, which defines liveness only for SIDE subsets (surely live / surely dead / undecided).
- Witness: `(?:\bab|\Bac\z)`. Roots by previous context (sw_close at depth 0): non-word or absent before -> {a of branch 1}; word before -> {a of branch 2}. Branch 2's root reaches accept only through `\z` (an N_CTX item): POSSIBLY LIVE, not SURELY LIVE, i.e. undecided. If "live roots" means surely-live roots, one root remains and the line runs a, b, accept: `2:97,98`. Truth (python re, `\z`=`\Z`): `xac` matches at (1,3), so the length-2 prefixes are {ab, ac}; S_1 = {b,c}, and the stated product {a}x{b} is wrong. Today lists `1:97` (byte and utf8), which is true.
- Fix: step 1 should say a root counts unless SURELY DEAD (undecided roots count as live), which gives 0 here (sound).

### SOUND-3 — ROOT RULE: "the live roots must be ONE subset" is a representation cut; the UNION of the roots is sound, general, and removes SOUND-2
- SUSPECTED (hand-executed; depends on whether the NFA shares the `a` node across the two arms, which the review tree cannot print). Severity: speed (a cover lost outside the census population) + design (one more special cut than the problem needs). Effort: small. Blast: context-split roots (111 listing compiles per §2; covers outside the census).
- Cite: §3.1 THE WALK step 1; kset.c:574-577 (the roots' purpose: "the sets describe the union over contexts").
- Witness: `(?:\bab|\Bab)c` is a COVER today (`RX_DFA_SCAN "cover"`, `span_facts 3:97,98,99`, byte). Roots: word before -> {a of the `\B` arm, R=word}; non-word/absent before -> {a of the `\b` arm, R=word}. With unshared arm nodes these are two subsets, so step 1 states 0 and C8 declines `producer-short`: a cover lost, and not in §6's mover list (the census population does not contain it).
- Why the union is sound: context matters only at depth 0. After the first consumed byte, every closure reads that byte as `prev` (sw_expand pushes with R = all), so the line from U_0 = (union of the non-surely-dead roots) follows exactly the union, over contexts, of the per-context languages; that union is what facts.h:296 defines `set[d]` over ("the context before it ranging over every byte and the subject start"). Liveness stays per successor, so an undecided root's private bytes surface as an undecided side successor at depth 0 and end the statement there. This also answers SOUND-2 without a root-liveness rule, and C8/C6 still read the DFA's single entry row independently.

### SOUND-4 — SOUNDNESS paragraph: the OPAQUE end is not covered, and "C8 compares on every cover" bounds less than it reads
- CONFIRMED as text (no wrong value reachable today). Severity: doc. Effort: two sentences. Blast: the proof a future item kind relies on.
- Cite: §3.1 step 2 ("If U_d is opaque ... it ends with exact_len = d") and the SOUNDNESS paragraph ("Suppose the line is live: it reaches its accept, or it reaches a decided branch").
- (i) An opaque end proves no liveness, yet step 2 states d positions there. Today it is harmless only because opacity arises at depth 0 alone: `N_GSTART` sets `opaque` only when `depth0` (kset.c:728-732) and `N_CSTART` is unreachable from `anch_start` (kset.c:571-572, K50). The paragraph should either say "opaque => exact_len = 0 unless d = 0" or argue the depth-0-only fact; a future depth>0 opaque kind would otherwise state an unproven prefix.
- (ii) "C8 compares the sets with the DFA's on every cover" checks only dd < min(k, exact_len) (known.c:264); with §3.2's H = exact_len the DFA cannot see a slice that is too long or wrong PAST k. That is fine for answers (the cover reads k from the DFA), but the listing (`span_facts`, a stated fact read by the trace build's SPANSET/X0) has no machine control past k: the soundness of those values rests on §3.1's argument alone. Say so; X0 (libpcre2) is the only control there.
- Held, for the record: on a LIVE line every exit (accept; all-surely-live branch; one-surely-live + undecided branch) proves the line live, and the cycle rule is correct (a repeat over one-successor steps with no accept is dead).

### SOUND-5 — §5.4 plants: all five witnesses flip in the sabotaged build and hold in the correct one, but three table cells mis-describe the flip
- CONFIRMED by hand-execution (no build exists). Severity: doc/test-design. Effort: table edits. Blast: §5.4 only.
- (c) `(?:[a-z]{0,3}\z|x)[0-9]{3}`: correct rev 2 = `0` (U_0 = {[a-z]_1, x}; class `x` -> {[a-z]_2, digit_1} SURELY LIVE via the digits; class [a-wyz] -> {[a-z]_2} only possibly live through `\z` = undecided; rule "undecided + one surely live" gives exact_len 0). Sabotaged (undecided as live) = union of the two classes = [a-z] = 26 bytes, `1:[26]`, not the PREDICTED `1:[27]` (no 27th byte is seeded at depth 0: the digit entry of arm 1 carries R = empty after `\z` and is dropped by `sw_take`). Truth (today's listing) is `4:120,[10],[10],[10]`, so `1:[26]` is a genuine overstatement: the witness discriminates.
- (a) "`40:` -> `32:`": under §3.1 a position is stated only when the line's END proves liveness ("the line's own subsets need no decision: the line's end decides them"), so a walk cut at depth 32 with no end has an undecided line and a faithful plant states `0`, not `32:`; `32:` only arises if the plant also re-introduces an incremental exact_len. Either value flips the `40:` row, so the witness holds; the predicted value should not be written as `32:`.
- (e) "(under ASAN, the overflow)": `cover_window` writes `e->set[d]` for d >= 32 into the arena (`pcrec_memfn_wpos_bits`, memfn_sites.c:559) BEFORE `window_bounds_check` runs in `pcrec_memfn_window_stated` (memfn_sites.c:578-603). The arena is a bump allocator with no poisoning (arena.c:13-38), so ASAN sees the overrun only if it crosses the block end. The reliable red is the internal error (`w->len` 40 > `MF_WSPAN_POS`). Drop the ASAN clause or say "the internal error"; also note the writes happen before the check (the check is a detector, not a guard).
- (b) `ab|abc|ad` `2:97,[2]` -> `1:97`: the sabotaged value depends on whether the NFA shares the `a` node (unshared arms give `0` under a thread reading); the review tree has no NFA dump, so `1:97` is unverifiable here, but every thread reading gives < 2, so the row flips. (d) the 25-literal: with H = exact_len = 25 and `j < H`, no row is examined at depth 25, outcome (3) gives k = 26, C8 declines `producer-short`; (a)-(c),(e) leave it a cover. Holds. Note (d) also flips every existing cover verdict row, which is fine for a matrix but means its witness is unique only against the other plants.
- Cycle witness `[ab]*\z\W`: roots under every context = {[ab]-loop} (the `\W` entry carries R = empty after `\z` and is dropped); class [ab] returns the identical subset; correct = `0`, no cycle rule = no end. Holds, BUT `sw_take` (kset.c:780) dedups only within one depth, so "a subset already on the line" is a new comparison across depths that §3.1 must name as a change to `sw_take` (the design says it "keeps" it); built literally, the cycle rule never fires and every cycle witness hangs.

## PROBED-AND-HELD

- Hand-executed §3.1 (rev 2) on the real `sw_close`/`sw_take` semantics, each against today's listing and, where it matters, python `re`: `a*?a` -> `1:97`; `ab|abc|ad` -> `2:97,[2]` (both successors at depth 1 accept-or-surely-live, union); `(?:a|ab)(?:c|bcd)` -> `2:97,[2]`; `a++b` (possessive, not erased) -> `2:97,[2]` (a successor equal to the line subset inside a branch is handled by the branch rule); `(?=a)a.`, `a(?!b).` (one-char lookarounds as N_CTX) -> today's values; `a(?=b)` -> `1:97` (accept with a non-empty after-R); `abc$`, `abc\z`, `\babc\b`, `(?i)abc`, `ab(?:|)c`, `(?i)é` utf8 `2:195,[2]`, `[а-я]{2}` utf8 `1:[2]` (lead-byte branch, all surely live) -> all equal today's; `(?>a|ab)c` declined `erased-nfa` (atomic not on this path); `a$\n`-style end-after on the LINE accepts correctly (only side end-after entries are undecided). 15 shapes, 0 overstatements beyond SOUND-1/2.
- Liveness rules: SURELY LIVE (class/epsilon path from the consumed entry's target, pushed with R = all and no flags) is spellable, so sound; SURELY DEAD (no possibly-live target) is sound; end-after side entries as undecided is conservative. The all-surely-live union keeps the contract's "no match ends before d+1" because U_d itself does not accept.
- Priority / lazy / first-match: covers read k from the PRIORITY DFA (kn_walk, C7/C10) while the slice is priority-free; any accept on the line ends it, any side accept ends the statement at its depth, so the two agree on every fixed-width cover; checked `ab|abc|ad` cover matcher vs python `re` on `abc`, `xadab`, `aab`, `abd`: 4/4 identical spans.
- Answer defence independent of the slice: C8 requires the DFA's own `w.exact` and set equality for dd < k (known.c:256-280), so a slice overstatement can only cost a cover (or trip the trace assert), never move an answer; held for every case above.
- §3.2 H = exact_len: outcome (3) yields `producer-short`, never an admission past the slice; held by reading known.c:126-170.
