#### R-1 — build — `skip` cannot be a `plan_of` fact: every input of skip is written after `plan_of` — **FIX-NOW (text)**
SEAM-2; VERIFIED V1. Order in `wf_plan_site` (window.c:2516-2518): `decide` -> `plan_of` -> `wf_find_decide` (the pick and
brow) -> Table E -> rows -> `wf_find_prepare` (:2578). HORS's skip needs `w->hl` (written by `b_hors_prepare`, :1999) and
`w->grp` (`find_groups`, :2471); the find rows' skip needs `stop_alone` (:2464). `plan_of` memsets `w`, so an unset skip
reads 0, a REAL entry index. skip reads no renderer-only state, so the lift is possible, at a different home.
Fix: §3 names `wf_find_prepare` (after the search row's `prepare`) as the producer, or a skip column on the search
renderer row. It states -1 for the floor and the fused B-fn row, and lists the readers that move: `ren_search_row.head`'s

Coordinator's leaning: a per-site list of stretches `{i, k, form, j}` computed ONCE in `wf_find_prepare`, after R-1's
skip, read by define and use. That keeps r68 F-10's intent (one selection, two readers that agree) with literal agreement,

the manager's call. Either way the note defines `j` and the trace phase. Effort small.
