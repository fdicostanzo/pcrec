## Headline

The proofs of the individual passes held wherever the critics could exercise them: V5/UNTRAIL, the C-move
with V1/V2 narrowing, D through calls, D over single-byte lookarounds, D183 compaction against UNTRAIL,
and 48,000 trail-cap cells on the specimen twin. What failed is the design's INPUT premise, again.

- Stage -1 extends the event stream with the shapes r3 found. The base emitter has at least four more
  shapes that touch an analysis column and record no event, or a wrong one:
  - guarded `if (c) { SET }` blocks;
  - the `${v}` compare's conditional fail, recorded as an unconditional FAIL;
  - raw cursor moves (`scan_position = ...`) logged as NOTE;
  - the cursor-span consume itself.
- The completeness check counts five chosen text shapes and none of these four, so it stays green.
- Six existing event kinds have no table row.
- Four answer-level twins are CONFIRMED against libpcre2, all built on the default route.
- The general fix is ONE rule, not four rows: every statement the emitter prints inside a matcher function
  is either a typed event or on a declared no-effect list. The count is enforced INSIDE the compiler as the
  V0 refusal, not only as a corpus test.

## Findings and proposed dispositions

Consolidated: S-4 = SEAM-1, and S-7 + SEAM-3 (with S-1/2/3/5 as its instances). Severity first, then the
disposition and a one-line reason.

### Answer level (CONFIRMED, verified)

- **S-1: guarded statement blocks are invisible control flow.**
  - Defect: a conditional capture publish (span rung, revdet) is read as the SET row's must-kill, so V3
    deletes a live write.
  - Witness: `^(?:(?:(a)b)*c){2}$` on `abcc` / `ababcc`. Base and libpcre2 give 1:0,1 / 1:2,3; the twin
    gives 1:-1,-1. The same reasoning breaks V4 and V5's kill.
  - Gate: likely NOT caught by the corpus (no such cell found).
  - **FIX-NOW** (design text): a guard event or a BRANCH around every printed block, a guarded SET is a
    may-write (no kill, no gen), and the completeness count covers `if (` block openers. One instance of
    the S-7/SEAM-3 rule.
- **S-2: the `${v}` caller-variable compare has no row.**
  - Defect: `vm_var` records FAIL then GOTO for a conditional fail, so every column reads a dead end.
  - Witness for V3: `^(a)${v}c` (v=b) on `abc` loses group 1.
  - Witness for D2: `^(?:${v}x|by)z` drops arm 1 (`axz` with v=a, `bxz` with v=b: match becomes nomatch).
    libpcre2 agrees with base.
  - Gate: the D form is caught by `tests/vars/basic.rxt:62`; the V3 form likely is not.
  - **FIX-NOW**: a VE_VAR consume row (FIRST+ OPAQUE, like BREF). State that FAIL ends a path only for an
    unconditional `goto <p>_fail`, and count `goto <p>_fail` sites. Clarify that the CALLOUT row's "next"
    is the trailing GOTO's target.
- **S-3: raw cursor moves are NOTEs.**
  - Defect: FIRST+ is position-blind, and a lookbehind (width 2 or more) is a back-step followed by
    FORWARD consumes, not the CLASSB the design assumes. The restore after a non-atomic lookahead is a
    NOTE too.
  - Witnesses: `^x(?:a|(?<=x|yz))w` on `xw` and `^(*napla:x(?:a|))xb` on `xb` (`--features all`). Both
    are match 0,2 in base and libpcre2 and nomatch in the twin.
  - Gate: likely caught by `lookbehind.rxt:212`, but the proof claim is wrong.
  - **FIX-NOW**: a cursor-assignment event (VE_SEEK), FIRST+ OPAQUE for it, the completeness count covers
    `scan_position =`, and the CLASSB row's description is corrected.
- **S-5: the "span (cursor rung)" row has no producer.**
  - Defect: no Stage -1 event carries the span's class, and VE_RUNG is a side-table record. Read
    literally, FIRST+ sees only the continuation byte.
  - Witnesses: `^(?:[ab]+b|y)(z)` on `abz` and `^(?:.*?x|y)(z)` on `axz`. Both match in base and
    libpcre2; both are nomatch in the twin.
  - Gate: the greedy form is likely caught, the lazy form is not.
  - **FIX-NOW**: VE_SPAN (class id, min), recorded at the rung's entry for every cursor-rung form, and
    counted.
- **S-7 + SEAM-3 (consolidated root): "unrecognised refuses the function" cannot see a statement that has
  no event, and six existing kinds (ASSERT, NOTE, ISLAND, RUNG, STRAT, PRUNE) have no row.**
  - Under a strict reading the build refuses every anchored matcher; under the intended reading (NOTE = no
    effect) S-3 follows.
  - The completeness check is a corpus test, so for a pattern outside the corpus's emitter paths G1 rests
    on coverage, not proof.
  - **FIX-NOW**:
    - an explicit row for each existing kind;
    - NOTE prints no C, by construction;
    - the guard counts every statement (each `;` statement and block opener at matcher-body depth, outside
      `#define`s), not a list of chosen tokens;
    - the same count runs inside the compiler on walks 1 and 2, with a mismatch taken as V0 (refuse, D
      declines), on the `vm_cls_reads` precedent (a count, not a parser);
    - the corpus check then tests that guard.
  - This one rule covers S-1, S-2, S-3 and S-5 and any shape not yet found.

### Answer level, latent (design text)

    - D-introduced sites kept out of the walk-1 numbering;

    - a check that can fail: a one-verdict table {k: DELETE} changes exactly site k.

    (-1,8 against 0,8). The kept-ordinal reading holds on 7 subjects.

  - **FIX-NOW** (one sentence, plus a codegen assertion that the snapshot list and the restore list at
    each site are the same slot sequence, plus this cell as its sabotage).

### Design text (CONFIRMED)

- **SEAM-2: the rounds are an in-memory rewrite.**
  - Round A needs 2 or more productive iterations on real programs (`^(?:(?1)y)*(a|b)$`, and the
    possessive nest takes 3).
  - So either "each pass reads a real emission" and Q3's rejection of an in-memory rewrite are false, or
    "at most three walks" and card 0i's 3x bound are false.
  - Soundness is not at stake: deleting or retagging in an event list is a faithful model of not emitting.
  - **FIX-NOW** (text, before Q3 goes to Frank): state walks 1-3 as emissions and the rounds as a fixpoint
    over walk 2's event list, with the invariant that makes it faithful. Q3 then narrows to whether D (which
    ADDS statements) may be modelled in memory.
- **SEAM-4: "the resume-point cap" that the final walk is said to own does not exist.**
  - `PCREC_MAX_VM_RESUME_POINTS` is defined nowhere, and `limits.h:196-203` rejected it.
  - `npush` has one reader, the listing row.
  - Making that row the final walk's count makes run_ir_listing.sh's under-count assertion compare the
    final walk with itself, so S305 goes UNDETECTED. Leaving it on the pre-pass turns the check red on W7b.
  - **FIX-NOW** (a decision in the text): drop the phantom cap. Then either retire `npush` together with
    S305 by name, or keep it with its own D-free comparison. Also name `vm_reseed_cal[has_push]` (not
    verified) and `tests/vm/run_vm_tests.sh:250` as readers.

## Recommendations

- A D27 spec-first test author, as the design already recommends. Brief it with G1's promise and the

## Lessons for the guide (proposed)

1. **A completeness check that counts a chosen list of text shapes inherits its author's alphabet.**
   Stage -1 listed r3's shapes, and the check counted exactly those, so four more shapes passed green
   (S-1, S-2, S-3, S-5). Count STATEMENTS, and declare the no-effect exceptions.
2. **A check of a mapping that uses the identity mapping is vacuous.** An all-KEEP table cannot reveal a
   keying slip. Two lenses found this independently (S-4, SEAM-1). Pin a map with a one-entry non-trivial
   map.
3. **A build designed to move give-ups to answers states its EXPECTED MOVES in every equality gate** (the
   STEP 0 card, the stage gates, the axes manifest). Otherwise its own first card goes red by design
   (SEAM-5).
