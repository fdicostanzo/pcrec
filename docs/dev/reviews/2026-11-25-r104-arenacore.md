## Findings (PROPOSED dispositions)

### Answer-level for a GATE (the gate passes what it should stop)

- **MEMGATE-1** (memgate; verified HOLDS) `rungs` reads `VERDICT IDENTICAL` when BOTH sides ERR on a rung: `err` is
  counted but never enters the verdict (memgate.py:317-337). D-9 says an ERR side STOPs. A build or driver broken on
  both sides passes R-1. **FIX-NOW**: any ERR side, either or both, is a failing move.
- **MEMGATE-3** (memgate) LAYOUT accepts a cell whose refusing side has NO threshold (refuses up to 64x the cap:
  `threshold B None; heap-extent delta ?`) and any delta size. Meets D-9 literally (requested peak equal), but an
  unfound threshold is a persistent refusal, not a layout move. **FIX-NOW**: LAYOUT needs both thresholds found
  (else MOVED); the delta stays printed, not gated (a delta cap would be an unmeasured constant).
- **CHECKS-4** (checks; verified HOLDS) scope_check's `REFUSES` counts ANY SIGABRT as the expected refusal; a detached
  `reg_fail` prints nothing, so a glibc `free(): invalid pointer` abort passes. Under plant S3601 the D-6 "(dst)
  REFUSED" check PASSES on glibc's abort. Same exposure on free-the-mark 3/4 and stale 6. **FIX-NOW**: the detached
  refusal leaves a tag the parent reads (a tagged stderr line or an exit code only `reg_fail`/`sb_adopt`'s refusal
  sets), and REFUSES requires it.
