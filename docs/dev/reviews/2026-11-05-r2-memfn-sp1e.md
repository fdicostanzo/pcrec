## Lessons for the guide (proposed)

1. **When a row moves between tables, check the gate input as well as the predicate.** F1 survived a move that was byte-identical by construction, because the new table's walk gates on a different `gate_in` from the one the facts were built into. Proposed critics.md line: "When a row moves between tables, compare the gate INPUT each walk hands `gate_check`, not only the row's predicate and contract; plant the contract's opposite and require a refusal."
2. **A row-move map must be checked for correctness, not only for existence.** Proposed check-adequacy addition: "For a declared map or list read by a check, plant a DELETED line and an INVENTED line; both must go red (F3: both were green)."
3. **A declared key whose members are not all in the trace can hide a bypass.** SEAM's equal-record drill (F4) and CHECK's bypass plant B found the same gap from two sides. Proposed seam-lens addition: "for a key the subject declares, check every member is printed in the record; a member missing from the record is where a bypass plant hides."
