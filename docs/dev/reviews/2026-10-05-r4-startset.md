## Verdict

**One BLOCKER, and it is fixed by measurement.** The DFA hat's `T = S ∩ E`
deletes matches whenever `S \ E ≠ ∅` on a seeded machine (sound-F1). The
three repairs the manager asked to be compared are measured in
`../../design/startset/rev2/` (`out/sweep_summary.txt`):

- **They are one set.** On every seeded machine, `E*` (the union of the seed
  states' escape sets) is all 256 bytes. This is structural: two distinct
  seed states cannot both keep a byte, because a byte that begins no thread
  lands in the one seed state its own class names. It holds on 94 of 94
  census rows. So (a) `T = S ∩ E*` is (b) `T = S`. The machine's own floor
  `Tdfa` (the bytes that begin a live thread from some seed state, read off
  the emitted tables) also equals `S` on all 94 rows.
- **(a)/(b) are sound and the r3 formula is not.** Over 13,583,325 cells
  (every subject, every startpos, full capture vector): (a) and (b) give 0
  diffs, 0 static failures (`Tdfa ⊆ T`) and 0 start-byte-oracle failures.
  The r3 formula gives 322,771 diffs on 20 rows, and fails both checks on
  21. Local libpcre2 agreed with base on every cell.
- **The choice is the admission rule.** Admit only when `S ⊊ E` (the scan
  set shrinks): that is (c) by algebra, and it gives identical tables on
  identical movers. Admit when `|S| < |E|`: that adds 15 corpus-only test
  shapes whose scanned set swaps members, which no cost argument covers.

The recommendation (rev-2 Q-R1) is (a) as stated, `T = S ∩ E*` (= S),
admitted iff `T ⊊ E`. That is the manager's (a), mover-identical to (c):
18 bench / 38 corpus. The r3 count was 18 / 58.

**Everything else is accept-fix or accept-measure.** Four findings change a
D148 ruling's text or basis and go to Frank as rev-2 questions (Q-R2..Q-R6).
