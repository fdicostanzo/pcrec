## Lessons for the guide
- A witness that compares SUMS keyed by row, with absent = 0, cannot see a deleted zero-reach row; a declared difference must be derived and compared, never only typed (critics.md / learnings §3 candidate).
- A census floor with slack below the map size is a silent-deletion allowance; floors on hand-declared maps should be exact.
