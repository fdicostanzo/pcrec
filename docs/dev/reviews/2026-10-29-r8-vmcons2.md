## Lessons for the guide (proposed)

1. **One writer closes record EXISTENCE, not record KIND.** A kind checked by counting tokens in the
   printed text is a chosen alphabet again. Render the text from the record where the kind matters, and
   choose sabotages by token CLASS, including the mirror of each (SOUND-6, FIX-6, FIX-10).
2. **A count over emitted C states its text domain.** Comments, string and char literals (which carry
   PATTERN bytes), macro bodies and trace text all reach a strstr count. A domain that differs between
   axes moves code across that axis (FIX-1, FIX-5/SOUND-4 (i)).
3. **An "exactly these lines change" check lists the derived lines one change legitimately moves**:
   counts printed elsewhere, renumbering, text copies. Otherwise the check is red on a correct build and
   gets loosened until it cannot fail (FIX-2).
4. **A new buffer joining a buffer family inherits every record and obligation the family carries**:
   decision-length records, `.cx`, `abort_over`, the balance check, the mid-line guard (SOUND-3 = FIX-3).
5. **A group-membership rule needs its opener ON the path.** "The open X" must be defined by a record
   the walk passes, not by position or a shared local (SOUND-1, SOUND-2).
