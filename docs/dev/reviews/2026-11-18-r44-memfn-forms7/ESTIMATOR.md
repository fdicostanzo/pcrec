- Fix direction: fit the variant effect per (text, regime) (a row level and a variant effect per cell group; df is then 5 launches x the arms of that text there, so the estimate then needs its own upper bound like every other term; the text-level point estimate holds without one today, see PROBED-AND-HELD), or test for a variant x regime interaction and refuse/record; and add the interaction model to drill (xxiii) as a gated row.
