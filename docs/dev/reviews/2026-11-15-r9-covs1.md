## Lessons for the guide (proposed)

1. **A coordinator-built nearby-regression plant turned a SUSPECTED escape into a confirmed
   answer-level gap in about 5 minutes.**

     not build, the coordinator builds it as one more incremental plant copy and runs the
     arm's comparison over cases.tsv (not the suite) before drafting."

   SAME/SILENT/LOUD without running make.**

   - Proposed skill text (§3.2, code mode with sabotage rows): "build `plants/<ID>/` per
     moved row from the row's own BEFORE/AFTER."

   bare run silently discarded measured weights (TRADES-1).**
   - Proposed lesson for `critics.md`: the trade lens diffs every regenerated table's
