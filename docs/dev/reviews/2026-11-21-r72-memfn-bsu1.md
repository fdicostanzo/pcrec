## Lessons for the guide

- A refactor that moves a render-time computation to plan time leaves a recomputation behind, and the critics found it by reading, not by probes. The 393 compares were all SAME. For a zero-mover unit, the emitted-vs-replaced lens should ask "which stored fact does the renderer still re-derive?" as its reading sub-part. This is the §4 note "cap probes, spend on reading", made specific.
- A new positional column on a renderer row needs its line in the table self-check in the same change (SLOT-5). Add this to the check-adequacy lens's "new or changed check" list: "a new table column -> its hole check".
- Coordinator plants settled both SUSPECTED coverage claims in about 3 minutes (3 plants, as in r64). Byte movement is settled in the round, and the suite verdict is handed to the fix lane, because critics never run suites.
