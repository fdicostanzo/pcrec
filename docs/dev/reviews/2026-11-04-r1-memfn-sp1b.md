## Lessons for the guide (proposed)

1. **A code round that moves or deletes kit text runs the repo's anchor checker once** (`python3 -I scripts/m6read_check_sab_anchors.py`, read-only, seconds) in the check lens. A plant can quote a function's BODY rather than its name (S1094), so a grep of the deleted names misses it. This is the learnings §3 "population nobody counts" shape: count EVERY anchor, not the named ones.
2. **The COMMON brief of a rate-sensitive subject names how to reach each rate regime**: default (the prior), NONE (`-e utf8`), all-tie (`--analysis uniform`), and a real bundle (lookup is `-I DIR` + `--analysis NAME` → DIR/NAME.rxt, defined name = file name). emit spent 220 of its 1,500 compiles on a misread bundle lookup.
