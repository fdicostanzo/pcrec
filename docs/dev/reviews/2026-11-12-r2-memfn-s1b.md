## Lessons for the guide (proposed)

1. **A fix that adds a check names its plant in the same breath.** R30B-3: S1-2 made ASK-6's refusal loud and gave it
   a reach witness for the green bytes, but nothing that reds when the new check is deleted. Readiness addition: "a
   new check added by a fix carries a control that reds without it".
2. **A cell names the build that counts it, per layout.** RK383-1 repeats r1's lesson 1 one level down: the fix named
   the instrumented build but not which layouts that build's counters are live in. Extend lesson 1: "and show the
   counter is live in every layout/population the cell names".
3. **A plant's named detector must be the FIRST one to red in the runner that runs it.** RK383-2: a stronger,
   earlier detector (the oracle) turns a correct plant into RED BUT NOT BY ITS DETECTOR. Check-adequacy addition.
4. **A versioned-data change lists the WRITERS of the pinned artifacts, not only their readers.** RK383-3 extends
   r1's lesson 3 (check_store) to est.py's set writer and the independent recompute.
