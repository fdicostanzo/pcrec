**HOUSE-1 (CONFIRMED by reading + grep; severity: answer-for-the-set if the draft step is run as written; effort S)** est.py:178-185 `form_hash()` shells out to `TREE/build/arm_fixtures`. `grep -rn build/arm_fixtures` over Makefile, scripts, tests and docs finds only this line; `ls T/build` has no such binary and no make rule builds it. link.py:37-43 `fx_path()` builds its OWN `RUNDIR/fx` from the same source. Two homes for "the fixture binary" and two lookups of "a form's hash" (link.py:54-61 reads FORMCLS lines, est.py:178 reads FORM lines). Observed: `est.py draft` on a real rundir raises FileNotFoundError (no "build the fixture" message; the `raise SystemExit` at :185 is only reached if the binary exists but lacks the id). Shared abstraction: est.py should take the fx path from the rundir (link.fx_path) and one `form_hash(fx, form, cls)` (link.py:54).

**HOUSE-2 (SUSPECTED; severity: design/answer; effort S)** est.py:217-222 `write_draft` writes each verify row's `deps` as `kit:form.<id>=<FORM hash>` = `mf_form_hash(id)`, the CANONICAL instance (w2 / c2 / l1). link.py:294-299 proves each cell's site text equals the FORMCLS hash of the (form, cls) instance actually timed. For cls w1, w3, c1, cn the dep hash is therefore NOT the hash of the text that was measured. Check C (finder_check) compares recorded deps with mf_form_hash(id), so it stays green by construction (a control sharing a source with what it controls, learnings §3). Confirm: ask whether the design wants the canonical or the per-class hash in `deps`; if per-class, the dep grammar needs the cls.

**HOUSE-3 (CONFIRMED; severity: answer-for-the-record; effort S)** record.py:81 `cause = {"never": "declined-j1b" if j == "J2p" else "failed", ...}.get(s, "failed")`. J2p in state `never` is labelled `declined-j1b` whatever J1's verdict was (the record's own `j1_verdict` is in `rec["run"]`, line 57). A J2p killed by the queue under J1 (a) or (c) is recorded as declined by (b). Unknown states also fall to "failed" silently (silent default USED). Should read `j1_verdict` from rec and use a declared state->cause table that refuses an unknown state.

Holds today (L values match). The facts are already available: `facts(fx, form, cls)["L"]` (arm_fixtures f_L). The null base should take L/run/mask/members from the paired verify arm's facts, not a literal table.

**HOUSE-12 (CONFIRMED; severity: maintenance; effort S)** formhash.c altitude and shape. (a) `fh_render` (formhash.c:387-~520) is a four-arm switch whose arms each rebuild the site by assignment; `shapes[]` already tables the names but not the builder, and `h->lo = e->shape == MF_FH_RUNCMP ? sh->cand : sh->lo` is an if on shape inside the generic path. A per-shape builder column (`shapes[].build`) plus the common block in `fh_site` would remove the switch and the nested `{ const site_rec *r ... }` block. (b) The 13-column positional `entries[]` initializers carry `policy` and `deny` columns that are the same in all ten rows (MF_P_PORTABLE_ONLY, NULL): data with no variation; per D77 a column with no reader needing it should wait. (c) `mask[64]` and `strlen(e->bytes) > sizeof w->mask` is a bare size with no label; `char buf[8]` fine. (d) `mf_form_row` renders a whole site (a full art + two arenas) to read one name, and `mf_form_site_split` re-calls `nb_put(&all, "", 0)` to force a non-NULL buffer; a header would say why.
