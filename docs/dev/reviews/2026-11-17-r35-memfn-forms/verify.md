### EMIT-3
- verdict: PARTLY. "Two" is definitional at its own boundary, the compiler takes the residual choice, and the real cut-over is h (the cards measure it). What is left is a doc-sized label, not a speed finding.
- D149 (`git show f2070d701:docs/dev/decisions.md`, :9111ff): covered constants include "every ... short-span cut-over ... hand-picked number in a kit form"; each is MEASURED, DERIVED ("from a stated quantity") or LEFT TO THE COMPILER; an unlabelled one is "LABELLED in place as an unmeasured default".
- code: window.c `wf_loop_len` ends `return j - i >= 2 ? j - i : 0;` (comment: "at least 2, or 0 where ... fewer than two such entries follow"); kit.h:347-349 states it as definitional ("a loop takes two positions"). The promise (§3 "The forms", :430-436, :672-678) defines the repeat as "two or more CONSECUTIVE stated" positions, "3. a LONE test: anything else".
- judgement: a one-entry loop is the lone test plus an induction variable and a back-edge: it can only cost, so excluding it is a DERIVATION, not a choice. Whether 2 (rather than 3 or 4) is the smallest worth emitting is a cut-over in principle, but checked: `kit.sh subject-h VERIFY/emit/d30 VERIFY/emit/dig32.pat /dev/null --harness=span-head=30` (`Pattern: \d{32}`) emits `size_t rx_mf1_j = 30; for (; rx_mf1_j < 32; rx_mf1_j++)`, and `gcc -std=gnu11 -O2 -w -c -fopt-info-loop-all` on it reports `optimized: loop with 2 iterations completely unrolled`. So at the target compiler's -O2 the 2-entry loop becomes the two inline tests: the machine-code choice is LEFT TO THE COMPILER; only the emitted C text differs (a size-of-source matter). The constant that sets which offsets loop is the head h, which is on the cards' grid and labelled UNMEASURED DEFAULT (CHOSEN grid top) until they run.
- corrected claim: not an unlabelled tuning constant with a speed cost; at most a D149 label gap: the comment at wf_loop_len should state the derivation ("a loop of one is a lone test; short trip counts are left to the compiler: gcc -O2 unrolls the 2-trip loop completely, observed").
