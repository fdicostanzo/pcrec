## Lessons for the guide

- A shell stage gate is code: a `case` whose pattern is built from the subject it tests is always true, and `set -u` turns an
  unset optional into a stage-killing exit. A lane that adds a stage gate to a runner script runs a stubbed copy over every case
  of the gate's input (unset, 1/1, K<N, N/N) before delivering; the review's parallelism lens gets the gate (both lenses found it
  here in minutes with a stub).
- A measurement report (per-doubling CPU) that shares a pool with a verdict sweep inherits the pool's contention: measurements
  run serial or repeat-min by default.
