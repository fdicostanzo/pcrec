## Lessons for the guide (proposed)

1. **A late reroute edits a record: list every sibling field.** The fix-induced lens's sibling-field rule (r7 landwalk3) applies to code too. The switch set `fit.chosen` and `fit.prefilter` and left the selection reason (CONTRACT-2). PROPOSED text for the contract lens: "when the subject changes an engine or route decision after it was made, list every field of the decision record and every stamp read from it, and probe each retry rung that can produce the record."
2. **Compare every entry family, not only the search.** The prefilter guards `search`/`next` but not the anchored `match` entries, so a switch "answer-identical because the prefilter already said no" moves `match`'s give-up surface (CONTRACT-1). PROPOSED for the contract lens: "for an engine swap, drive every exported entry family, including the anchored ones, at default and at tiny budgets."
3. **A sound check with a false comment is a finding** (DFAMINW-1). The soundness lens should restate the real argument, not only test answers.
