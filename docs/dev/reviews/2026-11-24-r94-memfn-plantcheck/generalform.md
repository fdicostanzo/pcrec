- Recommendation: enforce in the SAME pass, no second decoder: for ids present in both, compare (decoded runner FROM/TO) with (mech SAB_BEFORE/AFTER) after stripping a trailing `/* SABOTAGE Sxxxx */` and comments; red on material difference; the 23+16 pass today so it needs no data change. Better: derive one from the other (mech row sources the text; the runner `plant_spec` case for a twin id becomes a reference), but that crosses the three dialects and is a design step.
