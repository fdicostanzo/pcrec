## Lessons for the guide

1. **A "bounded scan helper" is not an "enforced catch-all".** The r1 note asked for the latter; the fix lane built
   the former and wrote the invariant into a comment. Brief fix lanes with the CHECKABLE form of a structural
   ask ("a nonzero arm on the last row must be impossible or red").
2. **A derivation is a reader with a grammar.** Deriving a list from a source file by `sed` introduces a second,
   narrower parser; derive with the source's own reader (cpp for a .def), or count both ways.
3. **Restating a floor is not tightening it.** When a floor is re-expressed over a different population, compute
   whether the old form already enforced the same bound before claiming a gain.
