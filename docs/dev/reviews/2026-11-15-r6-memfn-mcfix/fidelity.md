### FIDELITY-1 — TIMED-SHAPE passes an out-of-line site reached through a section-symbol reloc, an indirect call, or an external definition (CONFIRMED; measurement; effort S; blast: every find/cmp arm of every slot job)
link.py `timed_shape_check` (docs/design/memfn/span_cards/slot/link.py:203-234) refuses only a callee whose NAME is in the object's own `nm --defined-only` t/T/w/W set. Planted copies of the dry kit's arm64.c (mfind-w32 find_hit 16.0), compiled with link.py's CC, checked by the copied link.py (`pl/drive.py`, my dir):
- p1 site `noinline` (same section) -> REFUSE; p6 second caller in the timed TU -> REFUSE; p7 w32 rung noinline -> REFUSE (held).
- p2 site `noinline,section(".text.site")` -> PASS, ext=['.text.site'] (reloc `R_X86_64_PC32 .text.site-0x4`: gas rewrites a local symbol to its SECTION symbol, which nm does not list as a defined function, so it is filed as an "external").
- p3 site `noinline,cold` -> PASS, ext=['.text.unlikely'] — the shape gcc itself produces for a static function it judges unlikely/once-executed (`-freorder-functions`, default at -O2) — no source attribute needed.
- p4 site through a function pointer (`call *%rax`) -> PASS, ext=[] (the regex needs `<sym>`; indirect calls are never seen).
- p5 site defined in ANOTHER object (`extern mf_ext`) -> PASS, ext=['mf_ext'].
Root: the returned `ext` list is DISCARDED by build_objs (link.py:589 `timed_shape_check(a.name, o, sym)`); nothing holds it to the form's expected externals (memchr for fn-memchr, NONE for mfind-*). Fix: refuse any callee not in a per-form allowlist (mfind-*: {}, fn-memchr: {memchr}), resolve section-symbol relocs (or refuse them), refuse indirect call/jmp in `_time`. Today's 172 dry arms are clean (0 calls in mfind `_time`, one `memchr` PLT call in fn-memchr), so this is a guard gap, not a wrong timing now.
