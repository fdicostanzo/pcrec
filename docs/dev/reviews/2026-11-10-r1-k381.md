## Lessons for the guide (proposed)

1. A "reader asks the one decision" claim is checked by asking whether the reader's ANSWER can
   vary: a call whose reply is constant under the caller's own arguments is a census entry, not a
   reader (K1, found by all four lenses). Candidate line for critics.md: "for each counted reader
   of a decision, name one input under which its reply differs from the constant; none = a
   decorative caller".
2. A census over call text counts call SHAPES; plant a non-call spelling (alias, function pointer)
   before trusting "a reader left asking X directly reds" (K5). Already in the lens table's check
   adequacy row as "a BYPASS whose text contains none of the conforming call's tokens"; this round
   shows the bypass must also be ADDED, not only substituted (substitution reds by the lost call).
3. A trigger must name an instrument that can observe it (K3): when a design writes "trigger: check
   X finds Y", the slot lens asks whether X can see Y at all.
