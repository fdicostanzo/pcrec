## Themes (dispositions condensed from dispositions_r2.md)

**U-A Engine zero-means-X** (customer B2, M1; soundness B3). ACCEPT. The
engine follows no-silent-defaults itself. `routes == 0` is a table-definition
ERROR checked at registration; an "all routes" table writes `MF_ROUTES_ALL`.
A route is an INDEX. Scope has an explicit `MF_SCOPE_ONE` token distinct from
every real slot value (`CAND_SLOT_WINDOW == 0`). `honours`/`requires` are
explicit `MF_HONOURS_NONE/ALL`; 0/0 in a profiled table is a definition
error. The appendix's `dfa_pfs` row is corrected: today 0 means DFA-only.

**U-B Predicate signature** (customer B1). ACCEPT. The row head carries no
`applies`. Each table has one `test` thunk generated by `MF_TABLE_TYPED`,
which casts the row to RowT and calls the customer's OWN predicate in its
own type and polarity (`bool(const DfaSel*)`, by pointer). NULL-applies rows
(`fit_rungs`) and tag predicates (reseed rows) go through the same thunk.

**U-C Totality** (customer M3). ACCEPT. The engine never aborts
(`MF_NONE_ABORT` dropped). Each table has an `on_none` hook (pcrec:
`pcrec_ctx_fail`; kit: `kit_fail`), plus a per-query `MF_Q_NULL_OK` option
for the both-walks oracle.

**U-D Route carrier** (customer M2). ACCEPT. `mf_query` has no route; the
typed wrapper reads it from ctx through the table's `route_of` accessor, so
there is ONE carrier.

**U-E Trace absorption** (customer M4). ACCEPT, and NARROW THE CLAIM. The
engine absorbs ROW-CHOICE records only. The record prints the row's trace
token through the table's `tok` accessor (identity != spelling); a route may
be "-". RECF/ROUTE pseudo-records stay pcrec macros (not decisions). The call
is the macro `MF_SELECT(t, ctx, "site")`, which pastes `"" site`, keeping the
literal check and building nothing before the walk. (Differs from the
critic's fix: `tok` accessor rather than a separate `label` + route-name
list.)

**U-F Listing** (customer M5). ACCEPT. The engine only iterates rows.
Listing projections (`list[route]`, `order`, unlisted rows) stay the
customer's. "Force = deny of the alternatives" and the `strategy_denials`
remark are retracted.

**U-G Record nesting** (customer M6). ACCEPT. No parent pointers. A
caller-owned bounded stack plus a depth counter, reset on entry, so it is
longjmp-safe.

**U-H Missing customers** (customer m7, M7). ACCEPT. Add the `pss_verdict`
ladder, `pcrec_reseed_rows` and `fit_rungs` to the customer table with their
encodings: the degrading/FAST_OR_FAIL class deny, NULL-applies rows, and the
`fit_rung_of(FIT_REFUSE)` fallback.

**U-I Gate grain** (rvc M1; soundness M4; r1 soundness M1 partly). ACCEPT.
With the default column gone, `nondefault ⊆ honours` is meaningless.
`honours` is per (field, value class), classes in `fields.def` (miss ∈
{MISS_N, OTHER}, floor ∈ {ZERO, OTHER}). The gate admits a row iff every
stated (field, class) is honoured. pcrec stating `floor="0"` therefore stays
on ofsskip and no byte moves; "zero" is recognised by token identity.

**U-J Stated mechanism** (soundness B1, M6, M7; r1 soundness M3 not).
ACCEPT, with scope REFERRED to Frank as Q-ROW-5. A STATED BITMASK set by
builder macros (`MF_SET(site, field, value)`), inside the kit's `MF_SITE_ABI`
4→5 bump, covers enums and numerics whose 0 is a real value. Each row has a
READS list; the chosen row's reads must all be stated. The independent check
is a G2 POISON differential (undeclared hooks set to poison; output must be
identical). A full field inventory gives a token or a WRITTEN exemption per
field ("an absent offer is not a value" for callbacks). Rev 3 carries
Appendix B: each kit row's reads/honours from the audit matrix.

**U-K Snapshot placement** (soundness B2, M1, M2, M3; rvc M2, M3). ACCEPT.
Per-shape placement table: STMT a block top; EXPR GNU `({ })` (as generic
does); FUNC arguments are snapshot by C but unsequenced, so the kit
snapshots in a statement before the call where the form has one, else hooks
must be side-effect-free and G2 checks it; ASSIGN with `result_decl` names
unique per use; ADVANCE `more`/`peek` EXCLUDED (per-iteration by design).
Snapshot only the hooks the chosen row READS (keeps `-Werror` clean).
Reserved prefix `_mf_` (block scope, not user-choosable via `-p`); hook text
containing `_mf_` is refused. A bare `break`/`continue` in `on_miss`/`on_cand`
inside a kit loop is REFUSED. The spelling is fixed in rev 3, not at T3.
`--memfn=no-snapshot` is DROPPED; G1's comparator is the pre-T3b commit, an
exception to D144 item 4, REFERRED as Q-ROW-6. Rule 1 (side-effect-free
hooks) stays; the D80 hunk must not advertise calls.

**U-L Sequencing** (soundness M5). ACCEPT. Three steps that each stay green:
(1) R-6, pcrec states every value (zero-mover; nothing refuses yet);
(2) G2's blinded update; (3) the kit turns the refusals on. R-6's inventory
comes from the U-J field inventory. The `miss_is_n`, `ofs_fn_call`,
`ofs_fn_applies` and generic `need(miss)` rows change in step (1).

**U-M Trace wiring** (rvc M4). ACCEPT. The census uses `emit_sweep --trace`
(KITFLAGS inherit CFLAGS); no Makefile change. Counters are kit-private
statics outside public structs (no layout mismatch). The stderr tag is
distinct (`MFTRACE`, never `CANDTRACE\t`). The trace line format is a
documented contract in `memfn/docs`.

**U-N Cell independence** (rvc M5). ACCEPT. A committed `cells.tsv` written
by a BLINDED author, diffed by name against `fields.def` classes both ways,
plus census counts (compiles traced, witnesses executed, cells hit), all
with non-zero floors.

**U-O Q-ROW-4 fallback** (rvc M6). ACCEPT. If ruled no, the engine stays
kit-internal now (static, no `MF_NS` export, no `memfn.h` section) and is
exported when the first pcrec table adopts it.

## Questions for Frank

**Q-ROW-4 (pending): is a generic table engine in the kit's charter?**
D146 made the kit a delegate for search sites; a decision engine widens it.
Recommendation: YES, as a kit UTILITY under `MF_NS` with a charter line in
memfn/CLAUDE.md, adopted by pcrec tables only as an offer after START-TABLE
C7 (Q-ROW-3 answered "not now"). Revised fallback (U-O): if NO, the engine
stays kit-internal now (static, no `MF_NS` export, no `memfn.h` section) and
is exported when the first pcrec table adopts it (D77 trigger). T0 and Layer
2 are identical either way, T0's fixture is cut to cost the same under both
answers, and only the header moves. State plainly that "no" makes the
generalized-engine and decisions-in-kit goals deferred, not dropped.

**Q-ROW-5: does no-silent-defaults cover enums and numerics whose 0 is a
real value?** Rev 2.1's NULL-means-unstated reaches only pointer hooks
(about a third of the fields rows read; `MF_EMPTY_MISS`, `MF_REQUIRED`,
`end_back`, `plan_hint`, `comment_tier` are all silently forgettable).
Mechanism (U-J): a stated bitmask written by builder macros
(`MF_SET(site, field, value)`), part of the `MF_SITE_ABI` 4→5 bump already
planned, plus per-row READS and the G2 poison differential. The alternative
is to scope the ruling to text hooks only. Recommendation: YES. Half a
ruling leaves K96's shape open for most fields, and the bump is already
paid.

**Q-ROW-6: the snapshot carries no public deny; G1 compares against the
pre-snapshot commit.** `--memfn=no-snapshot` is dropped because a registry
deny that reinstates S2-S7 is inexpressible (no unsupported kind), would be
swept by `test-axes`, and puts a hazard switch on the user surface. G1's
OFF arm is the pre-T3b commit, per the memfn/CLAUDE.md "per-migration-step
comparator" idiom. This is an exception to D144 item 4 ("a byte-moving
change carries its own deny") for a CORRECTNESS change, not an
optimization. Recommendation: YES; record the exception where the rule
lives (decisions.md), and note the lexical refusals survive.
