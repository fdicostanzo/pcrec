### RD0-3 CONFIRMED (code read) — C2's classifier needs a byte in NO position's set; §5.2's own draws make that byte not exist
- Where: part_d.md §5.2 (Generator: "33-128; exactly 128", "scattered random members", lengths 2..MF_WSPAN_POS) against `memfn/tests/g2/g2_pres_run.c` `filler()` (:141-149 at 35bee4da9: the first byte in no position's set, else **0**) and its users: COVER and EXTENT `memset(buf, F, n)` then plant one occurrence (:369-395), EXTENT breaks position j with `buf[gap + j] = F` (:388), SCAN's no-candidate subject (:431).

- Fix (text): §5.2 states the classifier's breaker per position (a byte outside set j, which exists: no position is full, 128 is the max) and a background byte outside the VERIFIED positions' sets (or outside set[scan]) for COVER/SCAN, or bounds the draw so that a global filler exists and counts the sites where it does not.
