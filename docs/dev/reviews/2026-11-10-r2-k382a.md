## Lessons for the guide (proposed)
- A record written by a wrapper around the checked callee inherits the callee's arguments: for a contract stated in the CALLER's frame (origin = attempt start), record at the caller boundary (ORC-1; learnings §3 shared-source in a new shape).
- A negative probe built from one filler byte proves "compared", not "compared exactly": EXTENT-style classifiers need per-bit near-miss probes (FAM-3).
- An OWED branch must flip to FAIL in the change that lands what was owed (ORC-2).
