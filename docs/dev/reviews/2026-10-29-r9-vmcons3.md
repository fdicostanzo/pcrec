## Headline

- **No stock answer moves, and (a)'s bytes are protected by E1.** Every answer-level result is a
  rule-as-written twin for stage (c). The inversion did what r8 asked for the core kinds: no mis-typed
  record of a PRINTING control operand was found (conditional fail, conditional goto, guarded SET, CASE,
  nested checkpoint, CONSUME width all held by construction).
- **The guarantees hold only for bytes a renderer prints, at record time, from a printing operand.** The
  round found the seams where that premise fails, and every finding sits on one of them:
  1. **Bytes rewritten AFTER rendering**: the respell post-pass (truncate and regrow of the whole body,
     SOUND-5, FIX-4 ii) and the prefix placeholder rewrite at `facts_force` (SOUND-2). The lexer, the
     census, RT and the record offsets each read a DIFFERENT domain (render-time placeholder text, final
     text, uncut offsets: SOUND-2, SOUND-7, FIX-4 iii); the prototype evidence (49 windows, 0 refused)
     was taken in the final-text domain the in-compiler lexer never sees.
  2. **Operands that do not print** (group ids, island F and nullable, SPAN first-byte class, PUSH site
     kind, RESTORE ordinal): E1 and RT read text, so nothing detects a wrong one (SOUND-6, SOUND-8), and
     one pair of kinds prints identical bytes (SPAN init-only = LSET on the span cursor, SOUND-1/FIX-3),
     falsifying "a wrong builder is a different program".
  3. **Text the renderer prints but the row does not carry**: the macros' FRAMES exits in
     SET/SNAPSHOT/RESTORE/PUSH/CALL and CALLOUT's cursor write (SOUND-4); the counters stated over "SET
     records" after SNAPSHOT/RESTORE left SET (FIX-1).
  4. **The lexer's rules are token-shape denylists**, not the classes they claim: a CLEAN kit window can
     write slots through `__builtin_memset(slot_values + 2, ...)` (twin: group 1 -> -1,-1) and the
     registry's "pure" `decode` has an out-parameter (SOUND-3); R4's registry is filled after the walk
     (FIX-4 i) and its kit rows need a kit fact the D146/D147 contract does not carry (FIX-5).
- **Proposed path to the (a) go:** a short rev 3.1 text patch. The cheapest (fixind's FIX-6, which the
  coordinator recommends): **move the fragment lexer, the helper registry, FL and CEN out of (a) into (c)

## Findings and proposed dispositions

### Answer level (rule-as-written twins for (c); verified against libpcre2 10.46; no stock answer moves)

- **SOUND-3** (HOLDS). R3 defines "read" by token shape and R4 covers only prefixed names, so a kit
  window extended with `&& (__builtin_memset(slot_values + 2, 0xff, 2 * sizeof *slot_values) != 0)` lexes
  CLEAN. C8 `^(a)b+c` twin: `abbc`/`abc` group 1 -> -1,-1; base and libpcre2 0,1. Also: `<p>_decode` (a
  registry "pure" helper) has an out-parameter (src/enc/enc_utf8.c:234-235); R1's `break`/`continue`
  confinement premise is false inside the `do { } while (0)` renderer macros (unreachable today). The
  critic lists 15 CLEAN write/exit shapes.
  **PROPOSED: FIX-NOW (in the stage that builds the lexer).** Restate R3/R4 as an ALLOWLIST over the
  window's whole token stream (scope names only as rvalue heads; declared block locals; registry helpers
  with declared OUTPUT parameters; a declared list of unprefixed pure callees; refuse `*`-deref, `=`
  outside block locals, `asm`, unlisted `__builtin_`, preprocessor lines except the kit's guard arms;
  `break`/`continue` only inside a loop the window opened). Port the 15 rows to FL.
- **SOUND-8** (HOLDS; overlaps FIX-9). S-6 is stated two ways; the kind-table form (kept SNAPSHOT and kept
  RESTORE lists are the same slot SEQUENCE) passes a RESTORE with a stale ordinal. C6 twin (V1/V2 by
  hand, kept restores at original ordinals): `xaxabyby` 1:-1,8, `xaxaxabybyby` 1:-1,12; base, renumbered
  twin and libpcre2 1:0,8 / 1:0,12. C6's sabotage claim ("S-6 fires") is false under that statement.
  **PROPOSED: FIX-NOW (design text).** The RESTORE renderer derives `j` from the kept-snapshot list at
  render time (no ordinal operand; the mis-typing becomes impossible), S-6 stated once; M-row "RESTORE
  with a stale ordinal" with this witness.
- **SOUND-6** (PARTLY). The SPAN row says "class" where rev 2 said "first-byte class"; for a stride-k span
  the emitter holds a per-position sequence. Reading "class" as the last position: `^(?:((?:ab)+)c|bd)`
  dispatch twin drops `abc`, `ababc` (libpcre2 = base). PARTLY because rule 3's bullet says "first-byte
  set", so the row text admits the bad reading but the rules do not force it. The broader finding
  stands: non-printing operands (ids, F, nullable, first-byte class, PUSH site kind) have no detector in
  E1/RT and no M-row; wrong ids/placement fail safe (OPAQUE), a too-small F does not.
  **PROPOSED: FIX-NOW (design text) for (c).** Restore "first-byte (`seq[0]`)"; every first-byte operand
  DERIVED by the builder from the value it renders, never passed separately; PUSH site kind from the
  builder entry point; an M-row class "non-printing operand wrong" with "contributes the WRONG bytes"
  sabotages on C5c/C7a/C7b.

### The seams of "rendered from the record" (structural; verified)

- **SOUND-2** (HOLDS). Emitters see `PCREC_PREFIX_PLACEHOLDER` (`\x01q`, internal.h:742-743;
  compile.c:2020-2021); the real prefix is written at `facts_force` (compile.c:3489-3497), after every
  walk. The lexer (builder step 5) therefore reads placeholder text; R2/R3(prefixed)/R4 as written and
  prototyped are dead on it (4/4 sabotage windows CLEAN render-time vs REFUSED final). The census lexed
  the FINAL `.c`. Unsafe direction. **PROPOSED: FIX-NOW** if the lexer stays in (a), else with it in (c):
  state the domain as render-time text with the placeholder as an identifier lead; FL rows and CEN in
  that domain plus a placeholder-label control row.
- **SOUND-7** (HOLDS). `at`/`end` are uncut lengths; the lexer slices `[at, end)` of the written body:
  under default comments every window after the first muted role is mis-sliced (re-run: 116 muted
  bytes; spurious R4 refusals), and verdicts would move with `-fcomments`, contradicting the design.
  **PROPOSED: FIX-NOW (one sentence):** store text offsets as well (lexer, RT) and keep uncut for tiling.
- **SOUND-5 + FIX-4 (ii)** (HOLDS). `vm_cls_respell` (emit_vm.c:1726-1764) truncates and regrows the whole
  body after the walk; shipped CLS bytes are not any renderer's; every later record's offsets are stale;
  the design both claims tiling catches `b->len = 0` and exempts this one truncation unstated. Nested
  builders (BREF/VAR -> WORK, GOTO/BRANCH -> CHECKPOINT, CONSUME/SPAN -> CLS/KIT) have no tiling rule;
  tiling compares lengths so "by any route" means appends and truncations only.
  **PROPOSED: FIX-NOW (design text, bears on (a)):** state the respell as a declared exception or make it
  a record-level re-render of CLS pieces (FIX-12's general form); state RT's domain (final text) and the
  tiling nesting rule (a record stack); say "appends and truncations".
- **SOUND-1 = FIX-3** (HOLDS). emit_vm.c:5159 (SPAN init-only) and 5221 (LSET assign) are the same format
  string. "Calls the wrong builder = a different program" is false for this pair, so the SOUND-1 fix is
  invisible to E1 and RT; no M-row. **PROPOSED: FIX-NOW in (a)** (where typing is fixed): a pairwise
  template-collision check in render_check/RT; a non-text discriminator (CEN count "member with no opener
  record" = 0, or the span cursor writable only by SPAN and its members); M16.
- **SOUND-4** (HOLDS). RX_TRAIL (inside every `<P>_SET`), RX_PUSH and RX_CALL return `R_FRAMES`; rows for
  SET/SNAPSHOT/RESTORE/PUSH/CALL list no exit, so M10's mechanism is false for them. CALLOUT's consuming
  SUCCESS edge writes the cursor (emit_vm.c:9082, 9146-9148), absent from its row. Safe today by the
  columns' OPAQUE/kill-all defaults. **PROPOSED: FIX-NOW (table text) before (b)/(c):** add the exits and
  the cursor write; RT's unit half reads the prologue's macro definitions (or a macro-effects table
  checked against them).
- **FIX-1** (HOLDS). Today `vm_set` bumps `nset`/`emitted_set` for snapshots and restores; the witness
  `^(?:(?1)b)*(a)$`'s back-edge checkpoint exists only because of snapshots; `margin = 12` counts them.
  Rev 3 states K2, K4 and the counter move over "SET records". **PROPOSED: FIX-NOW (wording):** one
  population, "trail-write records" (SET, SNAPSHOT, RESTORE with verdict KEEP), used by nset,
  emitted_set, K2's pin, K4 and the listing's `set` op.
- **FIX-4 (i)** (HOLDS). The helper registry R4 reads is filled by the prologue/kit-helper writers, which
  run after the walk (emit_vm.c:14529, 14554; memfn.h:1346-1352): at lex time it is empty. **PROPOSED:
  with the lexer's stage** (see FIX-6): a walk-time registry from the interned class pool and the art's
  recorded helpers, with a control equal to the prologue's emitted definitions.
- **FIX-5** (HOLDS). `mf_result` carries no helper names or effects, so the registry's kit rows are a
  typed list (the thing R4 was meant to avoid) or a new kit fact. **PROPOSED: PLAN** (file the kit
  request, facts only: helper name + which parameters it writes; D157), due with the lexer's stage.

## Lessons for the guide (proposed)

1. **Every rewrite AFTER render is a second writer.** A design whose guarantee is "rendered from the
   record" must list every post-render transform (post-passes, placeholder/prefix rewrites, copies) and
   say which domain each check reads (SOUND-2, SOUND-5, SOUND-7).
2. **Byte identity cannot check what does not print.** For each operand an analysis reads, ask whether it
   prints; non-printing operands need derivation-by-construction or a non-text check (SOUND-1, SOUND-6,
   SOUND-8).
3. **A rule over untyped text is an allowlist or it is an alphabet.** "Read means not followed by `=`" is
   a denylist of shapes; the critic found 15 writes it passes (SOUND-3). r6/r8's alphabet lesson, one
   level down.
4. **Prototype evidence must be taken in the domain the build reads** (the census lexed final text; the
   build lexes render-time text).
