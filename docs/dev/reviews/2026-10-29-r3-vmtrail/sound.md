### SOUND-5 COPY's resume-edge facts rely on TRAIL-EQ, which UNTRAIL breaks; the composition is sound only if UNTRAIL reads the liveness AFTER the DELETE fixpoint, and neither doc says so
- status: SUSPECTED
- severity: design
- effort: S      blast radius: seam vmbc B (COPY) x trailgen U (row 4); the stage-1 verdict order and its checker
- where: vmbc_report.md 104-105 ("Repeat both to a fixpoint"), 113-128 (TRAIL-EQ: "every slot holds the value it had when F was pushed"), 143 (row 4: "`L` inherits the facts at the push"); trailgen_report.md 51 ("from one liveness pass plus one forward MAYFRAMES pass"), 306-314 (first-match verdicts), 320-329 (UNTRAIL soundness: "every LIVE slot"). Also altd_report.md 237 and vmbc 242-243 still cite the unweakened TRAIL-EQ.
- claim: Under UNTRAIL, TRAIL-EQ holds only for slots live at L; an untrailed slot comes back with its post-push value. COPY's must-facts at L (inherited from the push) can therefore be false for that slot. DEAD deletions only shrink liveness, but a COPY deletion REMOVES A KILL and can make a slot live at L that was dead in the pre-deletion liveness. If row 4 is decided on that earlier liveness ("one liveness pass"), the shape: fact `s == t` at push F(L); a live, untrailed write of s before the failure; at L the first write of s is the copy `s := t`, deleted by the inherited fact -> s keeps the untrailed value and is read. With row 4 decided on the post-DELETE-fixpoint liveness it is sound (any false fact at L is on a slot dead at L, and deleting a copy into it makes it live, which then blocks row 4). I did not find this shape in today's emitted code (splice parks use per-site SAVE slots, and the must-join at a shared park kills the fact), so no witness; it is a rule-order hole a future copy shape (e.g. a peeled loop) would hit.
- proposal: write the order into the table: DELETE (DEAD+COPY) to a fixpoint, THEN liveness once more, THEN row 4 on it; never re-run COPY after row 4. Restate TRAIL-EQ as TRAIL-EQ-LIVE ("every slot live at L") and check that each proof citing it (vmbc C's backtrack-into-callee case, altd's "the unwind restores every slot") only needs the live form — I believe they do (see PROBED-AND-HELD).
