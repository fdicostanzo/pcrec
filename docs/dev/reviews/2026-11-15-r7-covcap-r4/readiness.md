### READY-2 — the `cover` section's cases.tsv loader and VALUE format are mis-specified
CONFIRMED (spec/listing read). Severity: doc (a build following the text writes a loader that reads the wrong rows; red, not vacuous, but a round trip). Effort: small. Cite: design §5.3 "`$2 == "cover"`"; `docs/spec/facts_listing.md` [3¶2]/[4.1] at the review tree; `tests/kitproof/run_cover.sh:84`.

- The facts VALUE format is not defined: most new rows are written `exact_len:sets` (span_facts' spelling), while `a{4096}` is written "`why` `anchored-A`, `0`", and §5.3 says "compared whole". State which columns a `facts` VALUE holds (READY-1 needs `why` in it).
