## Lessons for the guide (proposed)

1. **A form-hash dep must cover every rendering the card times.** When a card's `deps` names one canonical instance, the check lens enumerates the instance's renderer branches against the card's cells (B = 16 vs B = 32, SIMD-off selector) and plants one per branch. One instance at a convenient k missed the branch every real site runs (F1).
2. **An A/A arm is a control only if it shares the comparison's axes.** For every A/A arm, list the axes the comparison moves that the A/A does not (here, the layout pool). The rule must also say what a failed A/A DOES (F2).
3. **"Written before data" includes the verdict clause and the unit.** A rule record that defers its unit or its verdict to a later reader is not frozen. The measurement lens drills an all-unreadable run (F5, F6).
