## Lessons for the guide (proposed)
- A harness's "fresh/new" claim must be stated in the SAME descriptor its own proof uses (F-1: bytes-new vs layout-new).
- A DRY/synthetic probe must key its readings on the exe it is HANDED, not on the cell label, or every wiring fault is
  invisible (F-2/C-3: found independently by two lenses).
- A selftest that RECOMPUTES a command's exit code instead of calling the command shares its source with what it checks (C-7).
- A no-launch guard must check the inherited environment, not only explicit arguments (C-5).
