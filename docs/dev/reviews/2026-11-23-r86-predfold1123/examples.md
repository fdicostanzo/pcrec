### EXAMPLES-3 — drill: on a NULLABLE loop body the fold's `?:` and `(h ?: capture("h"))` take PCRE's trailing empty pass first, so `?:` holds on a matched out-of-set value and the request returns unset; no document states or prints it
CONFIRMED by derivation from the documents' own rules (the model cannot run it: EVID-4, a nullable loop body is its known limit). Rules applied: core/model/match "for a loop the passes it ran, PCRE's trailing empty pass included (a reading)"; core/labels/one-rule "the empty last pass enters the body's optional, which resets"; core/conditions/form/optional-entry "holds when its left part has no value or its value is in S"; lib/structural/capture "After a loop the caller gets the label as a plain read gives it: the last pass's own value, unset where that pass set nothing". PCRE2 does run the trailing empty iteration (libpcre2 via ctypes: `(?:(\d)|())*x` on `3x` sets group 2 at (1,1), group 1 = `3`). So with P = `/(?:(?<h>\d)?)*x/`: `P & (h ?: <5)` WHOLE `7x` HOLDS (first path: passes `7`, then the empty pass, h unset), `3x` HOLDS, `x` HOLDS — it never rejects; `P & (h: <5)` WHOLE `3x` HOLDS (the second path, no empty pass, h = `3`), `7x` FAILS; `P & (h ?: capture("h"))` on `3x` HOLDS with the caller's h UNSET, while `P & (h: capture("h"))` gives h = `3`. The `?:` entry and the "if present" request are thus silently vacuous on any label whose loop body can match empty — the shape `(h ?: capture("h"))` is the documents' recommended "if present" form (lib/structural/capture, "If present").
Expected: one sentence (optional-entry or lib/structural/capture, or parked/ideas/user-doc-traps) stating it, with a printed line; or an owner question if he wants `?:` to see the last NON-empty pass.
severity: design (a trap in a ruled form; no printed line is wrong); effort: one sentence + one line, or one owner question; blast radius: optional-entry, capture, any looped optional group; location: core.md core/conditions/form/optional-entry, library.md lib/structural/capture.
