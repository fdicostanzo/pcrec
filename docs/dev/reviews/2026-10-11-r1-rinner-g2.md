## Proof sketch (single split R = P·L·S)

For occurrences j < j' of L and a start s' in starts(j') with s' <= j, one of two cases holds:
- j + |L| <= j': then the P-string over [s', j') contains L, which the factor-free condition excludes;
- j < j' < j + |L|: the two occurrences overlap, so L has a border, which border-freeness excludes.

So every start of a later occurrence lies above j. Border-freeness is necessary:
`(?:xb*a|b)aa` on `xbaaa` gives truth (0,5), but the tactic returns (1,4) without it.

## Lens: sibling of a family (forest for the trees)

The G2 arms, REVEND's end-minus-width, the K82 c-K window, [START-LANDING]'s RECOVER rows and the per-branch
inner_split all answer ONE question: where can a match start lie relative to a landmark occurrence?

Proposed general form: one derived fact on the P-NFA x landmark-set product (inner_split's derivation). It exposes:
1. disjointness, with the G2 arms as a first-match WITNESS table, cheapest first, each with its own sabotage row;
2. the maximum reach-back of a P string;
3. per-branch start equality.

Disposition: the stage 1 build implements (1) as that witness table, plus (3) as the per-branch form. (2), and K82's K
derived from it, is an UNLOCK. Trigger: a K82 cell whose hand-set K exceeds the derived bound.
Monotone-but-not-disjoint (`\S+@\S+`) stays with K7. Trigger: K7's owner fails to recover that cell's 1.41 ms.
