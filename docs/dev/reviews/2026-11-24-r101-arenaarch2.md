## Lessons for the guide (proposed)

1. Site populations in an arch note grep `src cli lib memfn/src` by habit. A unit that changes a struct's shape also changes every test that builds that struct by hand. Proposed text for pcrec-architect: "a population that a unit's shape change touches includes `tests/` (a test-tier writer compiles in make test); state the tests count beside the src count."
2. A RULED instruction of the form "every site that touches X names Y" was met at the sites the lane edited for X, not at the sites that reach X through a wider noun ("the named list"). Proposed text for pcrec-architect's fix-lane rules: "a ruled 'every site' instruction is answered by a grep over the note for X AND for each noun that contains X, with the hit list in the disposition table."
