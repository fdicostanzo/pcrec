## 8. Lessons for the guide (proposed)

- A `case A_LOOK:` in any new walk must read `u.look.atomic` (CON-2 repeats
  D62 control 3). Add the line to the coding.md "do-nots", or make the
  lookaround family a row column (atomic: seals / does not seal).
- A name table guarded by `_Static_assert(LAST == ...)` anchored by name is
  a control that stops reaching its population when a bit is appended
  (SLOT-3). Assert against a count enumerator.
- When a module turns user strings into C identifiers, check the identifier
  family against every FIXED name in the shared ABI block, not only against
  the prefix family (ADV-1, D57 precedent).
