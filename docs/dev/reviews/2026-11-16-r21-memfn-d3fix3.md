### D3H-2: the REPIN refusal plants (S3235-S3237) test repin_refusals, not main()'s wiring of it. LOW, FIX-WITH or NOTE
This is D3G-1's shape applied to D3G-2. Repro (repro1 B/B2): neuter `if refused:` in main() to `if False:`. All 60 plants stay ok, rc 0. A REPIN of four empty sweeps then writes a census with 0 rows and floors of 0, rc 0.
It is mitigated: REPIN is a manual, reviewed step whose diff is printed. But the gate would not notice the guard being unwired. A fix routes the refusal and the exit decision through one function that main() calls and the plants call (for example `repin_or_refuse(...) -> rc`, with a write callback). Alternatively, rule it as a note.

### D3H-3: d3_floor.tsv's header still carries the old remedy and the old hand-copy procedure. LOW, FIX BEFORE LAND (comment only)
At cc36c5515, d3_floor.tsv line 6 reads `(both red: "census changed: re-pin tests/memfn/d3_floor.tsv")` and line 8 reads `To re-pin after a deliberate change: rerun the gate, read its D3-FLOOR lines, copy the numbers, ...`. Both are wrong after D3G-3/6. floor_text() keeps the header verbatim, so no REPIN will ever correct it. Reword it to name D3FLOOR_REPIN=1 (and D3FLOOR_NOTE for the "which change moved them" provenance).

### D3H-4: `describe --dirty` sees the REPIN's own output. LOW, NOTE
Sequence: a REPIN on a clean tree records `<sha>`, and the tree is now dirty with the files it just wrote. A confirming second REPIN then records `<sha>-dirty` and changes every provenance field, so it is not a no-op. My R5 no-op was on a tree that was already dirty. Workarounds: use D3FLOOR_NOTE, or commit between runs. A possible fix is to compute dirtiness excluding d3_census.tsv/d3_floor.tsv (`git status --porcelain -- . ':!tests/memfn/d3_*.tsv'`). Note only.

### D3H-5: the refusal plants check that some refusal happened, not which one. NOTE
S3235 (empty) passes `n=0` and an empty hit set with shrink. If the `n == 0` check were deleted, the sub-pin reason would still refuse it, so S3235 cannot see that check removed. The `n == 0` check only matters for a cell with no DIFFER pin, which is none today. S3236 and S3237 are each isolated to their own reason (n=len(recs) >= compiles; hit unchanged), which is good. A needle on the reason text would make each plant name its reason.
