### CHECKS-1 (maintenance, check design): S3515 does not isolate the -O0 rule it is the control for. VERIFIED HOLDS.
- **What:** S3515 strips `always_inline` from `__w32`. Two legs of `simd_floor_check.py` reject
  it: the V-head TEXT leg (CHECKS-8's) and the -O0 rule.
- **Verifier:** a copy with `o0_inline_issues` turned into a no-op still fails S3515. It fails by
  the V-head leg, 3 V movers, no `-O0:` lines. With the V-head leg disabled instead, the -O0 rule
  alone catches the plant: 42 lines.
- **Consequence:** the mech verdict is suite-level, so deleting the -O0 rule would leave S3515
  DETECTED. The row's header says "the -O0 rule is the leg that sees it", and that is not what the
  row proves (learnings §3).
- **PROPOSED: FIX-NOW (small).** Add a control that only the -O0 rule can reject. One way: an
  in-script control in the V_PLANTS shape, judged by `o0_inline_issues` alone. Another: a plant
  the head text cannot see, such as a `__w32` that keeps its head but whose body calls `__body`
  (rule leg (2)). Correct S3515's header either way.
- Effort small. Blast radius: the check's own trust, no answer.

### CHECKS-2 (maintenance, a regression from BASE in the check): a FAILED -O0 compile is silently green for every always_inline (V) selector. VERIFIED HOLDS.
- **Where:** `simd_floor_check.py` C9 loop (review tree, lines 466-475). Every selector in
  `always_inline_sel` skips the "not defined in the -O0 object" line, and `o0_inline_issues` runs
  only on rc 0.
- **What BASE did:** BASE's loop had no skip. A failed -O0 compile left `defined` empty, which went
  red for every selector.
- **Verifier repro:** the critic's artifact-rewriting wrapper makes `[A-Z]{32}` compile at -O2 with
  `-Werror` and FAIL at -O0 ("the last argument must be an 8-bit immediate"). The real script then
  records 0 C9 issues for the cell.
- **PROPOSED: FIX-NOW (small).** Record an issue whenever the -O0 compile is not rc 0 (or times
  out), for every selector.
- Blast radius: debug-build (-O0) consumers of V artifacts, unseen by C18/C9.

### CHECKS-3 (maintenance, low): the NAMED `vspan` witness is held only by the kind-blind total `simd-form-named` 9. VERIFIED HOLDS (the miss is modelled, not run).

- **The miss:** any other named witness gaining a form compensates. Meanwhile "rows no artifact

- **PROPOSED: FIX-NOW (small)** if the fix lane is open anyway; otherwise PLAN. The fix is a
  per-row expectation: `named:vspan` must read `span-vector-w32`.

### r76 SLOT-1 (answer-adjacent, latent): the K >= 16 SAFETY assert reads T-vwin's MEASURED row bound. VERIFIED HOLDS.
- **Where:** `vs_w32_block` (window.c:4373) asserts `k < WF_VWIN_LO`, and the B choice uses a
  literal 16. The enum comment (:1927-1932) and §12 allow WF_VWIN_LO to RISE on a re-measure.
- **Failure:** if it rises (say to 32), T-vscan, whose bound is WF_VSCAN_LO = 24, still routes k
  24..31 to V. Those stretches then hit a kit_fail ("24 positions (16 at least)") instead of
  rendering at B = 16, which is sound by §4.2.
- **PROPOSED: FIX-NOW (small).** Name a block constant for the smallest B. Use it in the assert,
  the message and the B choice. Add `_Static_assert`s that both row lower bounds are >= it, so a
  re-measure that LOWERS a bound below safety fails the build.
- Blast radius: window.c, no byte moves.

### r76 SLOT-3 (maintenance, latent): the new `define` column does three jobs, one of them unstated. VERIFIED HOLDS.

### r76 SLOT-6 (design direction; standing question: general form + unlocks). SUSPECTED, not a defect.
- **The general form:** a SIMD-layer form is a list of declared level rows, each with its level,
  its FLD_target contract, its block writer and its guarded-bound row. ONE level-block writer and
  ONE selector writer serve every form.
- **What it unlocks:** a new level for any form, such as an AVX-512 w64 level, becomes one row; the
  guarded bound is derived per row, not CHOSEN; the level choice is traced and can be denied the
  same way for every form.
- **Trigger:** vany's next touch, or a measured second level for any form.
- **PROPOSED: NOTED** (attach to [BSPAN-VANY-RIDE]'s text). D77: not before the trigger.
