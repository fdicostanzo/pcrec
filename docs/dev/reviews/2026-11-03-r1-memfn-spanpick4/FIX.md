### FIX-3 — minimax step 3: the TIE hand-off can pick a candidate that does not clear guard (b); unpriced/noiseless candidates' place in the loss denominators is unstated
SUSPECTED (design text; no code yet). Severity design (answer-safe, speed). Effort small. Blast radius: every priced row's pick; the pcrec-side re-price (:465-467) must reproduce it.
- Rev 4 :178-181: "The minimax candidate c* has the least W. It is picked only when `W(default) - W(c*)` exceeds the band of that comparison (guard (b)); otherwise the default stays. Candidates within band of W(c*) go to TIE's rows ... a default within band is T_BAND -> TIE_DEFAULT."
- Ruling (D186 add. 2): "a pick departs from today's only when its worst case improves by more than the cards' measured noise." The guard is per DEPARTURE.
- Bands are per pair (:236-239) and not transitive. Case: W(default) - W(c*) > band(default, c*) but c2 within band(c2, c*) of W(c*) and W(default) - W(c2) <= band(default, c2). Step 3 sends {c*, c2} to TIE's rows; if TIE prefers c2, the kit departs to c2, whose worst case does NOT beat the default's beyond noise: the ruling's guard is broken. Fix: only candidates that themselves clear guard (b) against the default enter the tie set (or the default always joins the tie set and TIE_DEFAULT wins it).
- TIE's rows (`wf_ties[]`, window.c :79 `T_MASS_STRETCH, T_MASS_SET, T_MODEL, T_CMODEL, T_MARGIN, T_WINDOW`) compare positions/masses/alternatives; none compares METHODS, yet T-PICK candidates differ at "method, position, alternative" levels (:167). Which TIE row orders two method-level candidates within band is unstated (a new tie row, its own spelling, the census's business).
- Sibling fields left unstated by step 2/4: does a candidate that "cannot be picked" (no card, or a card without noise) still enter `min_c' price_r(c')`? If a noiseless-but-valued candidate enters the denominator, it lowers every other candidate's loss under that kind and can change c*; if it is excluded, a row's pick depends on which cards carry noise. The re-price (:465) must know which.
