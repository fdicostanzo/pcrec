## 3. S420-prefilter-drop-rung-deleted UNREACHED (batch b202611070125512685420)

**Cause: the probe's own compile was refused, not the rung.** Lane altfix
re-aimed the reach probe from `(\p{Xwd})x` to the resource suite's witness
`(\p{Xwd})\b` (stage 1's table shrink made the old one fit with its
prefilter) but kept the old command line, which passes no `--features`.
`\b` needs module `assertions`, so the probe's pcrec run printed
`\b requires module 'assertions'` to a `2>/dev/null` and nothing to
stdout: reach:MISSING with the rung firing all along. The normal form did
not rewrite the witness away; the resource suite's own measurement line
(`run_resource_tests.sh`, PFD_WIT) already names `-e utf8 --features
assertions`.

hand on the merged build it prints `size cap retry, hybrid`. The REACH run
over all 30 rows is owed (`altcatch-reach`). A lesson for the check, filed
for the manager: a reach probe that hides its compile's stderr cannot tell
"rung did not fire" from "witness did not compile".
