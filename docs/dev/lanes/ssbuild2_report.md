## 2. Placement and order (the brief's rulings)

- The seek runs after `rx_valid_upto`, from max(search_from, K82 handoff lo)
  — and a mover has NO handoff by construction ([vm-handoff]: V requires no
  prefilter, the handoff requires one), so it starts at the caller's
  startpos after K50's STARTPOS adjustment.
- **Against K65's pre-check:** the pre-check (a necessary-literal `memchr`/
  `memmem` over the whole subject) runs FIRST and answers 0 for an impossible
  call; the entry seek then walks from startpos. The two never read the same
  byte with a libc scan: the pre-check is the only libc scan, the seek is an
  inline table walk (no `memchr` form at stage 2).
- The give-up allowance is one-way (a deny give-up may become the hat's
  answer, never the reverse); the spec sentence names capacity (Q-R3) and
  `giveup.rxt` is its witness.

## 6. Findings

1. **The size term reads the hat's table.** `size_term_choose`'s materiality
   bar compares TOTAL comment-excluded bytes, tables included; the hat adds
   ~1.8 KB of K-invariant bytes per mover, so a borderline ladder pattern's
   unroll K can move. Measured on a threshold-1000 reference compiler: 1 of
   10 pool members (`(|a){0,12}b`, ratio -> 0.7502, declined). At the
   shipped threshold: 0 corpus patterns. `run_size_term.sh`'s pool read CODE
   bytes, which agreed with the compiler's quantity only while VM artifacts
   carried no table bytes; it now reads the compiler's own total, and
   `(?:abcd|abc|ab|a){17}z` joined the pool for the floor. §6.1's "movers
   differ modulo the abi digit and the stamp" holds for the 6,946 pairs, but
   it is a measurement, not a law.
2. **Dense S is admitted** (D149 label on `|S| < 256`): `\w`-led patterns
   (|S| = 63) seek; the dense guard cells in `alpha_s2.sh` measure it.
3. **CLI diagnostics truncate at ~256 bytes**: two rxtsource checks (W1.3
   dup-definition and head/prose-dedent-K57) failed under the long session
   scratchpad TMPDIR because the file names they look for were cut off the
   end of the message; green with a shorter TMPDIR. Pre-existing and
   environmental, not this lane's — filed here for the manager.
4. `tag` is a W1 candidate keyword the keyword census guards; ssedge's
   drafts carry `tag edge=` lines, which the importer now writes as
   comments (line numbers preserved for GROUP F5's keys).
