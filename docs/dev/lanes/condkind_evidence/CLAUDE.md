# docs/dev/lanes/condkind_evidence/ — lane condkind's evidence (2026-11-16)

Evidence for `docs/design/condition_kind.md` (an EXPLORATION of a condition as its own kind, the owner's SQL model;
rules nothing) and `docs/dev/lanes/condkind_report.md`. Historical after merge; never edited after.

## Files

- `rev22_ref.py` — dumps rev 22's own answers (predspec21_check.py exec'd verbatim, THE RULE) for every program of
  1-3 legal conditions of its pools A, B, P, LST, as a TSV in the scratch dir (not committed; regenerated by the run).
- `condkind_model.py` — a DECLARATIVE engine for the SQL model (conditions as data, no trap): the mark candidates
  M1 / M1a / M2c / M2r side by side, the two nots, the row choices; reads the TSV for the REV22 column.
  `CONDKIND_SWAP=1` reverses every order (the swap run must print the same lines); `CONDKIND_SABOTAGE=1` gives M2c a
  trap-shaped transparency (the swap run must then differ).
- `condkind_model.out` — the forward run's output, the numbers the note and the report quote.

Commands: the header of `condkind_model.py`.
