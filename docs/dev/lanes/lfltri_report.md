## 3. Why class (b), and why it is legitimate for a no-mover

- lfl0 L0.1 introduced `enum { CAND_FIN_REPORT = 1, CAND_FIN_NOMATCH,
  CAND_FIN_VERIFY, CAND_FIN_SEARCH }` at `src/gen/emit_dfa.c:5149` (the
  `CandFinish.act` tags). The scan's enum walk skips ORDINAL enums (explicit
  initialisers exactly 0,1,2,... in member order); this one is non-ordinal
  only because its first member is `= 1` at index 0, so its one literal is
  reported. The other three members are implicit and are never scanned.
- The constant is not a bound, a magnitude or a policy. The `= 1` reserves
  value 0 for a zero-initialised `CandFinish`, so a `cand_rows[]` row that was
  never given a `.u.finish` payload carries no action and matches no
  `act ==` test (the one comparison is `dfa_match_is_unwrapped`, which reads
  `u.finish.act == CAND_FIN_VERIFY`). It belongs with the SDR_* rung
  ordinals in the allowlist's fourth kind, and the added comment says so.
- Nothing the registry READS about the compiler moved: lfl0's report records 0
  `emit_sweep` movers on every stream at every commit, the `dumps` stream
  (the registry surfaces) included, and every other registry check is green.
  The red is the check seeing new SOURCE text, which a no-mover is allowed
  to add; a no-mover that moved a registry surface would have needed
  justifying and did not.
- Alternative considered and not taken: respell the enum with a leading
  `CAND_FIN_NONE` so it is ordinal and needs no allowlist entry. That is a
  `src/gen/emit_dfa.c` edit (a new enumerator, in the file S741 plants into)
  to satisfy a test-tooling classification, after a chain whose mech rows
  were scored from this exact HEAD. The allowlist is the route the check's
  own message names, touches only `tests/registry/`, and the reach arm
  (`[code-reach]`, 50 of 50 names reached) proves the new entry is live.
- Why lfl0 did not see it: its light gates (strict, emit_sweep, trace, census,
  cand oracle, codegen) do not include `tests/registry/limits_check.sh`, which
  only `make test`'s registry section runs. A lane that adds ANY numeric
  `#define`/enum literal under `src/`, `cli/` or `lib/` should run
  `bash tests/registry/limits_check.sh` (seconds) as a light gate.
