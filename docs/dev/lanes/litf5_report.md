# litf5 — [OPT-LITSCAN] F5 (D127): the lit-run one-compare floor is three bytes

Lane `litf5` (sonnet), 2026-09-28. Branch `lane/litf5` from `457eee4d`
(D127's own ruling commit). Builds `pcrec_lit_run`'s (`src/core/cpset.c`)
own floor from two consecutive one-byte literals to three, so the VM's
S2a one-compare form (abi 41) applies only to runs of L >= 3; a two-byte
run falls back to the pre-S2a per-byte early-exit chain. `abi` 42 -> 43.
