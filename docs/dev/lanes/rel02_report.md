D76/D94 row ("change emitted scaffolding") is about scaffolding STRUCTURE.

and `0.2.0-beta` are the same length (10 bytes), so no byte-count reader
moves — the resource suite's byte pins, the cpset `EMITTED_BYTES` manifest
