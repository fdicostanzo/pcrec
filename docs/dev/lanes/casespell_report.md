# casespell report -- caseless spelling identity check (2026-10-23)

Check: `tests/codegen/run_case_spelling_identity.sh`, in `make test-codegen`
(about 5 s). Claim: patterns differing only in the letter case of their
caseless text emit the same matcher.

## Groups (3 spellings each; dfa and vm; byte and utf8 where meaningful)

| group | spellings |
|---|---|
| literal | `(?i)hello` / `(?i)HeLLo` / `(?i)HELLO` |
| class | `(?i)h[ae]llo` / `(?i)H[AE]LLO` / `(?i)H[aE]lLo` |
| wordb | `(?i)\bfoo\b` / `(?i)\bFOO\b` / `(?i)\bFoO\b` (compiled `--features all`) |
| utf8-letter | `(?i)éa` / `(?i)ÉA` / `(?i)éA` (utf8 only) |
| alternation | `(?i)cat|dog` / `(?i)CAT|DOG` / `(?i)Cat|dOg` |
| flag-spelling | `(?i:abc)` / `(?i:ABC)` / `(?i:aBc)` |

22 cells compared, none refused, all identical.

## Mask (declared, exact whole-line match against text rebuilt from the spelling)

1. provenance comment line 1 of `.c` and of `.h`
   (`/* Generated by pcrec VER (abi N). Pattern: <spelling> */`; VER/abi free);
2. `.pattern = "<C-escaped spelling>",` (.c);
3. `.pattern_len = <byte length of spelling>,` (.c).

Fire counts are asserted per artifact (.c: 1/1/1, .h: 1/0/0); a stale or
over-firing entry fails. Basenames are equal across the three output dirs so
the `#include` name never differs and needs no mask.

## Results

Beyond the mask: nothing differs, and gcc -O2 `.text` is byte-identical in
every cell. No case leak found on main.

Positive controls (must differ, and do): `(?i)hello` vs `(?i)hellp`
(RX_REQ_RUN differs); case-sensitive `hello` vs `HELLO`.

## Observation (not case)

`(?i)abc` and `(?i:abc)` (same case, different flag scope form) differ on
`--engine=vm`: `RX_VM_PROGRAM_BYTES` 634 vs 577. That is a flag-scope-form
difference, not letter case, so the flag-spelling group uses the scoped form
for all three spellings. Possibly worth a look as an optimisation
(inline `(?i)` costing a larger VM program than the equivalent scoped group).
