**F-9 finding.** The design's `[SEL-1]` witness population is EMPTY. A record carried across attempts shows only if an earlier attempt asked and the final attempt did not. I instrumented the build to check this:
- The `[SEL-1]` first attempt overflows in the DFA build, before any reader asks.
- The size rungs keep a DFA scan (K53/K59). [OPT-4]'s collapse preserves nullability, so the final attempt asks again.

So S314 plants the general defect: the record becomes process state. It is detected through that defect's per-compile half, which is two targets in one invocation. The row's header carries the derivation.

## 6. Deviations and open items for the manager

1. **The `.rxt` reader is on the library's compile path.**
   - R17 has the library parse `analysis_source` and read `-I` files, so `pcrec_compile` → `pcrec_find_resolve` (in `src/parse/`) → the reader.
   - `compile.o` still names no `rxt_*` symbol, so [REVW.3]'s structure holds for the composer only.
   - **K7 residual:** the reader's own arena is detached, so an out-of-memory failure inside an `-I` or `analysis_source` parse aborts instead of routing through `pcrec_ctx_nomem`. Before B2 the reader was CLI-only.
2. **Library notes.** The fall-through note and the no-query note go to stderr from the library. That follows the drop-ladder notes' precedent.
3. **`-I` and `--analysis` scope.** They are legal with a plain `--pattern` compile, a file operand, and `--list-analysis`. They are still refused with `--emit-ir`, `--emit-facts` and every other query. The design listed only those three places.
4. **`--list-analysis`:**
   - It lists every compile encoding, and `-e` does not filter.
   - The per-target view carries `targets`, `chain` and `resolution` sections, but no per-bundle block sections; the name view shows those.
   - A value that is not an analysis name is read as a FILE, so `--list-analysis Upper` reads a file called `Upper`.
5. **The C3 witness flips G1 through its identity conjunct.** The rate moves the scan byte onto the necessary byte. The density conjunct alone fires only on a tie or on a scanned byte outside the necessary set, which is the population `run_prechecks.sh` owns.
6. **I did not edit the design doc.**
   - Stale spots: §6.4, §8.2's bundle index, and §11.2 F-5/F-9 (see §3).
   - Findings for the design's owner: F-5 is adapted to B2's one query, and F-9 has no per-attempt witness.
7. **`FINDINGS_SKIP_SLICE`** exists for quick runs. The mech `findings` arm runs the whole suite, slice included, at about 3.5 minutes per row.
