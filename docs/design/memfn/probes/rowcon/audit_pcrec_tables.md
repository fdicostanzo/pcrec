## (c) Boundary facts

- memfn/CLAUDE.md: kit links nothing from `src/`, `cli/`, `lib/`; pcrec reaches it only via `memfn/include/memfn.h`; generated artifacts never depend on it (text only); every external symbol through `MF_NS(name)` (`mf_*` extracted, `pcrec_mf_*` in-tree, memfn.h:29-36), internals `static`; libpcrec exports only `pcrec_`-prefixed names (C15); 0BSD with SPDX line and provenance header on files whose text can reach an artifact (C16), `PROVENANCE.md` rows per file under `include/` and `src/`. Kit sources include only `kit.h` and `../include/memfn.h`.
- libpcrec already links the kit: Makefile:115-129 `KITSRCS := $(wildcard memfn/src/*.c)`, compiled with `KITFLAGS` (no -Ilib), objects joined into libpcrec.a. A new .c in memfn/src/ is picked up automatically; `KITHDRS` (:128) lists memfn.h, kit.h, options.def and is a dependency of kit objects.
- Precedent for pcrec CALLING non-site kit utilities: yes, both read-only and both from one TU. `mf_run_rows(i)` (memfn.h:396) and `mf_options(&n)` (memfn.h:414) are called by `src/dump/axes_dump.c` (includes memfn.h at :83; calls at :664 and :1050) to print kit tables live in `--list-axes`. `src/gen/memfn_sites.{c,h}` (header includes memfn.h at :16) calls the site API, plus the one deny map `pcrec_memfn_deny_flags`. No pcrec code calls a kit function to SELECT; kit decision tables are consumed only for listing.
- Shared header-only idioms: none between pcrec and the kit. The two sides each carry their own copy of the idiom (DfaCand in emit_dfa.c; `rc_row`/`mf_run_row` in runcmp.c). `memfn.h` is the only header crossing the boundary and is both the extraction surface and a pcrec include; it defines `MF_FORM_FUNC` (a `static inline` form tag) but exports no inline helpers. `src/core/internal.h` is pcrec-private and may not be included by the kit. Any shared mechanism pcrec reads would have to live in memfn.h or a new kit .c with `MF_NS` symbols (C15 pins the allowlist at `tests/memfn/c15_allowlist.txt`).
- Checks touching the boundary: `test-memfn-link` (C15/C16), `test-memfn-arch`/`run_arch_blind.sh` (kit stays arch-blind), `test-memfn-manifest` (C17 site manifest), `test-memfn-reach`.
