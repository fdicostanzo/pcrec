## CELL A CORRECTION (found after reading the first run's own output)

The first run's Cell A used PAT_A="(?:${ALT})+" -- NO capturing group, so it
routes to the pure DFA engine under default selection. Verified by hand:
`diff` between the -fno-altcls-factor and default .c files for that exact
pattern is EMPTY past the stamp/include lines (537 lines each, byte-for-byte
identical bodies) -- DFA minimization erases the factored/unfactored AST
distinction entirely for this shape. The first run's Cell A numbers
(17.96 vs 17.96 us/call, ~0% delta) therefore measured two copies of the
SAME PROGRAM and are DISCARDED, not reported as a finding about stage 2.

pinned_measure.sh's PAT_A is corrected in place (git-tracked) to
`(${ALT})+` -- a capturing group around the alternation, forcing VM
routing (RX_ENGINE "vm" confirmed both sides; RX_ALTCLS_FACTORED 2 vs 0
confirmed; the two .c files are 1706 vs 1695 lines, 1392 diff lines --
genuinely different programs this time). Re-run standalone (same
methodology: N=200000 reps, best-of-9 x 3 interleaved rounds, mpstat-
