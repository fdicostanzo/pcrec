2. DOES \p REQUIRE PCRE2_UTF? -- the module-gating question
==========================================================================
If \p compiles and MATCHES without PCRE2_UTF, then module
`unicode-props` is NOT gated on the encoding, and charter (viii)'s
staging table has to say so: it would be landable under the `byte`
backend for the sub-0x100 part of every property.

  options        compile \p{L}                  match on...
  ----------------------------------------------------------------------
  options=0      yes                            a=MATCH  U+00E9 as UTF-8=MATCH  U+00E9 as one byte=MATCH  U+03B1 as UTF-8=MATCH
  PCRE2_UCP      yes                            a=MATCH  U+00E9 as UTF-8=MATCH  U+00E9 as one byte=MATCH  U+03B1 as UTF-8=MATCH
  PCRE2_UTF      yes                            a=MATCH  U+00E9 as UTF-8=MATCH  U+00E9 as one byte=ERRM-4  U+03B1 as UTF-8=MATCH
  PCRE2_UTF|PCRE2_UCP yes                            a=MATCH  U+00E9 as UTF-8=MATCH  U+00E9 as one byte=ERRM-4  U+03B1 as UTF-8=MATCH

  The same question for \w, \d, \s and \b -- these are the
  constructs PCRE2_UCP RE-DEFINES, and pcrec ships all of them
  today with ASCII bit tables (pcrec_cls_word_esc and friends):

  esc    options=0      UTF            UTF|UCP        on
  ----------------------------------------------------------------------
  \w     no             no             MATCH          U+03B1
  \w     no             no             MATCH          U+0660 arabic-indic 0
  \w     no             no             no             U+00A0 nbsp
  \d     no             no             no             U+03B1
  \d     no             no             MATCH          U+0660 arabic-indic 0
  \d     no             no             no             U+00A0 nbsp
  \s     no             no             no             U+03B1
  \s     no             no             no             U+0660 arabic-indic 0
  \s     no             no             MATCH          U+00A0 nbsp
  \W     no             MATCH          no             U+03B1
  \W     no             MATCH          no             U+0660 arabic-indic 0
  \W     no             MATCH          MATCH          U+00A0 nbsp
  \D     no             MATCH          MATCH          U+03B1

  \D     no             MATCH          MATCH          U+00A0 nbsp
