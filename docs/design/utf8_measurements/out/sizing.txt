CONVENTIONS used throughout (read before comparing numbers to pcrec's real caps):
  (c) naive/unshared NFA states = 1 shared start (S) + a fully private chain per byte-sequence alternative (no sharing at all, not even the accept state -- each alternative's own last state is its own private accept).
  (d) suffix-shared NFA states = a trie built from the END of every alternative, hash-consing identical (byte-range, target) pairs, plus one shared start (S) and one shared terminal accept (F) that the hash-consing merges automatically.
