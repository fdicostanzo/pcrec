READING THE COLUMNS
  FALSE-NEG = subjects the TRUE pattern matches and the ERASED
              one does not. Any non-zero refutes 'the erasure is
              a superset', which is the ONLY sound thing it is.
  SPAN DIFF = subjects BOTH match, at DIFFERENT spans. Every one
              of these is a window engine_m4.md 6.1's hybrid
              would hand the VM WRONG. A capture-only pattern's
              erasure has zero by construction; a backref's does
              not.
  last col  = how often the erasure agrees on NOMATCH, i.e. how
              much a sound `nomatch`-only prefilter would buy.
  subjs     = DISTINCT subjects (R32 C8: the first version
              sampled with replacement and inflated three
              families 31.5x).
