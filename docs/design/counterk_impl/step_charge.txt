steps_today = fail-label resumptions: what the budget charges TODAY
cut_frames  = frames RX_CUT discarded: pushed, then hidden from the fail label
scan_FRAMELESS = span-loop iterations in a loop with NO retreat frame:
                 never pushed, so the fail label never sees them
scan_RETREAT   = span-loop iterations in a loop that RETREATS: its frame
                 pops once per stride, so these are ALREADY charged in
                 steps_today. Counted separately and EXCLUDED [R25 26] --
                 conflating the two double-bills the triangular quantity.
UNCHARGED      = cut + scan_FRAMELESS. THIS is what S7 must cover.
