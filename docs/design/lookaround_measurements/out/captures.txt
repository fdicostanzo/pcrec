C6 -- BUDGET: is there unbounded work INSIDE a lookaround body?
==============================================================================
pattern                            subject    | libpcre2 10.46             | python3 re                 | note
# D42.6 asks whether a lookaround body's steps must be counted. If a
# body can burn unbounded work while the assertion as a whole is
# zero-width, then a budget that does not count them is not a budget.
#
# THE FIRST VERSION OF THIS AXIS WAS VACUOUS and the reason is worth
# more than the axis. It used `(?=(a+)+c)x` on 'a'*n + 'b' and measured
# 0.0000 s at every n -- not because the body is cheap but because
# PCRE2's own START OPTIMIZATION sees a REQUIRED CODE UNIT ('x') that
# the subject does not contain and never runs the match at all. A probe
# whose subject cannot reach the construct reports a confident zero.
# Both arms are kept below so the vacuity is visible rather than fixed
# away -- and the same optimization is a fact §5's prefilter section
# needs, since it is PCRE2 doing exactly what a prefilter does.

^(a+)+$                  n=16   | nomatch                      | 0.0041
