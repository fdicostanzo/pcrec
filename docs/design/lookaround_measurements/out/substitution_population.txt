THE EXPANSION MULTIPLIER
==============================================================================
A qualifying block yields ONE expanded pattern per substitution POLICY,
not one per assertion: the driver substitutes EVERY substitutable
occurrence in the pattern at once, because a half-substituted pattern
tests neither form. Two policies are worth generating and the second is
the one that finds bugs:

  P1  ALL-AT-ONCE  -- every occurrence replaced. 263 patterns.
  P2  ONE-AT-A-TIME -- one occurrence replaced per generated pattern,
      the rest left folded. This is the MIXED form, where a folded
      assertion and an expanded one must agree INSIDE ONE PATTERN, and
      it is where an interaction between the two lowerings would show.
      361 patterns (one per occurrence).

  TOTAL GENERATED PATTERNS: 624, over 8260 behavioural cells each time
  i.e. roughly 8260 three-way comparisons for P1 and 8260 for P2.

  (P2's cell count is not cells x occurrences: each generated pattern
   is checked against its OWN block's cells, and every occurrence in a
   block comes from the same block. The two policies therefore cost
   about the same per-cell total, which is why both are proposed.)
