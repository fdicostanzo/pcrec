## Standing rules: cpset, fold, sb, limits, findings, ksrc details

- `cpset.c`: the `A_CLASS` payload is a sorted, disjoint, NON-ADJACENT interval list; `pcrec_cls_bits` is the ONE interval-to-bitmap render and REFUSES (by `pcrec_ctx_fail`, not assert) non-byte-confined sets; `PcrecCpSet` builder is write-only, published `const PcrecCpRange *` read-only; `A_WCLASS` readers refuse by KIND (`cls_kind_guard`); `pcrec_cube_of` is the one cube definition parameterized by domain; caseless masks derive from `fold.c` through the SET. `pcrec_lit_run` floor is 3 (one fact, no second predicate at a call site). Check: `tests/codegen/run_cpset_structure.sh` (excludes this file from the `u.cls.bits` code needle on purpose; the D70 survey narration is kept in the history file).
- `fold.c`: `pcrec_ascii_fold` is the single ASCII fold table (parse-time `cls_casefold` derives from it; the residual `$_span_match_caseless` is tied by `tests/backrefs/fold_agreement_check.c`); the Unicode simple fold is a CYCLIC next-member relation (`fold_tables.inc`, generated); the ENCODING names its fold (`PcrecEnc.fold`), `cls_casefold` takes the fold as a parameter; a UCD bump must not move `byte` answers (`tests/backrefs/fold_agreement_utf8_check.c` part C); `pcrec_fold_latin1` checked by `tests/ucp/latin1_fold_check.c`.
- `sb.c` text layer: `pcrec_sb_text`/`_textn` (frame-only escape; registry dumps and `--explain`) vs `pcrec_sb_field` (`.rxt` subject escape, doubles backslash) are NOT interchangeable; `pcrec_sb_cstr` octal-escapes (hex swallows following digits); `pcrec_sb_fragf` (arena-sized, no fixed buffers); `pcrec_sb_stampf/_stampwf/_stamp_str` write every stamp line (value is a format, not a type; no typed int helper); `pcrec_sb_upper` is the one `<PREFIX>_` derivation. Text-layer functions take DATA and read no `Ctx` (D108).
- `sb.c` gates: the comment gate (`pcrec_sb_comments`, `_cmt_open/_close`) lives in the three primitives (`putc`/`puts`/`sb_vprintf`); ANY length decision or stamp comparison reads `pcrec_sb_len_decide` (uncut minus SIMD-guarded) and caps read `pcrec_sb_size_decide`; never `len`; layout marks (`pcrec_sb_layout_mark`, `layout_bytes`) are subtracted too (I5: no decision reads layout text). `pcrec_sb_simd_open/_close` brackets are line-aligned, never nested; `pcrec_sb_splice` carries the record. K79: placeholders `\x01q`/`\x01Q` rendered by `pcrec_sb_render_prefix`; size decisions measured at a canonical two-byte prefix (`docs/spec/limits.md` §8.2).
- `limits.h`/`limits.def`: every number that decides what pcrec ACCEPTS/REJECTS/PROMISES, in D26's three tiers (ours / PCRE2 syntax, measured / PCRE2 internals); keep provenance; structural constants and locally proven bounds stay where they are (see the file's inclusion rule). Read an entry (e.g. `PCREC_MAX_SUBSET_ELEMS`, `PCREC_MAX_AUTO_DFA_ELEMS`) before touching its number. Splice budgets `PCREC_MAX_SPLICE_NODES`/`_TOTAL` count AST nodes (decided before emission).
- `findings.c`: the gate lives here and nowhere else (no function outside the PICK/COMPARE/MASS primitives tests a rate pointer or the encoding; `tests/findings/structural_check.py`); each primitive spells its NONE answer ONCE (D126 Q4); a rate reader is "build a candidate order, ask one primitive"; PICK takes cube candidates, NONE answer prices SIZE with ties to the reader's `rightmost`; run reader's data tie follows its NONE order; chain selection is `pcrec_find_chain_answer` (one rule, also used by `--list-analysis`); the memo is read only in this file (S4); `find_derive_byte_rate_status` NEVER refuses, `find_raise_byte_rate` raises on the ASK path only; `pcrec_find_offer` never records an ask; the knowledge stamp lists a query ANY attempt asked (`Ctx.find_union`). Store `.inc` files are COMMITTED, regenerated by `make gen-findings`; a source tree compiles with no build step. Any change here that moves bytes is an abi event (D76/D94).
- `ksrc.c`/`ksrc.h` DEPENDENCY RULE (S989): include libc + `core/ksrc.h` ONLY (no `Arena`, `StrBuf`, `Ctx`, `pcrec_error`; caller supplies `KsAlloc`, reads `KsErr`); held by `tests/core/ksrc_deps_check.sh`. A `KsKind` column joins in the step that first reads it. Kind rows live in their own TUs; `ks_measures.c` is libc + `ksrc.h` only too.
