# src/parse — PCRE pattern parser

Base-tier PCRE parser (literals, `.`, classes, quantifiers, alternation, anchors, groups, metachar escapes) producing the AST, plus the construct registry and the module producers (`mod_*.c`) it reaches through four doorways, plus the `.rxt` source-file readers. Anything outside the base tier is routed through registry rows that yield a precise "requires module 'X'" diagnostic instead of a miscompile. Also hosts the knowledge-module rows (`ks_*.c`).

## Standing rules

Maintenance: update this file when files are added/removed or their roles change.

Registry (registry.c, D24) and doorways:
- Non-base syntax is described ONCE, as a row in registry.c, and reached through exactly four doorways (after `\`, after `(?`, after `(*`, after `[` in a class). Adding a construct = adding a row, never editing parse.c. A construct with two homes will drift (`\v` once decoded as VT because two tables disagreed).
- parse.c is the base grammar AND NOTHING ELSE (SR-2); it stops gaining CONSTRUCTS (not correctness fixes: FIX-1's `case '{'` / two-phase `try_quant` overflow rule were base-tier syntax bugs). A new construct needs a registry row.
- Add a row in registry.c and nowhere else. `syntax` must be a pattern that really reaches that doorway: tests/registry/ uses it as the probe, so a new row covers itself.
- `RS_MODULE` with no handler is a complete outcome (named, cleanly rejected, queryable), not a stub.
- `RS_BASE` rows in `RK_ESC` are a narrow named exception (7 rows: `\a \e \f \n \r \t` and bare `\x`, `ESC_BASE_D`) existing only to give `RegRow.definitions` (D85) a home; never consulted by live dispatch (`esc_char_value` still decodes them). Do not add an eighth base-tier construct casually (read definitions_table.md's architectural note). Braced `\x{...}` stays out (unicode-props' unbuilt form; no new doorway).
- Two "requires module" diagnostics deliberately stay in parse.c, no doorway: `\x{...}` and the possessive `+` suffix (a doorway would cost the base tier a lookup). `\b` in a class is the row's BASE class port (ExtPort.base; gate never touches it).
- `(?:` is base grammar, answered before the registry; its row exists only so the table is complete for the dump.
- The `engines` column is design intent, not measurement; nothing consumes it. The tripwire `check_engine_capability_tripwire` (tests/registry/registry_check.c) guards the gap (every VM_ONLY RS_MODULE row has no wired producer; `\K` is the one NAMED exception, asserted live). Do not build on its values unchecked; wiring a second such construct is when SR-8 earns its consultation axis.
- Tail selection (SR-9, MOD-0.2/D32): a row may carry a `tail` (literal prefix, not a pattern). Lookup = RECOGNISER + RANK; highest-ranked ANSWERING row wins; two answers at the WINNING rank is a defect (internal error), never resolved by declaration order. Ranks: 0 fallback, 25 tailed, 70 `\N{U+`; meaningful only between clashing rows (RegRow.rank). Row ORDER must not be able to stand in for the rule (keep the `\N` pair shortest-first). Use `tail` before any compound module name (no compound names like the retired "lookaround/named-groups"). `(?-` keeps ten rows "0".."9" (collapse deferred until a passing reachability differential). Checks: `check_row_ranks`, `check_arbitration_liveness`.
- An inline option setting is a RUN, not a byte (Q2): the `(?` doorway reads the whole run; grammar is measured (`(?aP)` ok, `(?aPP)` err 111, misplaced hyphen err 194, PCRE2 stops at first error). Module names in diagnostics are pinned by hand in tests/reject/, not verified by libpcre2.
- `RF_CLASS_DELIM` carries a construct's own recognition rule (opens only when its matching `X]` appears later); all THREE class-bracket rows carry it. `RF_CLASS_NAMED` is meaningful only ON an `RF_CLASS_DELIM` row (registry_check.c requires the pairing). `open_msg` is the one POSITION-varying field. `<`/`>` POSIX names are whole-class-only (`pcrec_registry_posix_whole_class_only()`, `at_content_start`; `check_posix_positions`).
- `RF_CLASS_INVALID` stays (permanent class-position invalidity); port data guarded by `check_class_ports` (populations pinned, values oracle-tied); set bitmaps are GENERATED from libpcre2 censuses (PC-4 re-measures), never hand-typed.
- A verb NAME goes in the VerbName tables (mod_verbs.c), not a RegRow (Q1/D25). Its form bits (VF_BARE/ARG/EMPTYARG/EQNUM/GROUPARG/ATSTART) are MEASUREMENTS: add the name, run `bash tests/registry/run_registry_tests.sh`, let libpcre2 tell you the bits; never reason from the docs. Table chosen by CASE of first name byte only; terminator set is per-name.
- `(?` doorway cannot decline (catch-all is REJECTED); `pcrec_ext_class_bracket` can (DECLINE, cursor unchanged). Do NOT give them one contract. Non-matching `(?X` bytes get PCRE2's wording with no module (the run/byte is the construct).
- RF_INDEX rows never dispatch by name/byte-only identity: in `pcrec_registry_arbitrate` the RF_INDEX skip goes BEFORE the `REG_SEL_ANY` case (load-bearing). Byte-keyed index rows record the true selector byte, never `REG_SEL_ANY`; `check_index_rows` (registry_check.c) asserts against the engine's own dispatch.
- Port chosen by construct FAMILY where families differ (`GROUP_RC`/`GROUP_RC_T` macros); a row differing in a macro-fixed field is written LONGHAND. `(?0` is a prefix of two targets: every numeric recursion port re-reads the WHOLE digit run from the selector byte (`(?01)` is group 1, not the root).

Doorway seam (ext.c):
- Doorways RETURN a tagged `ExtResult` (EXT_NOT_MINE / EXT_REFUSAL formatted at claim time); `pcrec_ext_finish` is the one epilogue; call sites in parse.c end in internal-error walls for unhandled outcomes. Every doorway takes an `ExtWant` level; `pcrec_ext_gate` demotes RESULT to VERDICT when the row's module is off (consults enabled.c AFTER row choice); `answered_at` records the post-gate level; the CURSOR RULE (cx->pos moves only under WANT_RESULT; the CALLER moves the cursor, never the doorway) is measured through `--probe-ask` (check06).
- `group_answer`: a general `want == WANT_RESULT && aport.kind == PORT_FN` producer-invocation path (passes the position after `sel`+`tail`; the option-run branch passes the SELECTOR byte). Every new `(?` producer not shaped like an option run uses it; no second special-cased block.
- UNBUILT epilogue: a gate-open construct with no producer refuses by the CONSTRUCT's name (not "requires module"), read off ONE source (post-gate WANT_RESULT reached = "gate open, port missing"); sits AFTER the `ROADMAP_NEVER` case. `PCREC_UNBUILT_MARKER` (internal.h) is the one shared wording. The `built` column (`pcrec_construct_built_status`, syntax_dump.c, D65) is DERIVED live, never hand-set, and must not text-match.
- `pcrec_ext_verb` lives in mod_verbs.c as a direct call (not a port); ext.c still owns `DECLINE` (class-bracket only); `REFUSE`/`BAD_ROW` macros are shared via internal.h.
- Keep lexer extent scans (scans.c) out of module TUs; scans.c must NEVER link the enabled-set symbols (`nm` is the oracle, check01).

Parser structure (PARSE-1):
- The group case is three functions: `p_group` owns entry/exit bookkeeping (`cx->depth`), `p_group_body` owns everything between `(` and `)` and neither end. Keep it so a `return` in the body stays balanced. `pcrec_ctx_fail`'s longjmp bypassing the exit is structural: `src/core/compile.c` holds the ONLY `setjmp`.
- `p_alt_info` fills `AltInfo {nbr, last_bar}` (count computed by the loop that drives the parse; `Ast` has no position field, so modules needing an offset need it reported). Never re-derive branch counts by scanning text.
- Modifier state lives in `cx->mods` (ModState), seeded once from options in compile.c; saved/restored around every BODY-CARRYING group; a bare option run escapes its paren's restore (measured leak rule). The restore belongs at the group boundary in the base grammar, not in a module.
- Nested bodies use `pcrec_parse_body` (stops AT its terminator; the CALLER consumes its own `)` and raises its own unterminated diagnostic with `PCREC_MISSING_CLOSE_PAREN_MSG`). Do not use `pcrec_parse_info` for a nested body.
- Capturing `(` hook (`p_group_body`): `Ctx.ncap++`, group number (taken BEFORE the body) and `A_CAP` wrapper live together; `Ctx.want_caps` is the ONLY gate (false = tree byte-identical to D31's); the wrapper PROPAGATES `not_repeatable`; capture wrap goes OUTSIDE the bare-anchor `A_CAT` wrap. Named/numbered groups always build the wrapper; `pcrec_bref_resolve` deletes unread ones.
- Bare-anchor rule is ONE function pair: `pcrec_is_bare_anchor` / `pcrec_wrap_bare_anchor` (parse.c); never hand-copy it (four copies drifted before). `not_repeatable` is NOT part of the predicate (per-node flag a bare option run sets: `(?:(?i))*` is error 109, `(^)*` is not). `A_LOOK` and `A_CALL` answer false (repeatable); `la_has_kreset`'s `A_CALL` case answers false and the post-resolution check obligation stays (re-check over the call graph / refuse / measure).
- A bare option run's node is `not_repeatable` (R20/SPEC-1); boundary is BARE-vs-SCOPING; lexical constructs (`\Q\E`, `(?#)`) are TRANSPARENT to a following quantifier.
- Lexical modes: `\Q...\E` lives IN parse.c (RF_LEXICAL, `Ctx.in_quote`, gated on `pcrec_feature_enabled(FEAT_QUOTING)`; no `mod_quoting.c`, no registry port ever for an RF_LEXICAL row). Transparency rule: empty `\Q\E` and stray `\E` vanish at `xskip` boundaries; `cat_ends` closes a quote BEFORE judging a boundary and returns false while a quoted byte is pending; in classes the range grammar sees through empty quotes but a QUOTED dash is never a range (`p_class` dash lookahead gated `!cx->in_quote`); `\Q` backslash is a plain byte. x/xx consumers: `xskip`, `cls_skip`, `cls_peek_past_dash`. Quoted quantifier chars must not be live (`p_rep` in_quote guard, S212).
- Case folding (OS-1/D23): `options.caseless` handled here by `cls_casefold` (ASCII only); FOLD THE POSITIVE SET, THEN NEGATE; every site building an A_CLASS must fold (char_node, p_class; `.` needs nothing); a new class-producing construct calls `cls_casefold` itself (no post-parse AST walk: unbounded recursion, DD-10/TS-4). Class fold T2 = `fold_rows` in parse.c (rows as data). Pinned by tests/base/caseless.rxt.
- Scoped modifier state is resolved at parse time ONTO THE NODE; no post-parse pass reads it (compile error outside src/parse via incomplete `ParseMods`, parse_mods.h). Need a modifier's decision elsewhere? add a node field (`Ast.u.rep.greedy`, `Ast.u.anch.multiline`), not a wider read. `pcrec_parse_mods_init` is the ONE seeding entry point; every Ctx reaching a parser/port calls it.
- Context nodes ([DD-11.5]): `^`/`$` under `(?m)` build A_CTX (`mline_ctx`, `nl_convs[]`; a multi-byte newline convention refuses by name); `pcrec_ast_pin` (parse.c) builds the subject PIN for `^` (outside `(?m)`), `\A`, `\z`, spelled as an anchor so `\A*` stays error 109; `\A` still raises LB 1. `pcrec_ast_is_core` treats A_CTX as core. The registry's `^` row description still says "A_BOL" (filed, not changed).
- Lookbehind max ([UTF-VALID], D133): `Ctx.lb_max` is a parse-time running max raised only via `pcrec_lb_raise`: `mod_assertions.c` raises 1 for `\A`, `\b`, `\B`; `mod_lookaround.c` raises the widest branch (`la_lb_raise`) where a width table settles (hook, or `pcrec_lookaround_fix_widths`) and 1 for a one-char lookbehind turned context node. Nesting is max, never sum; dead DEFINE bodies count; the future `[[:<:]]` producer must raise LB.
- Module handlers: each module's handlers live in their own FLAT TU `mod_<module>.c` here (not a subdirectory), added when the module lands. Handler families: esc_class, esc_assert, esc_backref, esc_uniprop, esc_misc, grp_lookaround, grp_named, grp_atomic, grp_cond, grp_recurse, grp_modifier, grp_callout, verbs, cls_posix. Keep a module's measured-grammar comment WITH its code (probes-and-code-together rule).
- A port that dispatches several rows on `sel` shares one producer (assertions, named-groups, lookaround, backrefs); an alias row resolves through `family` to its primary; flags/kinds are decided in ONE place (`la_kind`). Stamp `Ast.reg` with the ROW (SR-8/D67), never a copy of the mask; an unstamped node claims both engines on purpose. Stamp the A_BREF only (per-node answer).
- Enabled-set (enabled.c): process-wide, written once by `--features` before any compile, NOT a pcrec_options field (D20); `std1` named set is FROZEN forever; `pcrec_default_features` is D37's single mapping point (stays "none" until the deliberate re-baseline commit); `render_modules` over-long policy is an ordered prefix; one name->bits lookup (`find_module_bits`). Enabling a module with producers changes verdicts (check07's transition rule).
- Module-specific invariants:
  - unicode-props (mod_uprops.c): scanner algorithm unchanged (146 malformed vs 147 unknown, 48 significant chars `PCREC_UPROP_NAME_MAX`, caret rule, blame offsets); ports stay `NO_PORT` (function takes `in_class`); caseless rule is a SPAN SUBSTITUTION, never `cls_casefold` (`\p{Lu}`/`Ll`/`Lt` = `L&` under -i, all else invariant); table lookup brace-path is fold-free; bare `\p{Greek}` = Script|Script_Extensions, `sc=` strict; tables generated by `third_party/ucd-16.0.0/generate.py` (no hand copy, no libpcre2-generated copy: PC-3 must ask the live oracle about a table it did not produce); `Katakana_Or_Hiragana` declined; refusals split by gate state and closed-gate texts stay byte-identical (tests/reject pins).
  - ucp (mod_ucp.c): `(*UTF)`/`(*UCP)` option run, `-e utf8` implies `ucp`+`unicode-props`; UCP sets are data (`PcrecSetDef`), one producer `pcrec_setdef_class`; wide set under utf8 refused by name (D130 Q3).
  - named-groups: `cx->ncap` increments unconditionally (ignores `(?n)`); name grammar measured (128 bytes `PCREC_MAX_GROUP_NAME`); no DUPNAMES/`(?J)` (ruled out; J refuses via K14 permanent wording, unconditional); `Ctx.named_groups` feeds emit's `rx_info.groups`.
  - assertions: `\A \Z \z \b \B \G \K` via `pcrec_asrtport_atom`; `Ast.u.anch.multiline` left zero for `\A`/`\Z` (unaffected by multiline); rows keep `RF_CLASS_INVALID`/`NO_PORT` except `\b` (keeps its scalar class port, backspace); not-repeatable inherited; `\K` records `cx->first_kreset_pos` and is the only VM_ONLY row; `\z` has its own kind.
  - lookaround: ONE port for all rows; width rule `la_widths` (written order reverse of walk; branch count from `AltInfo.nbr`); call-containing bodies defer to `pcrec_lookaround_fix_widths` (hook records `u.look.at/nbranch`, `widths==NULL` = PENDING); refusal sentence has one home `la_width_refusal`; deferral test is `pcrec_has_call`; `\K` in lookaround refused PERMANENTLY (err 199; `PCRE2_EXTRA_ALLOW_LOOKAROUND_BSK` not adopted, not to be proposed); `not_repeatable` propagated from the body.
  - atomic-groups: `(?>` port plus `X*+` suffixes desugared in `p_rep` to `A_ATOMIC(A_REP(X))`; `RK_QUANTSUFFIX` rows are consulted by the dump and `p_rep` only; `Ctx.first_atomic_pos` is diagnostic-offset only.
  - backrefs: four ports, one node kind; octal rule is four ordered questions (asymmetry groups-so-far vs whole-pattern is load-bearing); `pcrec_clsport_octal` (parse.c) is the single octal scan; ports RECORD a `PendingRef`, `pcrec_bref_resolve` settles at end of parse (single "group k exists" definition); only rule 3's backref-vs-octal decision cannot defer; `\g<`/`\g'` cases build `A_CALL` via recursion's exports.
  - recursion: ports `_num`/`_rel`/`_name` + `pcrec_rcport_define`; roots `(?R)/(?0)/(?00)` and absolute-zero `\g<0>` never queue a `PendingRef`; relative never the root; A_CALL target = ONE number resolved to the FIRST DECLARATION (§3.4(c)); `(?(DEFINE)` = `A_REP{0,0}` over body (artifact identical to `(?:BODY){0}`, codegen rule 4); `pcrec_call_node`/`pcrec_call_by_name` exports; `PendingRef` carries `PendKind`.
  - vars (mod_vars.c): `${name}`; grammar lives in `src/core/varexp.c` (shared consumer); recognition is one `if` in `p_atom` + direct `pcrec_feature_enabled` test (RK_BARE has no dispatch); two intern tables (`Ctx.var_names` distinct names, `Ctx.var_exps` distinct expansions, nested interned bottom-up); resolution at END of parse; `pcrec_has_var` is MANDATORY in `prefilter_decision` (nfa.c has no A_VAR case). Contract docs/spec/vars.md.
  - modifiers: `m` real; `J` refuses unconditionally with K14 wording; per-letter module-off refusal is produced here; option run grammar in `pcrec_registry_option_run_ok`, `recognise` marker is pointer-identity (never reconstruct from `at`).
  - classes: includes generated cls_bits.inc (regenerate with `probe_cls_bits --emit`, never hand-edit); negation is table-free (complement law); `pcrec_ast_class_from_bits` is the ONE constructor owning fold-before-negate; a SET at a range endpoint refuses (err-150 analogue) in both gate states.
- Definitions (definitions.c, D85): `pcrec_def_tag_applies` is the single exhaustive no-default switch over `DefTag` with exactly ONE caller (`pcrec_def_resolve`; grep-checked in tests/registry/run_definitions_tests.sh); `pcrec_ast_is_core`/`_all_core` are the exhaustive switch over `AKind`; `DEF_IDENTITY` is always an EXPLICIT entry (resolve fallthrough is an `assert`); `DEFK_ROW` chains to another row's resolution (depth bound 4), never restate a fact a row carries; `DEFK_TEXTFN`/`DEFK_BUILDER` `str` is a template (one placeholder `X`); POSIX names stay `DEFK_STR`; `RK_BARE` rows (`^`, `$`, capturing group) are consulted by dumps/definitions only; changing `RK_COUNT` means re-measuring every `RK_COUNT`-shaped guard live (tests/registry/CLAUDE.md, docs/spec/registry.md §2/§9); wiring definitions into real AST construction is [DD-11.5] (read definitions_table.md §4's DFA-erasure hazard first).
- `.rxt` readers (rxt_*): the head grammar has ONE implementation (rxt_source.c); the BODY has three readers on purpose (`tests/harness/run.sh`, `tests/harness/verify_rxt.py`, this) and the NAME grammar has three readers that move together (here, run.sh's `name` case, verify_rxt.py's `NAME_RE`; C1 differential). `rxt_schema.def` (X-macro, `.def` must be in the object rule's Makefile prerequisites) DECLARES what is legal where; the parser decides only what a legal line MEANS. A withdrawn production has NO row. Every diagnostic carries a class tag first in brackets (`[structure-attachment]`, `[unknown-token-in-scope]`, `[schema-constraint]`, `[value-shape]`). The prose-region trigger is kind AND bare `|` AND not in an open subtree. Cardinality is enforced generically from the column. `--list-source` TSV is the contract (docs/spec/rxt_format.md, docs/spec/table_contract.md; 15 columns AS WRITTEN, cols 4/5/15 escaped in the `.rxt` subject vocabulary; no filesystem at parse time). `pcrec_rxt_decode_escaped` is the one decoder (`\x00` refused citing K9); `pcrec_rxt_prefix_from_name` is the one home of `-`/`.` to `_`; `defname_ok` is not `ident_ok` (keep two); `pcrec_rxt_flags_from_letters` lives here; ONE `RxtRow` type in file order; no `Ctx` here (errors returned, naming FILE, LINE, CONSTRUCT; W2/W3 keywords refused as NOT IN THIS BUILD, never unknown); `cfg_merge` is the one later-wins rule for `with`/`from`; the per-kind table applies once in `resolve_one`; `#section` record types (`RxtProv/Variant/Case/Aux`) are accumulated and dumped only here; `RXT_CLOSE_FRAME` has FOUR call sites (dedent pop, EOF, blank/comment S0 close, new group) keep them one mechanism; `read_prose_region` validates content-line indent before stripping (K57FIX; same rule in run.sh `prose_take` and verify_rxt.py); `parse_case_body` is a best-effort split, NOT a second validator; `prose_value` subtracts indent before reading; `under_key_distinct.rxtin` is the accept half for the under tuple; fragment rule is a sub-parse (`fragment_check`); `pcrec_bref_resolve` defers unresolved by-name `PEND_CALL` when `Ctx.defer_file_refs`, never `PEND_BREF` (D87 rule 2), `deferred` written explicitly.
- Composer (rxt_compose.c, D89): runs BETWEEN `pcrec_parse` and `pcrec_altcls`, before `pcrec_callgraph_build`; output in NUMBERS not pointers; adds no AST shape (bound definition = `A_REP{0,0}(A_CAP{base}(body))`); three tiers DELIVERED (named) / HIDDEN (unnamed but read) / ERASED (unnamed, unread: spends no number), slot MAP not `+base`; delivery is declared by NAMING; early return when `cx->defs` is NULL (non-`--source` artifacts byte-identical); by-name calls bind through the derived identifier (`pcrec_rxt_prefix_from_name`), collisions (`x_y` vs `x-y`) refuse naming BOTH; closure walk keyed on resolved path, `lib` declaration order, duplicate definition names across the closure refuse.
- Analysis resolution (rxt_find.c, [FINDINGS] B2 / [KNOW-SRC]): stops S1 own bundles, S2 `DIR/<name>.rxt` per `-I` (exact entry match), S3 store; then `include` with `#include_next`, `PCREC_MAX_FIND_CHAIN`, built-in `default` terminal by identity; chain returned is plain data copied into the caller's arena; the stop loop is the knowledge module's (`pcrec_ks_resolve` under `pcrec_ks_analysis`/`pcrec_ks_lib`); name rule is `pcrec_ks_name_ok` at every caller; query vocabulary via `pcrec_find_query`/`pcrec_find_query_tags` (no local list); compile.o names `pcrec_find_resolve` (the `.rxt` reader is on the library compile path; composer only is rxt-free).

## Files

- scans.c — always-live extent scans (K4 three-rule delimiter-pair scan, `pcrec_ext_class_pair_opens`, verb-name extent); pure over (pat, patlen); never links enabled-set symbols
- enabled.c — the enabled feature set (`--features`, `std1` named set, `pcrec_default_features`, `pcrec_enabled_set_label/_modules`)
- parse.c — base grammar, AST, case fold T2 (`fold_rows`), `\Q\E` lexing, bare-anchor helpers, `pcrec_ast_pin`, `pcrec_parse_body`, `pcrec_parse_mods_init`
- parse_mods.h — ModState/ParseMods definition; included by nothing outside this directory
- registry.c — construct registry (D24/SR-1): all non-base rows, `bare_rows[]`, index rows, arbitration, `pcrec_registry_verb_name_row`
- ext.c — three of the four doorways (`pcrec_ext_escape`, `pcrec_ext_group`, `pcrec_ext_class_bracket`), `pcrec_ext_gate`, `pcrec_ext_finish`
- ctxnode.c — lookaround to context-node lowering table (`ctx-node` row, `-fno-ctx-node`/`PCREC_NO_CTX_NODE`; `pcrec_look_rows`)
- definitions.c — `RegRow.definitions` evaluator/resolver/tag-namer/core-set predicates (D85)
- mod_verbs.c — `(*` doorway (`pcrec_ext_verb`), VerbName tables; resolves a name to its own row
- mod_classes.c — module `classes`: POSIX port, includes generated cls_bits.inc
- cls_bits.inc — GENERATED positive byte-set tables (do not edit)
- mod_modifiers.c — module `modifiers`: option-run grammar and semantic port (`pcrec_modport_optrun`)
- mod_uprops.c — module `unicode-props` scanner + producer; uprops_tables.inc GENERATED from third_party/ucd-16.0.0
- uprops_tables.inc — GENERATED category/script tables (do not edit)
- mod_ucp.c — module `ucp`: `(*UTF)`/`(*UCP)`, option run, UCP sets
- mod_named_groups.c — module `named-groups` declaring port
- mod_assertions.c — module `assertions` (`\A \Z \z \b \B \G \K`)
- mod_lookaround.c — module `lookaround` (one port, width rule, `\K` check)
- mod_atomic_groups.c — module `atomic-groups`, `pcrec_atomic_suffix_row`
- mod_vars.c — module `vars` (`${name}`)
- mod_backrefs.c — module `backrefs`, `pcrec_bref_resolve`
- mod_recursion.c — module `recursion` (calls, DEFINE)
- rxt_schema.def / rxt_schema.c — `.rxt` format schema as data and its reader (one exhaustive switch over the constraint kinds)
- rxt_source.c — `.rxt` head parser, `--list-source`, resolution (`pcrec_rxt_source_resolve`), `lib` closure
- rxt_find.c — analysis-bundle resolution chain ([FINDINGS] B2)
- ks_analysis.c / ks_lib.c — knowledge-module kind rows for analysis and `lib` ([KNOW-SRC])
- rxt_compose.c — the composer binding `.rxt` definitions into the target tree (W1.3)
