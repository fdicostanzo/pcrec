  - recursion: ports `_num`/`_rel`/`_name` + `pcrec_rcport_define`; roots `(?R)/(?0)/(?00)` and absolute-zero `\g<0>` never queue a `PendingRef`; relative never the root; A_CALL target = ONE number resolved to the FIRST DECLARATION (§3.4(c)); `(?(DEFINE)` = `A_REP{0,0}` over body (artifact identical to `(?:BODY){0}`, codegen rule 4); `pcrec_call_node`/`pcrec_call_by_name` exports; `PendingRef` carries `PendKind`.

## Parser structure details (PARSE-1)

- Capturing `(` hook (`p_group_body`): `Ctx.ncap++`, group number (taken BEFORE the body) and `A_CAP` wrapper live together; `Ctx.want_caps` is the ONLY gate (false = tree byte-identical to D31's); the wrapper does not copy `not_repeatable` (the seal already cleared it, K124); capture wrap goes OUTSIDE the bare-anchor `A_CAT` wrap. Named/numbered groups always build the wrapper; `pcrec_bref_resolve` deletes unread ones.
- Bare-anchor rule is ONE function pair: `pcrec_is_bare_anchor` / `pcrec_wrap_bare_anchor` (parse.c); never hand-copy it (four copies drifted before). `not_repeatable` is a per-node flag a bare option run sets (`a(?i)*` is error 109); `pcrec_wrap_bare_anchor` ALSO clears it on a group's body (in place, never a wrap, so no previously-right tree moves), so every group is repeatable (`(?:(?i))*` compiles, K124). `A_LOOK` and `A_CALL` answer false (repeatable); `la_has_kreset`'s `A_CALL` case answers false and the post-resolution check obligation stays (re-check over the call graph / refuse / measure).
- A bare option run's node is `not_repeatable` (R20/SPEC-1); boundary is BARE-vs-SCOPING; lexical constructs (`\Q\E`, `(?#)`) are TRANSPARENT to a following quantifier.
- Lexical modes: `\Q...\E` lives IN parse.c (RF_LEXICAL, `Ctx.in_quote`, gated on `pcrec_feature_enabled(FEAT_QUOTING)`; no `mod_quoting.c`, no registry port ever for an RF_LEXICAL row). Transparency rule: empty `\Q\E` and stray `\E` vanish at `xskip` boundaries; `cat_ends` closes a quote BEFORE judging a boundary and returns false while a quoted byte is pending; in classes the range grammar sees through empty quotes but a QUOTED dash is never a range (`p_class` dash lookahead gated `!cx->in_quote`); `\Q` backslash is a plain byte. x/xx consumers: `xskip`, `cls_skip`, `cls_peek_past_dash`. Quoted quantifier chars must not be live (`p_rep` in_quote guard, S212).
- Case folding (OS-1/D23): `options.caseless` handled here by `cls_casefold` (ASCII only); FOLD THE POSITIVE SET, THEN NEGATE; every site building an A_CLASS must fold (char_node, p_class; `.` needs nothing); a new class-producing construct calls `cls_casefold` itself (no post-parse AST walk: unbounded recursion, DD-10/TS-4). Class fold T2 = `fold_rows` in parse.c (rows as data). Pinned by tests/base/caseless.rxt.
- Scoped modifier state is resolved at parse time ONTO THE NODE; no post-parse pass reads it (compile error outside src/parse via incomplete `ParseMods`, parse_mods.h). Need a modifier's decision elsewhere? add a node field (`Ast.u.rep.greedy`, `Ast.u.anch.multiline`), not a wider read. `pcrec_parse_mods_init` is the ONE seeding entry point; every Ctx reaching a parser/port calls it.
- Context nodes ([DD-11.5]): `^`/`$` under `(?m)` build A_CTX (`mline_ctx`, `nl_convs[]`; a multi-byte newline convention refuses by name); `pcrec_ast_pin` (parse.c) builds the subject PIN for `^` (outside `(?m)`), `\A`, `\z`, spelled as an anchor so `\A*` stays error 109; `\A` still raises LB 1. `pcrec_ast_is_core` treats A_CTX as core. The registry's `^` row description still says "A_BOL" (filed, not changed).
- Lookbehind max ([UTF-VALID], D133): `Ctx.lb_max` is a parse-time running max raised only via `pcrec_lb_raise`: `mod_assertions.c` raises 1 for `\A`, `\b`, `\B`; `mod_lookaround.c` raises the widest branch (`la_lb_raise`) where a width table settles (hook, or `pcrec_lookaround_fix_widths`) and 1 for a one-char lookbehind turned context node. Nesting is max, never sum; dead DEFINE bodies count; the future `[[:<:]]` producer must raise LB.
- Module handlers: each module's handlers live in their own FLAT TU `mod_<module>.c` here (not a subdirectory), added when the module lands. Handler families: esc_class, esc_assert, esc_backref, esc_uniprop, esc_misc, grp_lookaround, grp_named, grp_atomic, grp_cond, grp_recurse, grp_modifier, grp_callout, verbs, cls_posix. Keep a module's measured-grammar comment WITH its code (probes-and-code-together rule).
- A port that dispatches several rows on `sel` shares one producer (assertions, named-groups, lookaround, backrefs); an alias row resolves through `family` to its primary; flags/kinds are decided in ONE place (`la_kind`). Stamp `Ast.reg` with the ROW (SR-8/D67), never a copy of the mask; an unstamped node claims both engines on purpose. Stamp the A_BREF only (per-node answer).
- Enabled-set (enabled.c): process-wide, written once by `--features` before any compile, NOT a pcrec_options field (D20); `std1` named set is FROZEN forever; `pcrec_default_features` is D37's single mapping point (stays "none" until the deliberate re-baseline commit); `render_modules` over-long policy is an ordered prefix; one name->bits lookup (`find_module_bits`). Enabling a module with producers changes verdicts (check07's transition rule).

## Registry: tail selection and engines column

- The `engines` column is design intent, not measurement; nothing consumes it. The tripwire `check_engine_capability_tripwire` (tests/registry/registry_check.c) guards the gap (every VM_ONLY RS_MODULE row has no wired producer; `\K` is the one NAMED exception, asserted live). Do not build on its values unchecked; wiring a second such construct is when SR-8 earns its consultation axis.
- Tail selection (SR-9, MOD-0.2/D32): a row may carry a `tail` (literal prefix, not a pattern). Lookup = RECOGNISER + RANK; highest-ranked ANSWERING row wins; two answers at the WINNING rank is a defect (internal error), never resolved by declaration order. Ranks: 0 fallback, 25 tailed, 70 `\N{U+`; meaningful only between clashing rows (RegRow.rank). Row ORDER must not be able to stand in for the rule (keep the `\N` pair shortest-first). Use `tail` before any compound module name (no compound names like the retired "lookaround/named-groups"). `(?-` keeps ten rows "0".."9" (collapse deferred until a passing reachability differential). Checks: `check_row_ranks`, `check_arbitration_liveness`.
