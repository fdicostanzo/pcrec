
## [FINDALL-NEXT] lane iterland: additions carried from lane/itertri (verbatim)

- **dfa.c** — priority subset construction with byte equivalence classes; `prune` on for forward machines (leftmost-first accept-pruning), off for the reverse machine (must keep all threads to find the earliest match start); **[UCP] U2 (ucp_design.md §2.4): THE CLASS AXIS IS A PER-MACHINE CONTEXT-SET LIST.** `ctx_collect` fills `Dfa.ctx[]` from a contributor table (every A_CTX set — `\b`/`\B`'s word set, a recognized one-character lookaround's set — then the newline set of `(?m)^/$`, then the encoding's non-start set for K50's gate), `eqclasses` refines by each, and a byte's context is its ATOM (membership vector); `DState.up[]`, `s1u[]`/`s1g[]` are atom-indexed and sized to the realized count, `upc_of_class` is a table read. Overlapping sets are exact by construction (the old fixed UPC if-chain was exact only for disjoint sets). Over `PCREC_MAX_CTX_SETS`/`PCREC_MAX_CTX_ATOMS` the build is declined like a state-cap overflow. The `-DPCREC_NO_WORDCTX`/`NO_MLINECTX` reference knobs sit in `ctx_entry_live`, the list's two consumers. The closure's N_CTX arm is one truth-function read, whatever spelling produced the node. **[FINDALL-NEXT] I0 (lane i1build, 2026-10-21): THE NOTEMPTY START ROOT.** `Dfa.notempty` (an input, a memo key in `src/opt/dfamemo.c`) builds every START state as the start closure with its accepting threads removed and no accept pruning (`Mach.noacc`), closed with `\G` true, so the machine's matches are the preferred NON-EMPTY match at the start: the find-all iterator's NOTEMPTY_ATSTART retry (findall_iter.md §3.3). Every state after the first byte is the ordinary construction's.
