# src/ir — NFA construction and DFA compilation

AST -> priority Thompson NFA (nfa.c) -> DFA via priority subset construction (dfa.c). Priority order on NFA split edges encodes greedy/lazy and alternation preference; subset construction with accept-pruning gives PCRE leftmost-first semantics.

## Standing rules

- Maintenance: update this file when files are added/removed or their roles change.
- NFA states are a flat array; split edges are `state*2 + slot` (slot 0 preferred, 1 alternate). Split order encodes choice preference (D3). Byte equivalence classes are computed first so DFA tables are ncls-wide.
- Every nfa.c arm that WIDENS the machine's language records itself in `Nfa.erased` (`NFA_ERASED_LOOK`/`_ATOMIC`/`_COUNT`), reset per build; `pcrec_vm_prefilter_window` reads `erased == 0` ([OPT-REVEND] L0, locate_finish.md §1.2). A later relaxation records its own bit in its arm.
- `A_CAP` is INVISIBLE in nfa.c via `ast_bare` ([M4.5b]): applied at compile_ast entry, trie_key spine head and leaves, and both spine flattenings. Missing a call site perturbs trie eligibility (gate failure, not a wrong answer). Keeps `(a|b)+c` state-for-state equal to `(?:a|b)+c` (engine_m4.md §6.1/§5.4).
- The `X{m,n}` tail loop INHERITS its out-patch array (`Frag w = { s, cat.out }`), never copies it ([M4.7b/K7]: copying made construction quadratic). `nst`'s state-count check reads the raise-only per-compile `opt->max_nfa_states` ([LIM-2] N1; table in `cli/main.c` `raise_only_limits[]`).
- Trie factoring (M2.8, D9) must stay output-preserving: keep both soundness guards (index-range partitioning around a mid-trie branch end; pairwise-disjointness before reordering). `-DPCREC_NO_TRIE` is for `tests/codegen/run_trie_identity.sh` only; never defined in a shipped build.
- Reference `-D` knobs (`PCREC_NO_ENDVAR`, `NO_WORDCTX`; `NO_MLINECTX` deleted by DD-11.5) exist solely for their identity scripts (`run_endvar_identity.sh`, `run_wordctx_identity.sh`); never in a shipped build. A knob must NOT share a source with the code a sabotage edits (it cancels the sabotage in both builds; S71/S83): place it at the analysis's ACTION (`eqclasses` refinement, `make_state` interning) plus a pin in front of the flag's consumers, and an emitter half where emitted text decides. `-DPCREC_NO_GSTART` lives in `src/gen/emit_dfa.c`, not here. The K50 axis ships NO knob (no pre-K50 reference is correct); its gate is `tests/utf8/run_startbnd_diff.sh` + S234/S235.
- `pcrec_build_dfa` takes `root` and `optional` as parameters ([ENG-ABS]); `optional` is read only in `intern`'s "pattern too complex" sites (record on `Dfa.overflowed`, return `PCREC_DFA_DEAD`, no refusal). Takes `reverse` explicitly (never derived from `prune`; prune on for forward, off for reverse which keeps all threads). DIRECTION appears in one place: `make_state`'s `sides_of`; closure operands are named by SIDE (`left_*`/`right_*`).
- Overflow is a RESULT, not a special case ([SEL-1], [LIM-2] N1): `intern()`'s checks (state count, `PCREC_MAX_SUBSET_ELEMS`, and the auto-only smaller `PCREC_MAX_AUTO_DFA_ELEMS` when `!d->optional && engine==AUTO`) record `Ctx.dfa_overflowed`/`dfa_overflow_why`/`dfa_overflow_is_budget` before the unchanged `pcrec_ctx_fail`. Gate: `tests/codegen/run_n1_budget.sh`. `tab_grow` and the reallocs fail via `pcrec_ctx_nomem`, never `abort`.
- Class axis = per-machine CONTEXT-SET LIST ([UCP] U2): `ctx_collect` fills `Dfa.ctx[]` (A_CTX sets, then newline set, then encoding non-start set); `eqclasses` refines by each; a byte's context is its ATOM. Over `PCREC_MAX_CTX_SETS`/`_ATOMS` the build is declined like a state-cap overflow. Anchors/`(?m)` are N_CTX rows (DD-11.5 P2d/P2e: N_BOT/N_END and A_BOL/A_END deleted; `src/core/ctxfn.def`; `cr_ctx_reads` -> `ctxfn_reads_membership` so absent-only rows add no set, S1171). N_CTX reads each side three-valued (`left_abs`/`right_abs`), "absent" only where the ctxfn row reads absent (re-check R1).
- `end_ok` view ([M6.2] A): `endvar` is interned iff it differs from the EOL view, NOT the base (else artifacts stop being byte-identical). Word assertions: `eqclasses` refines by `pcrec_cls_word_esc` (one spelling shared with `\w`); the previous-byte-word bit is NOT a state field. `(?m)^` is not the mirror of `(?m)$` (newline half guarded by `!end_ok`; `tests/assertions/run_mline_diff.sh`).
- `\G`: `s0` closed with `gst_ok` TRUE (derived: start==0 implies startpos==0), every worklist successor with it FALSE (mid-pattern `\G` unsatisfiable); `s1g[]` is the second start family; `gst_ok` is a caller parameter, no invariant to other bits.
- [K50] unanchored wrap: `pcrec_nfa_wrap_unanchored` builds TWO splits; `nfa->start` stays UNGATED (caller's position), the self-loop returns to a split gated by `N_CSTART` (`PcrecEnc.start_cls`, NULL under byte). `UPC_NOSTART` must be a refinement of `UPC_PLAIN` (checked: `pcrec_enc_start_cls_ok`). `Dfa.startcls` set ONLY when the machine carries `N_CSTART`, cleared at the top of `pcrec_build_dfa` (one `Dfa` is reused across builds).
- Non-lowerable arms (the lowering choice per construct is load-bearing; do not "approximate"): `A_KRESET` -> N_EPS (exact; changes no language); `A_BREF` has NO machine, falls to internal error deliberately (nothing builds it: `select_engine.c` forces prefilter off and refuses `-fprefilter` on backref patterns) ([M6.5.2]); `A_LOOK` -> N_EPS = SOUND SUPERSET (sound for rejection and span START, not END; `pcrec_has_lookaround` switches off the MRL window ceiling; [ENG-LOOK], lookaround_design.md §5); `A_CALL`: CALL_SPLICE callee is INLINED exactly ([DD-14] wave G), a LINKED call reaching the builder is a hard internal error; the descent follows `Ast.u.call.body` (the AST's one back edge), bounded by `NB.splice_depth` (S175).
- Closure: visit marks generation-stamped (D10). PCRE empty-iteration rule lives in the closure walk (ε re-arrival at a loop entry follows the EXIT edge; not one-shot, K17). The closure is PATH-SENSITIVE (K18): memo keyed (state, open-loop ctx), interned immutable ctx chain; keep the ctx-0 fast path; NO recursion in `clo_walk` (explicit LIFO); both `DFA_INVARIANT` checks stay live (`pcrec_ctx_fail`, K61). Read `docs/design/k18_memo_design.md` §2a/§3 + known_issues.md K17/K18 before touching it; guards `tests/base/k18_*.rxt`. [OPT-CLOSURE-CTX] (K67): memo/ctx tables hash via `hash_slot`; loops whose entry is on no epsilon cycle (`eps_cyclic`) open no context.
- PCRE2-semantics and emitted-byte changes here must be checked with the identity scripts above and `make test-codegen`.

## Files

- nfa.c — Thompson NFA construction; reverse compile (D7), `pcrec_nfa_wrap_unanchored`, iterative CAT/ALT spine flattening (R1 R-2), prefix trie for flat alternations (trie_build/trie_key; reverse mode factors suffixes), `A_CALL` splice.
- dfa.c — priority subset construction, byte equivalence classes, closure walk, EOL/end variants, per-engine state caps (R1 A-3), `PCREC_MAX_SUBSET_ELEMS` charge in `intern()`.
