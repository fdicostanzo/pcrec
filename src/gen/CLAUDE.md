# src/gen — C code generation

Emits self-contained gcc-dialect C from the DFA machines and the VM program; the generated code has zero dependency on pcrec at build or run time. Two DFA engines (D7): ENG_UNANCH (patterns without `^`, `$`-bearing ones included, D8) = table-driven forward scan + reverse scan for the start, with a memchr/bitmap start prefilter; ENG_ATTEMPT (`^` patterns) = per-start computed-goto attempt loop with EOL-variant states. Tables because gcc compile time on huge computed-goto functions is superlinear (R1 A-3). `emit_vm.c` is the backtracking-VM emitter (one function per pattern, computed goto, one `goto *` at the fail label plus one per shared callee body).

## Standing rules

### The memfn kit owns the search TEXT of delegated sites
- The text of the DELEG_SITES (PRE+SETREST, OFS, PF, MLINE, N7, STAY/EDGE/VMSPAN/VMSTRIDE, VMRUN, `cover`; list: `memfn_sites.def`) is the kit's (D146, `memfn/CLAUDE.md` "The boundary with pcrec"; D147 layers; `memfn/src/{precheck,ofsskip,pffind,mismatch,generic}.c`). Edit it in `memfn/`, not here. A change to what a delegated site EMITS is a kit change: its own `--memfn=no-NAME` row, `tests/memfn/pins/arms.tsv` re-pin, and a pcrec abi event in the same commit. A change to a DECISION (admission, lead, runs, set, handoff, description builders such as `req_site_define`, `ofs_site_define`, `find_site`, `pcrec_memfn_advance_site`, `pcrec_memfn_span_site`) stays here. Read `memfn/CLAUDE.md` + D146/D147 before touching search/scan emission.
- Describe a site via `pcrec_emit_find` / `pcrec_memfn_emit` and let the kit write it; do not spell a find/skip loop locally. Generalize the shared description (`PcrecFind`, `PcrecAdvance`) rather than adding a parallel mechanism. Site description and the pcrec-side builders for one site come from ONE constructor each (`pf_site_of`, `mline_find_of`, ...).
- `memfn_sites.h` is the one pcrec header that includes the kit's (`memfn/include/memfn.h`). Checks: C10 `tests/memfn/run_deleg_sites.sh`, C5 `tests/memfn/run_arm_pins.sh`, C17 `tests/memfn/site_census.py`.
- pcrec -> kit carries FACTS only (D157); the kit's method is not presumed in fields or comments.
- Comments in the architecture-neutral emitter must stay ISA-neutral. A per-ISA SIMD form is reserved and ISA-NEUTRAL by ruling (R2): a form of the LOOP, never described as an x86 slot - the scalar loop is the portable baseline and stays the fallback forever. `tests/memfn/arch_blind_check.py` (C4, allowlist `tests/memfn/c4_allowlist.tsv`) counts architecture vocabulary in CLAUDE.md files: add none here.

### The `abi` number and emitted scaffolding
- `rx_info.abi` versions the emitted scaffolding as a whole (D76). Current value: `PCREC_ARTIFACT_ABI` (`emit_dfa.c`). The ONE canonical change log is `docs/dev/history/abi_changelog.md` (also spec `match_api.md` §6); `tests/codegen/run_codegen_tests.sh`'s transition string is a check message maintained FROM it, not a second home. Do not read an abi number in this file's history titles as the current one.
- Any change to emitted scaffolding (comments, declarations, layout, a stamp line on every artifact, a struct member) is an abi bump + identity-gate re-pin in the same change (D76/D94): grep the tree for EVERY reader of the current number (the `.abi` stamp, test expectations, spec sentences, the gate's (B) pin); run `make test-codegen`, then the suites that count (registry, codegen, rxtsource). A VALUE (new stamp token on an existing stamp, `declined-nullable`-style) is not scaffolding and needs no bump. Struct members are APPENDED at the end so no offset moves; the abi comment states the effect per artifact KIND (DFA and VM; `emit_info_def` is shared).
- Spec in the SAME change: `docs/spec/match_api.md` §6.3 (stamps: (a) selection facts unconditional on every artifact, (b) capacity/activity macros VM-only) and `docs/spec/tuning.md`.

### Emitted text and comments
- **Every whole-line comment site is BRACKETED** `pcrec_sb_cmt_open(buf, PCREC_CMT_NONESSENTIAL)` ... `pcrec_sb_cmt_close(buf)` ([EMIT-VERB], D112): a default artifact carries only essential comments (provenance line, `PCREC_RX_ABI_H` block doc-comments); the rest only under `-fcomments`. `PCREC_CMT_ESSENTIAL` has exactly two users in `emit_dfa.c`; a third needs D112's reasoning. An unbracketed site fails `tests/codegen/run_comments_axis.sh` arm 1; an open with no close silently truncates the buffer (`compile.c` checks balance). The separator blank line stays OUTSIDE the region (the comment-excluded size caps depend on it).
- Emitted text is ASCII-only, comments included. Emitted code must stay warning-clean under `-Wall -Wextra -Werror` (the harness enforces).
- [M6-READ] full names for locally scoped identifiers (style of record `docs/design/m6read_samples/`). FROZEN: everything with linkage and every name in the shared `PCREC_RX_ABI_H` block (`rx_ctx`, `rx_matchfn`, `rx_group_entry`, `struct rx_info`, `PCREC_*`); `emit_rx_abi_types` is EXCLUDED from `scripts/m6read_rename_emitted.py`. Before renaming emitted names, grep BOTH the composed and the direct spelling (revdet `%s_rv%d_mk` vs `%s_mk`). A name can carry a property tests rely on (`RX_PRUNE_*`, grepped by tests/mrl): a rename must preserve it.
- `emit_rx_abi_types`: once per file under the prefix-independent `#ifndef PCREC_RX_ABI_H` guard whose VALUE is the abi (K80: `#error` on a mixed-abi TU); fixed-literal ABI types, never `<prefix>`-scoped; universal macros (give-up codes, `PCREC_UNSET`, `PCREC_ENGINE_*`, D46 bit constants) live there unprefixed with no aliases ([ABI-NS], D60). Its text must name no particular ENCODING or prefix (placeholders only).
- K79: emitters see the render PLACEHOLDER prefix (`\x01q`/`\x01Q`), not the caller's. Never pass prefix-derived text through an escaper; never transform the prefix other than by `pcrec_sb_upper` (derived once in `pcrec_gen_names`; do not re-derive an uppercase at a call site). `emit_c_string_literal` uses fixed 3-digit OCTAL escapes, never `\xNN`.
- Every stamp line is ONE helper call: `pcrec_sb_stampf`/`_stampwf`/`_stamp_str` with a literal NAME; a new hand-written `pcrec_sb_printf(c, "#define %s_...")` in either emitter is a finding (function-like macro bodies and the streamed `_DFA_PREFILTER_OFFSETS` are the exceptions). Unconditional stamps share one emitter (`pcrec_emit_engine_stamp`). Formatted fragments use the arena (`pcrec_sb_fragf`/`vm_rolef`/`dfa_fragf`), never fixed `char[]` buffers. No silent-degradation path: allocation failure refuses through the arena -> `pcrec_ctx_nomem` (D105).
- Emission is DISCOVERED-BY-EMITTING for some facts (`Job.enc_mask`, class pool, cursor local, `has_push`): the prologue is written AFTER the program body; `job->enc_mask` is copied before use per the timing rule in `enc/CLAUDE.md`.
- Strategy-denial and force-pair flags are masked out of `rx_info.flags` (`emit_info_def`; mask DERIVED from `src/core/axes.def` minus the `kept` set, [FLAGBITS]): an axis that changes no answer must not make behaviorally identical artifacts differ; the activity record is `<PREFIX>_VM_STRATS` etc.
- `<prefix>_search` carries `__attribute__((noclone))` ([K24]): do NOT delete as decoration or replace with `hot`/`cold`; the lever must live in emitted text. One site serves both engines (`emit_search_head`). Reasoning: docs/dev/known_issues.md K24, docs/design/k24bisect_impl/k24_fix_note.md.
- The encoding seam ([M5-SEAM], D58): no encoding conditional in the emitter. This directory only looks up the backend's residual text (`emit_residual_decls`, `emit_residual_defs`/`pcrec_emit_residual`, both masked by `Job.enc_mask`) and copies it; adding an encoding test here is a design stop. The VM's unanchored retry advance comes from `PcrecEnc.advance` via `pcrec_enc_advance` (K49). Backreference compares go through the seam entries (`caseless` picks the entry at emit time, never a runtime flag). See `enc/CLAUDE.md`.
- Entry names come from `engine_entry_name()`/`derived_name()` only; file-scope names are per-prefix, locals are function-local (multi-engine naming surface, OS-0b), checked by the multi-engine block in `tests/codegen/run_codegen_tests.sh`.

### DFA emitter organization ([ENG-FORM], D82; note `docs/design/emitter_form.md`)
- Layer 1: the form is a VALUE. Per axis with >= 2 real forms there is a `static const` list in PREFERENCE order, first applicable wins: A `dfa_reprs`, B prefilter (`cand_rows[]` NEXT rows via `cand_select`), C `dfa_views`, D `dfa_seeds`, E `dfa_accs`, F `dfa_dir_forward`/`_reverse`, G `dfa_matches` (entry form, ENG-ABS), H/I scan edge (OPT-5), J start-pinned search. Rules: (1) every list's LAST entry always applies (`cand_always`); (2) the chosen object's `c.name` IS the stamp value (never re-derive a stamp from a predicate); (3) a `-fno-*` deny is the object's `c.deny` field, a FILTER on the list, never a clause in the emitter body; (4) only axes with >= 2 real forms get a list (facts stay booleans, D75 addendum). A new candidate needs no edit to the read-only axis accessors (`pcrec_dfa_axis_*_cands`, used by `--list-axes`).
- Layer 2: the emitted state is an OPAQUE TOKEN (typedef + accessors per machine at file scope via `repr->emit_token`); `emit_scan_loop` and `emit_machine_tables` are written once and called with forward and reverse `DfaForm`. A new table representation = one `dfa_reprs` entry + one `emit_token`. `<M>_row` MUST NOT be hoisted (a divide under pre-multiplied tables). Emitted state constants are scaled at EMIT time by `repr->cell_of`.
- ONE derivation, N readers (never restate a condition at a second site): `attempt_cand`, `unanch_start`, `dfa_engine_is_empty`, `dfa_match_of`, `req_admit`, `dfa_search_start_of`, `vm_marked`, `vm_cursor_fits`, `vm_cuts`/`vm_lifts`, `under_atomic` (threaded, never stored). The start-decision table is `cand_rows[]` ([START-TABLE], `docs/design/start_table.md`, D148): readers ask `cand_select`/`cand_read` (a slot's predicate asks another slot's row, never restates it), `CandNode.reads[]`/`kask` declare every read; `tests/codegen/run_cand_rows.sh` and `run_cand_oracle.sh` check.
- `emit_unanchored` handles EOL and non-EOL machines in ONE function (M2.12: a forked `$` copy lost the prefilter/skip loops). Under EOL every skip is bounded at n-1 and scan avoidance runs BEFORE the accept/EOL evaluation (D11). `views = eol || endv` is what every former `eol` site reads. `emit_view_select` is one branch that reproduces the old string (byte-identity discipline); `endvar == -1` = same as EOL view. The start dispatch order is load-bearing (`start == 0`, then `== startpos`, then above). `pick_skip_states` declines states whose accept varies by class. The `last_accept_position == (size_t)-1` gate is load-bearing. A reference knob for an identity gate goes at the emitter AND at the analysis action (`#ifndef` in `src/ir/dfa.c`) - a knob inside the sabotaged source cancels (wave D finding).
- Cost/soundness hazards: `vm_cost` must charge every trailed write (`A_ATOMIC` mark, `\K` one trail entry per emitted `\K`) or the artifact refuses subjects it can match; `A_CAP` publish-at-close for groups some `A_BREF` names (suppression covers both halves of the pending+pair publication); an atomic group's follow is zeroed at the BOUNDARY (`vm_atomic`) and restored after the cut; `vm_cut` is reused unchanged; the lookaround/callee follow is scoped to 0; slots 0 and 1 are never members of a call's `W`; `call_top` is on every frame and both reset functions set `call_top = CALL_TOP_NONE`; the callee region has its OWN exit; the `goto *` is written out inline per region; all call bytes gated on `Vm.has_calls`; `<prefix>_search_in` delegates to the un-suffixed entries never the reverse ([DD-14.FB]).
- Wave knobs/gates: `tests/codegen/run_endvar_identity.sh` (S69), `run_wordctx_identity.sh` (S71), `run_mlinectx_identity.sh` (S76), `run_gstart_identity.sh` (S83), `[M6.2-WORDB]`/`[M6.2-KRESET]`/`[DD-14-RECURSION]` blocks in `run_codegen_tests.sh`, `tests/assertions/run_mline_diff.sh`/`run_kreset_diff.sh`, `tests/codegen/run_dfa_stamps.sh` (stamp == loop), `run_vm_identity.sh` (DFA-only output byte-identical to pre-VM), `run_object_neutrality.sh`, `run_vm_frameless.sh`, `run_dfa_uniform_fold.sh`, `tests/utfcheck/`, `tests/kitproof/`, `tests/partlayout/`, `tests/compound/`.
- Stamp-scope rule: a stamp belongs to the mechanism it names, not the artifact kind that usually carries it (a hybrid stamps the scan it inlines through `pcrec_emit_dfa_scan_stamps`, gated on `fit.prefilter` only; `pcrec_artifact_has_dfa_scan`). `rx_info` mirror fields call the same derivations as the macros.
- `--emit-ir` is table-contract TSV ([DD-8], D106/D108; contract `docs/spec/ir_listing.md`, read before changing it): named `#section` blocks, cells literal or arena fragments, an empty population is a ROW with empty cells, never a `#` remark.
- `emit_state_legend` allocates from the arena; after a change run the witnesses in D105 notes (`x[0-9]{500}y`, `(?i)a{2,40}Z`, `((a)|b){0,4000}c`, `[a-z]{0,16384}`).
- Entry linkage is decided in `entries.c` only (EXPORTED / STATIC / OMITTED, derived edges from `entry_rows[]`); a request it cannot honour is an internal error. Attribute text comes only from `attr_text.c` (`pcrec_attr_text`). Part layout decisions only in `part_layout.c`'s declared first-match tables.

## Files

- `emit_dfa.c` — both DFA engine emitters (`emit_unanchored`, `emit_attempt`), the six+ axis lists and `cand_rows[]`, naming helpers, shared prologue/ABI types/`rx_info`/`main`/info emission, stamps, `pcrec_emit_find`, start-set/landing/cover rows, the pre-check admission (`req_*`), scan edge, `emit_state_legend`, residual decls/defs, `PCREC_ARTIFACT_ABI`.
- `emit_vm.c` — the backtracking VM emitter (rungs: cursor/frames/possessive/revdet/counter, MRL pruning, lookaround, atomic, backreferences, calls/splice, alternation island, entry ladder/default entry, hybrid prefilter and retry re-seed, `--emit-ir` listing, VM stamps, class kit callers).
- `emit_comb.c` — combinator emitters: every exported entry via `pcrec_emit_entry` (`forward`, `finish-at`, `locate-then-finish`, `first-nonzero`).
- `emit_compound.c` — compound artifact shell: parts' texts and the controller (`first-nonzero`), `callsite_rows[]` call-site table.
- `entries.c` — entry table and linkage closure (`entry_rows[]`, `PcrecEntryShape`, `pcrec_entry_linkage`); checks `tests/compound/` (`check_entry_ranks.py`, `entry_ranks.tsv`).
- `part_layout.c` — [ENTRY-TABLE] part-layout tables (art/part/wrap/head rows), marks, render, listings; checks `tests/partlayout/`.
- `attr_text.c` — [ATTR-TABLE] the one value-to-guarded-text table for function-linkage attributes.
- `memfn_sites.c` / `memfn_sites.h` / `memfn_sites.def` — pcrec's side of the kit's sites: DELEG_SITES, the `mf_art`, sink, constructors, define/use wrappers, `PcrecFind`, analysis/measures builders, deny map.
- `memfn_stamps.c` — the kit's every-artifact stamps (`_MEMFN_FORMS`, `_MEMFN_LIBC`, `_SIMD_GUARDED_BYTES`) and pcrec's knowledge stamps (`_FINDINGS`, `_MEASURES`) rendered over marks after emission; check `tests/memfn/run_libc_census.sh`.
- `clskit.c` / `clskit.h` — [CLS-TREE] class-matcher kit: leaf forms, sectioning DP, `ROWS`/`TAB_ROWS` first-match tables, byte test spellings (VM and scan edge callers); reference `studies/cls_tree_study/`, tests `tests/clskit/`.
- `known.c` / `known.h` — [KIT-VERIFY] Z2 `cover` decision (`cover_conj[]`, `MkEnd`); harness-routed only (`pcrec_kit_proof_routed`); checks `tests/kitproof/`.
- `emit_subst.c` — [M4-SUBST] the subst artifact (`docs/spec/subst_api.md`): the prefix-independent subst block (`PCREC_SUBST_H`: codes, cursor, binding, generic bind, glue `pcrec_subst`), the per-template element `<prefix>_render`, `<prefix>_subst_info` and its stamps. Changing the subst block's text is NOT an rx abi event (it is never in an rx artifact) but its `#error` guard ties it to `PCREC_RX_ABI_H`.
- `stamp_kinds.c` — [COMPOUND] the STAMP CATALOGUE (match_api.md §6.3): every stamp classified by what it is a fact about, deciding its value on a compound.
- `runcmp.c` — DELETED ([MEMFN] M1b; the run compare is the kit's `memfn/src/runcmp.c`).
